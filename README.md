# 微光小鎮 Glimmerville

一款**完全原創**的等距像素城市建造小遊戲。單一 HTML 檔案、零依賴、零外部素材——
所有像素美術都是用 Canvas 在載入時程式化手繪的。

## 怎麼玩

| 步驟 | 說明 |
|------|------|
| 1️⃣ 鋪路 | 選「🛣 道路」拖曳畫路（跨水自動變橋，$60） |
| 2️⃣ 分區 | 選「🏠 住宅」「🏪 商業」「🏭 工業」框選路邊的地 |
| 3️⃣ 供電 | 蓋一座「⚡ 電廠」，電力沿道路輸送（每座供 50 棟） |
| 4️⃣ 收稅 | 建築自己生長、升級（最高 3 級），每天繳稅給你 |

- **需求條 R/C/I**：綠＝居民想搬來、藍＝缺商店、黃＝缺工廠，跟著需求劃區
- **幸福度**：🌳 公園加分；住宅緊鄰工業/電廠會扣分
- **里程碑＋成就**：人口達標有獎金；跨海造橋、綠意之城等 8 個成就等你解鎖 🏆
- 日夜循環（夜裡窗燈✨）、小地圖導航、📊 收支統計、↩️ 撤銷（Ctrl+Z）、
  🔊 三段音效（含晝鳥鳴/夜蟲鳴）、每張地圖隨機鎮名、3 存檔槽＋分享碼匯出入
- 進階（v1.3+）：火災與 🚒 消防局、🏫 學校、🏦 貸款

## 操作

| 平台 | 操作 |
|------|------|
| 電腦 | 拖曳平移・滾輪縮放・數字鍵 1-8 切換工具・空白鍵暫停 |
| 手機 | 單指拖曳（檢視模式＝平移，建造模式＝畫）・雙指縮放平移 |

進度每 25 秒自動存檔（localStorage），關掉再開可「繼續上次的小鎮」。

## 放到安卓手機玩

任選一種：

1. **直接傳檔**：把 `index.html` 傳到手機（LINE/網盤/USB 都行），用 Chrome 開啟即可。
2. **區網共享**：電腦上在本資料夾執行
   `python -m http.server 8123`
   手機連同一個 Wi-Fi，瀏覽器開 `http://<電腦IP>:8123`。
3. Chrome 選單 →「加到主畫面」，就有全螢幕圖示像 App 一樣。
