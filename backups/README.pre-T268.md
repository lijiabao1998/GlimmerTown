# 微光小鎮 Glimmerville

一款**完全原創**的等距像素城市建造小遊戲。單一 HTML 檔案、零依賴、零外部素材——
所有像素美術都是用 Canvas 在載入時程式化手繪的。

## 操作

| 平台 | 操作 |
|------|------|
| 電腦 | 拖曳平移・滾輪縮放・快捷鍵切工具・空白鍵暫停/速度循環 |
| 手機 | 單指拖曳（檢視模式＝平移，建造模式＝畫）・雙指縮放平移 |

快捷鍵（電腦）：`1` 檢視、`2`-`6` 五級道路、`7`/`8`/`9`/`0` 住宅/商業/工業/公園、
`-` 拆除、`=` 路飾；字母鍵 `b` 公車站、`w` 水塔、`g` 水管、`j` 警察局、`h` 醫院、
`c` 診所、`l` 圖書館、`o` 郵局、`m` 墓園；`Ctrl/Cmd+Z` 撤銷、`Esc` 回檢視。

進度每 25 秒自動存檔（localStorage），關掉再開可「繼續上次的小鎮」。

## 放到安卓手機玩

**首選：區網共享**（功能完整，支援 PWA 離線快取與「加到主畫面」全螢幕圖示）：

1. 電腦上在本資料夾執行 `python -m http.server 8123`
2. 手機連同一個 Wi-Fi，瀏覽器開 `http://<電腦IP>:8123`
3. Chrome 選單 →「加到主畫面」，就有全螢幕圖示像 App 一樣

⚠️ 存檔跟著 origin 走：**換 IP 或換端口＝換 origin＝存檔各自獨立**，
網址一變就看不到舊存檔（可用遊戲內 💾 面板的分享碼匯出/匯入搬家）。

備選：**直接傳檔**——把 `index.html` 傳到手機（LINE/網盤/USB）用 Chrome 開。
注意現代 Android Chrome 對 `file://` 限制多：無 Service Worker＝**沒有離線快取與
主畫面圖示**，僅適合隨手試玩；要長期經營請用上面的區網方式。
