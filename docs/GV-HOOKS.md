# GV 鉤子語意手冊（探針作者必讀）

> T561 立（2026-08-25）。緣起：2026-08-22 十小時玩測馬拉松出的三張 P2 卡**全數**死於鉤子語意誤用
>（T555 clamp 型誤呼叫／T556 setter 型誤清狀態／T554 座標型誤當投影），P3 清單再添三個同因假象
>（紅游標、診斷餵法、HUD 殘影）。**規則：呼叫任何 GV 鉤子前，先 `String(GV.鉤子名)` 看簽名與實作。**
> 本檔記「語意類型」與「已判決的誤用案例」；逐鉤子的行為以 `String(fn)` 現場為準（原文才是真相）。

## 一、語意類型（六類，誤用各有典型症狀）

| 類型 | 例 | 陷阱 |
|---|---|---|
| **setter 型** | `challenge541(id,bonus)` | **無參數呼叫＝寫入 undefined/null**。T556 的「挑戰完成不觸發」就是探針自己 `challenge541()` 把狀態清了 |
| **clamp 型** | `diffDesc547(i)` | 無參數 → `undefined|0=0` → 回**簡單難度**的描述。T555 誤判「沙盒回錯描述」 |
| **查詢型（含 null 語意）** | `canPlaceTool(t,x,y)` | **回 null＝可建**、回字串＝拒因。peer 記成「恆回 null＝壞了」，其實是讀反了 |
| **座標型** | `w2v/v2w` | **格索引旋轉變換**（T367，rot=0 恆等），**不是**世界像素→螢幕投影。要置中用 `lookAt(x,y)`；`center()` 是唯讀查詢（回螢幕中心的格），不動相機。T554 撤卡主因 |
| **面板轉儲型** | `inspectAt(x,y)` | 觸發 inspect 並回 `#infoBody` 的 innerHTML（與指南共用容器）——它是 UI 快照不是資料查詢 |
| **時間型** | `step(n)`＝日結；`advanceN(dt,n)`＝幀 | 船隻/載具/幀效果走 advance；經濟/電網/提示走 step。混用會「量不到」 |

## 二、造境規則（本輪玩測與判決實驗踩出來的）

1. **先關開始畫面再點螢幕**：`newWorldSeeded()` 不關 `#start` 覆蓋層；螢幕座標點擊會全落在
   覆蓋層上。先 `#bNewGame.click()` 正門進場。**每次螢幕點擊前 `elementFromPoint` 遮擋審計。**
2. **驗屍法要閉環**：UI 動作「成功」後對同格跑反向 oracle（應「已佔」）才證明落點精確；
   只看計數器增加會把「畫到別格」誤判成功（T554 判決實驗方法）。
3. **canPlace 含資金檢查**：造境先 `addMoney`，否則「哪裡都不可建」（T265 前例）。
4. **建築要完工才工作**：新建築 age<9 是工地（不供電、不生產）。`__t412Set(x,y,'age',9)` 凍結完工
   （測試橋）或 `step(10+)`。
5. **電廠 k5 是 1×1、路要貼身**：啟動源的帶電判定看四鄰；隔一格草＝孤島（誠實診斷，非 bug）。
   太陽能/風力是併網容量**不是啟動源**（資訊面板原文「需電廠併網啟動」）。
6. **25 秒自動存檔會覆蓋當前槽**：長跑前 `GV.save()` 隔離、探針一律槽 3（RULES 18）。
7. **rAF 停擺的環境裡 HUD 是殘影**：`updHud` 每 0.25s 跑一次——headless 渲染凍結時讀到的
   日期/數字是舊的（P3-6 判決：真人環境 250ms 自癒，非缺陷）。
8. **紅色半透明菱形＝「此處不可建」游標**（`SPR.cursorBad`）：滑鼠停在已佔格＋選著建造工具
   就常駐。headless 滑鼠不動＝截圖裡永遠有紅格（P3-3 判決：非缺陷）。

9. **forceDraw 有視錐裁剪**：只畫視野內的格——遠格量測必須先 `lookAt` 該格再 draw
   （兩幀量測法；T571 守衛實踩：轉角格在中心視野外＝計數恆 0 的假陰性）。
10. **streetHash 是純座標函數**：與 seed 無關——被密度閥擋格時換 seed 無效，
   要**擴座標候選集**（T571：四組 L 路 16 內角）。套件端可經 `__t571Hash` 橋讀值。
