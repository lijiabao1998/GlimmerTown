# T107 遠景 LOD（全城視野 60fps）
版本：v3.2 ｜ 難度：★★ ｜ 前置：T106 ｜ 建議模型：Sonnet

## 目標
z<1 的遠景檔位下維持流暢：按檔位裁剪細節，全圖視野不卡。

## 定位錨
draw() 主迴圈各繪製段；T96 groundCache（遠景時快取一整張更省）；updCars/updSmoke 粒子繪製段。

## 允許觸碰
draw() 內按 `cam.z` 分級跳過：z<1 → 不畫 speck 細沙/路面裝飾/煙粒/雨雪個體（雨雪改全屏色調）；z<0.5 → 小車不畫個體（可畫路網高亮代替）、建築夜窗簡化為單色亮塊，建築本體可退化為 2~4px 色塊（**直接複用 drawMini 的建築色表**，保證遠景與小地圖視覺語言一致）。模擬邏輯一律照跑——只裁「畫」，不裁「算」。

## 禁區
tick() 與一切模擬狀態；sprite 生成；z≥1 的繪製路徑一個字不許動。

## 硬性不變量
- z≥1 逐像素與改動前一致（像素回歸必做）。
- LOD 只影響視覺，GV 數值任何檔位完全一致。

## 本卡驗收
1. 三件套照常（node --check / 380 斷言 / 瀏覽器零錯誤）。
2. z=0.25 全圖視野：用 performance.now() 採樣 60 幀平均幀時間，對比改動前有可測改善；tick 不掉。
3. z≥1 像素回歸一致；z<1 畫面仍「像一座城」（建築剪影與路網清晰可辨，getImageData 亮度分佈非純色）。
