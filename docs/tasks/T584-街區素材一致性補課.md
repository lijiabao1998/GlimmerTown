## 0. 問題定義與進場證據

這不是「全素材再畫一次」，而是修同一種視覺病：主體、附屬物與地面之間缺少可讀的支撐、厚度或前後層級，於是遠景出現浮空橫條、紙片墓碑、平田、箱形廠房與不同年代素材混在一起。

進場探針已確認：

1. 截圖中的粉紅橫條是 T147 商業遮陽棚。現行 `shopAwning()` 只有 `7×2` 色條，掛點為牆面高度 `.72`，沒有牆座、側厚、垂片或支撐；因此不是未知渲染雜訊，而是可重現的美術結構缺陷。
2. `k16`／`k54` 墓園已有墓位，但多數墓碑仍是窄直矩形；業主口述「床位」依畫面與鍵清冊判作「墓位」，卡面保留此推論，若業主指出別的建築則另卡處理。
3. `k22`／`k53` 農場已有作物、稻草人、白鷺與農莊套件；缺口在田壟厚度、田界與灌溉／作業層級，不應再把隨機小物撒滿畫面。
4. `k57` 食品加工廠已有筒倉、輸送帶、貨車與棧板，但主廠房仍以大片平矩形為主，屋面與裝卸區讀不出工業體積。
5. 水塔共有 v0..v4 五式，年代不同、支架／平台／梯具／接地陰影的完整度不一致。
6. 早期住宅與電廠已有多輪覆蓋。只處理真像素與遊戲內樣張仍顯扁的鍵；成熟鍵列「合格不動」，不得把變更數當 KPI。

## 2. 美術語法

1. **遮陽棚**：位置回到首層店面；牆座、棚面、前垂片與兩側支撐形成一組。保留小鎮原色票，不做巨大霓虹、不遮窗。
2. **墓園**：墓碑至少可讀出正面、側暗、帽緣／肩線與落地底座；大墓園增加道路／禮拜堂與墓排的層級，不靠放大墓碑製造體積。
3. **農場**：補田壟高光＋背陰、田界土埂與少量灌溉／作業件；春夏秋冬與生長階段同構，不能只有 base 圖改善、換季又打回平面。
4. **食品加工廠**：主廠房補屋面折線、簷口暗面、裝卸平台／坡道與筒倉—廠房間的管線支撐；既有貨車、棧板、煙囪不得被覆蓋。
5. **水塔**：五式共用「罐體分層、平台、梯／管、斜撐、柱腳／落影」語法，但保留各自剪影；不把五式畫成同一座。
6. **舊住宅**：只補入口門廊、屋簷厚度、基座 AO、側牆投影等能解扁平的結構；不把每棟都塞滿小物，不抹掉 HERO_PIX 辨識細節。
7. **電廠**：優先補主體—附屬設備—院落的尺度關係、管線與維修平台；不得重演 T573 冷卻塔越界，不改新 3×3 佔地或舊檔相容路徑。

所有落筆使用整數像素與既有等距軸；顏色從同鍵既有色系取值。細節的目的為「一眼知道它如何站立與運作」，不是把畫面做成噪點牆。
