# T57 自然災害：洪水

## 目標
加入洪水災害，與河流/高地系統連動，讓低窪與河岸區域面臨淹水風險。

## 需求

### 1. 觸發機制
- 雨天/暴雨持續 5 天以上後，每天 5% 機率發生洪水。
- 洪水影響所有 `t.el===0`（平地）且鄰接水域的格子，以及河流兩岸 1 格範圍。

### 2. 淹水效果
- 淹水格變為 `t.flood=1`（視覺上水面上升），持續 3–5 天。
- 淹水格上的道路不可通行、建築停止產出與升級。
- 建築在淹水格上每天有 10% 機率變為焦土。
- 高地（`t.el===1`）不受洪水影響。

### 3. 防洪設施
- `COST.levee=60`（堤防）：僅河岸格可建，設定 `t.levee=1`。
- 堤防後方 1 格範圍內不受洪水影響。
- 污水處理廠與抽水站（可併入 T49 擴充）可縮短淹水時間。

### 4. 視覺
- `draw()` 中淹水格疊加半透明藍色水紋。
- `SPR.levee`：堤防 sprite。

### 5. UI
- `inspect()` 顯示「⚠️ 淹水中」或「🧱 堤防」。

### 6. 存檔
- 新增 `fl` 字串記錄 `t.flood`，`le` 字串記錄 `t.levee`。

### 7. 測試
- `test_t57.js`：驗證洪水範圍、堤防保護、存讀檔。

- [ ] 高地與堤防可抵擋洪水。
