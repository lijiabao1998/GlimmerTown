## 1. 玩家目標

1. 啟動時（目前 p50 ≈5.1s 全黑無回饋）出現一張像素風載入卡：遊戲標題、微光天際線場景、四階段（核心／建築／城市細節／夜景）、真實進度條與百分比。
2. 進度必須是真進度：只在實際完成的素材區段邊界更新，不是假 timer；載入中使用者能看到畫面推進，而非凍結或跳動。
3. 載入完成卡片淡出，主選單正常出現；失敗路徑顯示「啟動失敗」提示而非靜默凍結。
4. 桌機與手機寬度（≥390px）都可讀；`prefers-reduced-motion` 下關閉動畫。
