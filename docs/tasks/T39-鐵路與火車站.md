# T39 鐵路與火車站

## 目標
建立城際與市內鐵路系統，提供更大量、更低污染的客貨運輸選項，並作為後期高人口城市的骨幹交通。

## 需求

### 1. 常數與工具列
- `COST.rail=40`（每格鐵軌）、`COST.railBridge=160`、`COST.trainStation=900`。
- `KNAME[17]='火車站'`。
- TOOLS 在墓園後插入 `rail`（paint 工具）與 `trainStation`（單點建築）；快捷鍵 `t`（train）。
- 小地圖色表：鐵軌 `#6b5a4a`、火車站 `#8a6a4a`。

### 2. 建造邏輯
- `canPlace`：
  - `rail`：僅陸地或水面（自動變橋），不可與道路重疊，可與高速公路立體交叉（視為不同層）。
  - `trainStation`：陸地、非道路、非鐵路、無建築，且至少一側鄰接鐵軌。
- `doPlace`：
  - `rail`：設定 `t.rail=1`、`t.railBridge=(t.t===0)?1:0`，自動計算連接位罩 `railMask`，清除 tree/deco/zone。
  - `trainStation`：建立 `bld={k:17,lv:1,v:ri(3),age:0,pw:true,h:1}`。
- `doze`：清鐵軌時同步更新四鄰 `railMask`；拆除火車站正常清除。

### 3. 模擬邏擬
- 鐵路提供獨立運輸網：與道路互不搶奪，火車站半徑 12 內住宅幸福 +0.05、工業稅收 ×1.15。
- 火車站維護費 $6/天，就業 12/座。
- 鐵軌維護費 $0.04/格（低於道路）。
- 僅當火車站有連通鐵路網（連到至少另一站或地圖邊界視為對外）時效果生效。
- 列車視覺：每 2 座連通火車站之間生成 1 列通勤列車（8 節車廂），沿最短路徑移動，不參與汽車隨機遊走。

### 4. 視覺
- `buildSprites` 追加：
  - `SPR.rail[16]`：64×32 鐵軌 sprite（枕木＋鋼軌，16 種連接位罩）。
  - `SPR.railBridge[16]`：鐵路橋（鋼桁架＋橋墩）。
  - `SPR.bld['17_1_v']`：火車站 sprite（72×112，月台屋頂＋時鐘塔Ｎ變體，夜間窗燈）。
- `draw()` 地面層道路後繪製鐵路，物件層繪製列車（位於鐵軌上方、建築下方）。

### 5. UI
- `inspect()` 火車站：「🚉 火車站｜半徑12住宅+幸福、工業稅×1.15｜就業12｜維護$6/天」。
- `inspect()` 鐵軌格：「🛤️ 鐵路｜維護$0.04/天｜不吸引住宅」。
- `showStats()` 加 `nSta`、維護費行加「🚉 火車站 -$fin.upSta.toFixed(1)」。
- `showHelp()` 說明鐵路與火車站。

### 6. 存檔
- 新增字串欄位 `rl` 記錄 `t.rail`（0/1），`rb` 記錄 `t.railBridge`（0/1），`rm` 記錄 `railMask`（charCode）。
- `load()` 還原並重算連通性。

### 7. 測試
- `test_t39.js`：驗證鐵路連通判定、火車站效果在連通時生效、列車生成、存讀檔保留。
- `node --check index.html` OK、`node test_t39.js` PASS。
