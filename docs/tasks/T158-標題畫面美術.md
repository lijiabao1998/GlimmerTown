# T158 標題畫面與品牌美術（第一印象）
版本：v4.3 ｜ 難度：★★ ｜ 前置：無 ｜ 建議模型：Sonnet

## 目標
開始畫面是玩家看到的第一眼。目前 logo 是程序化文字。升級為：一幅程序化繪製的等距小鎮剪影背景（晝夜漸變/星空/微光燈火）、精緻 logo、選單排版美化。讓「打開就想玩」。

## 定位錨
- `#start` 開始畫面 DOM 與 CSS、既有 `#logo` canvas（224×128）
- `buildSprites`/繪製手法（可複用等距建築剪影畫法）；晝夜/星空既有手法

## 允許觸碰
- `#logo` canvas（或新增背景 canvas）：程序化繪製一排等距小鎮剪影（沿用遊戲 sprite 畫法縮小），加天空漸層＋星點＋建築窗燈微光＋緩慢飄動（`requestAnimationFrame` 或 CSS 動畫，僅標題畫面）；標題文字加像素風描邊/光暈。
- `#start` 選單：按鈕分組排版、視覺層級（主按鈕「繼續/開拓」突出，難度/挑戰/戰役次級）、與 T157 主題變數統一。
- 標題畫面關閉後停止其動畫迴圈（不影響遊戲主迴圈效能）。

## 硬性不變量
- 只影響開始畫面，**遊戲進行中渲染與模擬零改動**（進遊戲後標題 canvas/動畫停止）。
- 既有開始按鈕功能全不變（繼續/開拓/難度/挑戰/戰役/編輯器/災害/效能）。
- 標題動畫不洩漏（進遊戲 cancelAnimationFrame）；不影響 test_fixde。

## 本卡驗收
1. 三件套（node --check / test_fixde 380 / 瀏覽器零錯誤）。
2. 開始畫面：等距剪影背景＋星空＋窗燈微光可見（getImageData 驗背景非純色、有動態）；logo 精緻化。
3. 所有開始按鈕功能不變；進遊戲後標題動畫停止（無殘留 rAF，效能不受影響）。
4. 手機尺寸標題不破版。
