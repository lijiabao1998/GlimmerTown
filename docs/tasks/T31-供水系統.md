# T31 供水系統

版本：v2.1 ｜ 難度：★★ ｜ 前置：T29（道路分級）｜ 建議模型：Kimi/DeepSeek

## 目標

新增第二種基礎服務網路：供水。水塔提供水壓，地下水管輸送，建築需同時有電與水才能升到 Lv3。
水管可與道路同格，不影響車流與分區。

## 允許觸碰

- 第 1 節：`COST`、`TOOLS`、`KNAME` 相關常數與全域狀態宣告
- 第 2 節：`buildSprites()` 內水塔 sprite 生成區塊
- 第 3 節：`genWorld()`、`newWorld()` 的地磚初始化
- 第 4 節：`canPlace`、`placeCost`、`doPlace`、拆除分支
- 第 5 節：`tick()` 模擬與升級判定
- 第 6 節：`computeWater()` 新建函數
- 第 7 節：`draw()` 地面層／物件層繪製
- 第 8 節：`inspect()`、快捷鍵
- 第 10 節：小地圖
- 第 11 節：`save()` / `load()` 存檔欄位

## 禁區

- 不改電力網路 `computePower`、BFS 邏輯
- 不改道路系統（T29）
- 不改核心日夜循環、煙霧粒子系統
- 不改存檔版本號 `data.v`

### 4. 供水網路

於 `computePower()` 之後新增：
```js
function computeWater(){
  let towers=0;
  for(let i=0;i<N*N;i++){tiles[i].wr=false;if(tiles[i].bld&&tiles[i].bld.k===10)towers++;}
  if(!towers)return 0;
  const seen=new Uint8Array(N*N);
  const q=[];
  for(let y=0;y<N;y++)for(let x=0;x<N;x++){
    const t=T(idx(x,y));
    if(!(t.bld&&t.bld.k===10))continue;
    for(const[dx,dy]of[[0,-1],[1,0],[0,1],[-1,0]]){
      const nx=x+dx,ny=y+dy;
      if(inMap(nx,ny)&&T(idx(nx,ny)).wp&&!seen[idx(nx,ny)]){
        seen[idx(nx,ny)]=1;q.push([nx,ny,0]);
      }
    }
  }
  let head=0;
  while(head<q.length){
    const[x,y,d]=q[head++];
    T(idx(x,y)).wr=true;
    if(d>=90)continue;
    for(const[dx,dy]of[[0,-1],[1,0],[0,1],[-1,0]]){
      const nx=x+dx,ny=y+dy;
      if(!inMap(nx,ny))continue;
      const j=idx(nx,ny);
      if(T(j).wp&&!seen[j]){seen[j]=1;q.push([nx,ny,d+1]);}
    }
  }
  return towers*WATER_TOWER_CAP;
}
function hasWaterNear(x,y,r=2){
  for(let dy=-r;dy<=r;dy++)for(let dx=-r;dx<=r;dx++){
    const nx=x+dx,ny=y+dy;
    if(!inMap(nx,ny))continue;
    if(T(idx(nx,ny)).wr)return true;
  }
  return false;
}
```

## 存檔相容性

新增可選欄位 `wp`（water pipe）。舊檔無 `wp` → 全 0（無水管）。`data.v` 不變。

## 本卡驗收

1. 開新地圖，放置水塔與水管，Console 無錯誤。
2. 有電無水區域的住宅可長出 Lv1，但長期不升 Lv3；補上水管後最終有人升到 Lv3。
3. `GV.tile(x,y)` 檢查水管格 `wp=1`；水塔連通後鄰近水管格 `wr=true`。
4. 拆除水管後 `wr` 重新計算，受影響建築 `b.wa` 歸 false。
5. 💾 → 重新整理 → 繼續 → 水塔/水管位置保留。
6. VERIFY.md 全套通過。
