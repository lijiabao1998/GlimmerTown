# T08 拆除保護（Lv2+ 建築需二次確認）
版本：v1.2 ｜ 難度：★ ｜ 前置：無 ｜ 建議模型：Sonnet

## 目標
單點拆除 Lv2 以上住/商/工建築需在 3 秒內點第二次確認；框選拆除自動跳過它們並提示。防手滑毀城。

## 允許觸碰
第 8 節 `commitRect()` 整個函數（完整替換）；第 8 節全域宣告行加一個變數。

## 禁區
`doPlace` 本體不動（保護邏輯全部放在 commitRect，因為 doze 是框選工具，單點＝1×1 框選）；GV.place 不受保護（測試用）。

## 實作步驟
1. 定位錨 `let panBase=null,pinchBase=null,paintLast=null,downInfo=null,firstPaint=null;`
   → 行尾追加宣告：改為 `...,firstPaint=null,dozeArm=null;`
2. 定位錨 `function commitRect(){`，整個函數替換為：
```js
function commitRect(){
  const x0=Math.min(rect.x0,rect.x1),x1=Math.max(rect.x0,rect.x1);
  const y0=Math.min(rect.y0,rect.y1),y1=Math.max(rect.y0,rect.y1);
  const single=(x0===x1&&y0===y1);
  const hiBld=(x,y)=>{const b=T(idx(x,y)).bld;return !!(b&&b.k<=3&&b.lv>=2);};
  let done=0,cost=0,skippedHi=0;
  // 先估總價，一次判斷
  for(let y=y0;y<=y1;y++)for(let x=x0;x<=x1;x++){
    if(!inMap(x,y)||canPlace(tool,x,y))continue;
    if(tool==='doze'&&hiBld(x,y)){
      if(single){
        if(!(dozeArm&&dozeArm.x===x&&dozeArm.y===y&&performance.now()-dozeArm.t<3000)){
          dozeArm={x,y,t:performance.now()};
          const b=T(idx(x,y)).bld;
          toast(`⚠️ 再點一次確認拆除 Lv${b.lv} ${KNAME[b.k]}`,'bad');sErr();
          return;
        }
        dozeArm=null;
      }else{skippedHi++;continue;}
    }
    cost+=placeCost(tool,x,y);
  }
  if(cost>money){toast('資金不足！需要 $'+Math.round(cost),'bad');sErr();return;}
  for(let y=y0;y<=y1;y++)for(let x=x0;x<=x1;x++){
    if(!inMap(x,y))continue;
    if(tool==='doze'&&hiBld(x,y)&&!single)continue;
    if(doPlace(tool,x,y,true))done++;
  }
  if(skippedHi)toast(`已跳過 ${skippedHi} 棟 Lv2+ 建築（單獨點兩次可拆）`);
  if(done){sBuild();}
}
```

1. 建城至有 Lv2 建築（冒煙腳本＋等待），找到一棟 Lv2：

2. 模擬單點（設 rect 後 commit 不可直接調）→ 改用 UI 實測：選 💥 工具點該建築一次 → 出現「再點一次確認」toast、建築仍在；3 秒內再點 → 拆除。
3. 框選一片含 Lv2 建築的區域拆除 → Lv2 建築保留、出現「已跳過 N 棟」toast、其他物件被拆。

5. VERIFY.md 全套（第 2、5 項必跑）。
