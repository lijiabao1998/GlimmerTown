# T29 道路五級分級系統

版本：v2.1 ｜ 難度：★★ ｜ 前置：T28（資料驅動重構已完成）｜ 建議模型：Kimi/DeepSeek

## 目標

把現有「道路 / 高速路」二分擴展為五級功能道路系統：小巷、支路、次幹道、主幹道、快速路。
不同等級道路有不同的視覺、車速、建造成本、維護費，以及對兩側建築幸福度與稅收的影響。

## 允許觸碰

- 第 1 節：`COST`、`TOOLS`、`KNAME` 相關常數與全域狀態宣告
- 第 2 節：`buildSprites()` 內道路 sprite 生成區塊
- 第 3 節：`genWorld()`、`newWorld()` 的地磚初始化
- 第 4 節：`canPlace`、`placeCost`、`doPlace`、`roadCostAt`、拆除分支
- 第 5 節：`tick()` 經濟與幸福計算
- 第 6 節：`updCars` 車速相關
- 第 7 節：`draw()` 道路渲染
- 第 8 節：工具列切換、框選/拖曳建造
- 第 11 節：`save()` / `load()` 存檔欄位

## 禁區

- 不改電力網路 `computePower`、BFS 邏輯
- 不改地形生成演算法、海拔/河流系統
- 不改核心日夜循環、煙霧粒子系統
- 不改存檔版本號 `data.v`（本卡為新增可選欄位）

## 實作步驟

### 1. 資料模型與常數

定位錨：
```js
const COST={road:15,bridge:60,zone:8,park:60,plant:550,doze:2,fire:400,school:350,dump:300,rdec:25,hwy:45,hwyBridge:180,stad:1200,tree:5,fill:20,bus:80};
```

替換為：
```js
const ROAD_CLASS={ALLEY:0,LOCAL:1,COLLECTOR:2,ARTERIAL:3,EXPRESSWAY:4};
const ROAD_NAME=['小巷','支路','次幹道','主幹道','快速路'];
const ROAD_COST=[8,15,28,55,120];
const ROAD_UPKEEP=[0.01,0.02,0.05,0.12,0.35];
const ROAD_SPEED=[0.5,1.0,1.4,2.0,3.5];
const COST={road:15,bridge:60,zone:8,park:60,plant:550,doze:2,fire:400,school:350,dump:300,rdec:25,hwy:45,hwyBridge:180,stad:1200,tree:5,fill:20,bus:80};
```

定位錨（tile 初始化）：
```js
const tile={t,tree:0,gv:ri(4),road:0,bridge:0,mask:0,zone:0,bld:null,rp:false,wm:0,el:0,ruin:0,rdec:0,bus:0,fire:0};
```

追加 `rc:0`（roadClass，0=無道路，1~5 對應 ALLEY~EXPRESSWAY；與 `road` 布林並存，`road=1` 時 `rc` 才有效）：
```js
const tile={t,tree:0,gv:ri(4),road:0,bridge:0,mask:0,zone:0,bld:null,rp:false,wm:0,el:0,ruin:0,rdec:0,bus:0,fire:0,rc:0};
```

### 2. 工具列

定位錨：

```js
const TOOLS=[
```

改為：

```js
const TOOLS=[

  {id:'alley', ic:'🚶',  nm:'小巷',   pr:'$'+ROAD_COST[0]},
  {id:'road',  ic:'🛣',  nm:'支路',   pr:'$'+ROAD_COST[1]},
  {id:'coll',  ic:'🛤',  nm:'次幹道', pr:'$'+ROAD_COST[2]},
  {id:'art',   ic:'🛣️', nm:'主幹道', pr:'$'+ROAD_COST[3]},
  {id:'hwy',   ic:'🛤️', nm:'快速路', pr:'$'+COST.hwy},
```

（注意：保留 `hwy` id 與現有存檔/快捷鍵相容；內部對應 `rc=EXPRESSWAY+1`）

### 3. 建造邏輯

定位錨 `function canPlace(toolId,x,y)` 的 road 分支：
```js
case 'road':
  if(t.road)return null;
```

改為依工具 id 判斷，允許在同格道路上覆蓋升級（例如支路改次幹道）：
```js
case 'alley':case 'road':case 'coll':case 'art':case 'hwy':
  const rcTarget=roadToolToRc(toolId);
  if(t.road&&t.rc>=rcTarget)return '已為同級或更高級道路';
  if(t.bld||t.zone)return '請先清除建築或分區';
  return null;
```

新增輔助：
```js
function roadToolToRc(id){return {alley:1,road:2,coll:3,art:4,hwy:5}[id]||0;}
function rcToName(rc){return ROAD_NAME[rc-1]||'';}
```

`placeCost` 與 `doPlace` 同步修改：
- `alley/road/coll/art/hwy` 成本取 `ROAD_COST[rc-1]`，橋樑加價 `COST.bridge`
- 若同格已有較低等級道路，只收差價
- `doPlace` 設定 `t.rc=rcTarget`；拆除時 `t.rc=0`
- 修改道路後對自己＋四鄰呼叫 `recalcMask()`（不變）

### 4. 視覺差異

定位錨：道路 sprite 生成區塊（搜尋 `/* ---------- 道路 16 種`）。

為每級道路生成不同外觀：
- 小巷（rc=1）：窄路面，無車道線，兩側略暗
- 支路（rc=2）：現有道路樣式
- 次幹道（rc=3）：雙黃線、略寬路面
- 主幹道（rc=4）：雙向四車道視覺、中央分隔島
- 快速路（rc=5）：現有高速路樣式

可使用同一組 mask 16 種，但每級道路用不同基底顏色/線條。

### 5. 模擬影響

定位錨 `tick()` 幸福計算（`b.h=clamp(...)`）。

追加道路等級對住宅幸福的影響：
```js
const rc=getRoadClass(x,y); // 取鄰近最高級道路
const roadHappy = rc===5?-.12 : rc===4?-.05 : rc===3?0 : rc===2?.02 : rc===1?.05 : 0;
```

商業稅收影響（定位錨住宅/商業/工業稅收計算）：
```js
if(b.k===2){const rc=getRoadClass(x,y); const mult=1+rc*.08; income+=JOBSC[b.lv]*.18*mult;}
```

車速影響（定位錨 `updCars`）：
```js
const speed=ROAD_SPEED[t.rc-1]||1.0;
```

### 6. 存檔相容

定位錨 `save()` 的 `rd`/`br` 字串累加處。

在 `rd`（road）字串後追加 `rcl` 字串（避免與既有 `rc` 路飾欄位衝突）：`rcl+=String.fromCharCode(48+(t.rc||0));`

`load()` 解碼：`rc:d.rcl?+d.rcl[i]:0`。

舊檔無 `rcl` → 全部 rc=0，但 `road=1` 的格視覺上暫時對應支路（rc=2），可在 `load()` 後做一次遷移：
```js
for(let i=0;i<N*N;i++)if(tiles[i].road&&!tiles[i].rc)tiles[i].rc=2;
```

## 存檔相容性

新增可選欄位 `rcl`（roadClass，避免與既有 `rc` 路飾欄位衝突）。舊檔無 `rcl` 時，所有 `road=1` 的格自動遷移為 rc=2（支路）。
`data.v` 不變。
