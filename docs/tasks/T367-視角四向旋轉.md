## 核心設計（對著 v10.0 代碼查證）

單一接縫：**view-space 變換層**。

```text
rot ∈ {0,1,2,3}
w2v(x,y)：rot0 (x,y)｜rot1 (N-1-y,x)｜rot2 (N-1-x,N-1-y)｜rot3 (y,N-1-x)
v2w：逆映射（同式反解）
rotMask(m,r)：鄰接位元 1上/2右/4下/8左 的旋轉置換（recalcFoamAt 位元約定）
```

- **地面層**（groundCache 烘焙迴圈，12576 起）：改走 view 序 `(vy,vx)`，迴圈首行
  `(x,y)=v2w(vx,vy)`；所有「看鄰居」的 sprite（泡沫 wm／shoreBlend sm／道路鐵軌自動拼塊／
  崖邊 16 mask）改用 `rotMask` 後的位元選鍵。地圖邊崖（x=N-1||y=N-1）是世界特徵，
  view 序下自動落在正確格，不用特判。`gKey`（12575）加 `rot` 一欄即自動分鍵。
- **主繪製迴圈（objs）**：同樣改 view 序迭代——則 `dep:fx+fy` 自動＝view 空間深度，
  畫家排序零改動（這是單接縫設計的關鍵收益）。
- **建築錨點**：sz×sz footprint 旋轉後仍是正方形，但「朝相機的角」換了。取 footprint
  四角 world 座標經 w2v，以 view 空間最小角當新 root，沿用 T353 既有錨點語意繪製。
- **實體**（車／船／飛機／行人／粒子／煙，17 處 objs.push）：push 前把世界座標過 w2v，
  dep 跟著用 view 值。
- **輸入**：`toTile`（14349）現行公式得出的是 view 座標，尾端加 v2w 即還原世界格；
  拖曳框選／L 型補間（paintTo）在世界空間運算，pick 對了就全對。
- **陰影／光照**：v1 **固定畫面系光源**（T149 方向性陰影不隨轉）——太陽在畫面上不動、
  世界在轉，屬可詮釋取捨，CHANGELOG 誠實記錄；否決「光源跟轉」（多一套方向表、收益低）。
- **相機**：cam 語意維持「畫面中心的世界格」，旋轉時世界中心不動＝原地轉視角，不暈。
- **存檔**：旋轉**不進存檔格式**（localStorage 獨立 UI 偏好鍵），零存檔相容風險。
