# T531 資源耗盡由玩家決定（照競品的正解給開關，順手補上 T530 自己漏的一半）

**日期**：2026-08-19　**發卡**：Claude（業主授權：自己玩→出卡→施工→合併）

## 0. 兩個來源

**① 競品的正解**（T530 卡面已記，本卡執行後半）：
Cities: Skylines 的礦/油耗盡是品類公認爭議，官方 Colossal Order 的回應
**不是重新調數值，而是內建 `Unlimited Oil and Ore` 開關讓玩家自己選**。
T530 只做了「不騙玩家」那一半（擋下死礦脈、見底通知、疊圖誠實），
刻意把「這個數字該是多少」留給玩家——本卡把開關做出來。

**② T530 自己漏的一半（我的缺陷，本卡負責補）**：
T530 抽了 `resDepleted530(i)` 當單一真相源，但**只收斂了 `>=` 那一側**。
抽取條件用的是等價的 `<` 寫法，**兩處還在裸寫**：
```js
if(RESOURCE[oi]===1&&RDEP[oi]<RESOURCE_STOCK){   // 油井
if(RESOURCE[mi]===2&&RDEP[mi]<RESOURCE_STOCK){   // 礦場
```
而 T530 的 G1 計數釘只釘 `RDEP[..]>=RESOURCE_STOCK` ⇒ **沒抓到**。
**同一條規則的兩種等價寫法，釘住一種等於沒釘。** 這正是 T530 要治的病本身。
補完這一側同時也是本卡的前置：開關必須同時影響「能不能挖」與「能不能蓋」，
不然就會出現「開了無限資源、但礦場照樣停產」的半殘狀態。

## 1. 落地

1. **收斂 `<` 側**：兩處抽取條件改 `!resDepleted530(i)`；抽取與耗損累計收進
   `resExtract531(i,rate)` 一個函式，讓「挖多少、記多少」只有一個決定點。
2. **遊戲選項 `resInfinite531`**（**不是政策**）：
   改的是世界規則不是治理，做成政策會不誠實。走既有 `mkSet` 先例
   （開始畫面「快速設定」，與 `disastersOn`／畫質／地圖尺寸／類別標記同一排），
   `localStorage` 持久化、**不進存檔**。
   **預設關閉 ⇒ 位元恆等**（T385 pattern）：關閉時 `resDepleted530` 與 `resExtract531`
   的算式與原本逐字等價（同樣的 clamp、同樣先寫 `RDEP` 再累加產出）。
3. **開啟時不累計耗損**（而非讓 `RDEP` 無限長大）：這樣玩家把開關關回去時，
   礦脈維持原狀，而不是瞬間全部見底。

**不影響成就**：查過成就表，沒有任何成就以資源開採量為條件（`cat:'resource'` 那些是工具分類不是成就），
所以本開關不會讓任何成就變好拿。如實記，不另設限制。

## 2. 驗收計畫

- **G1 強化（本卡靈魂）**：`RDEP[..]>=RESOURCE_STOCK` **與** `RDEP[..]<RESOURCE_STOCK`
  兩種等價寫法都只准出現在真相源／抽取函式裡——**釘住一種等於沒釘**（T530 的教訓）。
- **G2 預設關閉時位元恆等**：六哨兵不動；且開關關閉時耗盡行為與 T530 完全相同
  （耗盡格擋下、見底通知、疊圖轉暗三項全部照舊）。
- **G3 開啟時行為（雙向）**：開啟後 ①礦場永不見底（跑滿 300 天仍在產出）
  ②耗盡格可以蓋 ③疊圖不轉暗 ④不發耗盡通知；**關回去之後 `RDEP` 不得暴增**。
- **G4 不進存檔**（它是偏好，不是世界狀態）＋走 `localStorage` 持久化。
- **G5 零亂數**。
- 紅源：①只收斂 `>=` 不收斂 `<`（G1 應紅）②開關預設開啟（G2 應紅）
  ③開啟時仍累計 `RDEP`（G3 的「關回去不得暴增」應紅）。
