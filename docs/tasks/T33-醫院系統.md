# T33 醫院系統

版本：v2.1 ｜ 難度：★★ ｜ 前置：T32（警察局系統）｜ 建議模型：Kimi/DeepSeek

## 目標

新增第四種公共服務建築：醫院。醫院提供健康覆蓋，降低其半徑內住宅生病率；未受覆蓋的住宅有機率生病，生病期間不產生人口、不繳稅、幸福大幅下降。

## 允許觸碰

- 第 1 節：`COST`、`TOOLS`、`KNAME` 相關常數與全域狀態宣告
- 第 2 節：`buildSprites()` 內醫院 sprite 生成區塊
- 第 5 節：`tick()` 模擬（生病事件、人口/稅收修正、幸福修正、經濟計數）
- 第 7 節：`draw()` 物件層／生病標記繪製
- 第 8 節：`inspect()`、快捷鍵
- 第 10 節：小地圖
- 第 11 節：`save()` / `load()`（新增 `sk` 欄位記錄生病標記）

## 禁區

- 不改電力/供水/治安網路
- 不改道路系統（T29）
- 不改核心日夜循環、煙霧粒子系統
- 不改存檔版本號 `data.v`

## 實作步驟

### 1. 常數與工具列

`COST` 追加 `hospital:600`。

`KNAME` 追加 `12:'醫院'`。

`TOOLS` 於 `police` 後插入 `hospital`：
```js
  {id:'police',ic:'🚓', nm:'警察局', pr:'$'+COST.police},
  {id:'hospital',ic:'🏥', nm:'醫院', pr:'$'+COST.hospital},
```

快捷鍵追加小寫 `h`：
```js
const map={...,'P':'police','h':'hospital'};
```

### 2. 資料模型

生病標記使用建築 `bld.sick` 欄位（0/1）。

### 3. 建造邏輯

`canPlace` 於 `police` 分支後新增：
```js
    case 'hospital':
      if(t.t!==2&&t.t!==1)return '只能蓋在陸地上';
      if(t.road)return '道路上不能建造';
      if(t.bld)return '已有建築';
      return null;
```

`placeCost` 新增 `case 'hospital':c=COST.hospital;break;`。

`doPlace` 新增：
```js
    case 'hospital':
      t.bld={k:12,lv:1,v:ri(3),age:0,pw:true,h:1};t.tree=0;t.zone=0;t.deco=0;
      break;
```

### 4. 模擬影響

`tick()` 主建築迴圈於警察局計數附近新增 `hospitals` 計數：
```js
    if(b&&b.k===11)policeStations++;
    if(b&&b.k===12)hospitals++; // 醫院計數（T33）
```

於犯罪段之後、經濟段之前新增生病段：
```js
  // 生病（T33）：未受醫院半徑12覆蓋的住宅每天小機率生病
  let sickAlert=false;
  for(let i=0;i<N*N;i++){
    const b=tiles[i].bld;
    if(!b||b.k!==1||b.sick)continue;
    const x=i%N,y=(i/N)|0;
    if(countNear(x,y,12,tt=>tt.bld&&tt.bld.k===12)>0)continue;
    if(R()<.001*b.lv){
      b.sick=1;
      if(!sickAlert){toast('🏥 '+townName+'爆發疾病！點擊生病住宅處理','bad');sErr();sickAlert=true;}
    }
  }
  // 醫院覆蓋內次日康復
  for(let i=0;i<N*N;i++){
    const b=tiles[i].bld;
    if(!b||b.k!==1||!b.sick)continue;
    const x=i%N,y=(i/N)|0;
    if(countNear(x,y,12,tt=>tt.bld&&tt.bld.k===12)>0){b.sick=0;}
  }
```

住宅人口計算改為：
```js
      if(b.pw&&!b.sick){popN+=Math.round(POPS[b.lv]*(b.den?DEN_POP[b.den-1]:1));}
```

住宅幸福公式追加生病懲罰：
```js
      b.h=clamp(...-(b.sick?.35:0),...);
```

經濟段住宅稅收也排除生病建築：
```js
      if(b.k===1&&!b.sick&&!b.fire){...}
```

經濟段新增 `hospitals` 計數與維護費：
```js
  upkeep=... +hospitals*5;
  fin={...,upH:hospitals*5,net:income-upkeep};
```

`buildSprites()` 尾端追加醫院 sprite：72×112，白色建築＋紅十字＋救護車＋夜間窗燈。

`draw()` 物件層於警察局後追加：

    else if(bd.k===12)s=SPR.hospital; // 醫院（T33）

## 本卡驗收

1. 開新地圖，放置醫院，Console 無錯誤。
2. 醫院半徑12內住宅不生病；移除醫院後一段時間開始生病。
3. 生病住宅人口為 0、不繳稅、幸福顯著下降。
4. 醫院覆蓋後，生病住宅次日康復。
5. 💾 → 重新整理 → 繼續 → 醫院與生病標記保留。
6. VERIFY.md 全套通過。
