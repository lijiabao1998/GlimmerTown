## 問題（調查清單 P4、P5、P9、P10、P19）

- **整列一根棍子**：每節車廂用車頭的方向往回推 `ci*.62`，轉彎時三節同時換方向，後兩節飄出軌道最多 1.2 格。
- **線尾瞬間掉頭**：到線尾那一刻 `c.d=rev`，整列跳到線尾外的草地上。
- **對撞穿過**：同一條單線上兩列直接互相穿過。
- **從不停車**：速度固定 1.1 格／秒，不停站、不減速。
- **尾燈每節都亮**：除了車頭以外每一節都畫紅色尾燈。

## 做什麼（`index.html`）

- `t707On()`：`?noT707=1` 或 `window.__noT707` 關閉。T707 建在 T706 的分流上：T706 關了，T707 也一起關。
- 每列車記住頭車走過的格（`trail`，最近的在前）；缺的時候沿軌道往回補（剛生成、或 frame 場景直接放的列車；車頭停在彎道格上時從彎的另一條腿補）。列車不進存檔，這些欄位只影響畫面。
- `trainCar707`：第 i 節取在頭車後方弧長 i×0.62 處（間距不變），方向是它所在那一段的行進方向。轉彎時各節各自轉向，永遠在軌道上。
- `cars707`：繪製迴圈每節的位置、畫面朝向、是不是機車、尾燈都從這裡取（測試也取同一個函式，量到的就是畫出來的）。
- **線尾**：減速、停在擋車器前 1.2 秒，再推拉折返。新車頭就是原本最後一節的位置，新的最後一節正好落在原車頭的位置：不瞬移、不穿過自己。折返後機車在最後、車頭朝後（推送）。
- **停站**：與車站（k17／k55）相鄰的軌道格停 1.5 秒，同一座車站只停一次。
- **變速**：下一格要轉彎、是線尾或車站旁時減到 0.55 格／秒，其餘 1.1（原速）。加速 0.8、減速 1.4 格／秒²。
- **閉塞**：前一格被別列的車身壓到（每節所在的格與它正跨進的下一格）就停在本格；等超過 2.5 秒就推拉折返。
- **燈**：頭燈照舊在最前一節；尾燈只畫在最後一節的車尾。
- 選岔路的 `vri` 呼叫不增不減（T402 G2 釘 20 處）；T581 的取幀與光錐、T344c 的逐節 dep 都不動。
