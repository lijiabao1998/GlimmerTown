## 兩項裁決(最高權限行使,記錄在案)

**A1 鋼雙重計帳 → 裁決:改真分流。**
理由:T418 的卡魂是「乘數鏈→物流鏈」,雙重計帳(當日產出全額入庫又全額當加速額度)讓「耗鋼」
退化回配額開關,背叛卡魂。落地:施工加速迴圈內**每加速一棟即 `steel--`**(額度 `cap418=steelMade`
與庫存雙重下界,`steel<=0` 即停)——鋼真的流向工地;造船廠與施工**競爭同一庫存**
(結算順序=造船先、施工後,既有 tick 位置不動,入卡聲明);`steelTaxMul` 快照時點=
「造船結算後、施工消耗前」,入卡聲明。新增本日快照 `constrSteelUse418`(鐵律7 三處成對歸零
——newWorld/load/tick 首,**T418 A3 的血就在 load 這一處**)。

**A2 舊城貨輪歸零 → 裁決:港口保底 1 艘。**
理由:港口本身有民用航運(基線 1 艘=港口活著的感覺),造船廠艦隊撐起第 2 艘=新機制仍可見;
既有存檔不再無預警失去全部貨輪。落地:`want.cargo=Math.min(2,hubs.cargo.length,1+shipCount)`。
frame path 純算術,不動 vri 呼叫點(T402 G2 恰 20 不動;G4 雙生子不受影響——vri 消耗差異不進 tick 態)。

## 四口守衛債(T418 事後審計實證,修法照工作流處方)

1. **F2 收入側零守衛(紅線級)**:全部 T418 測試跑在 diff 3 沙盒(money 凍結)⇒ income 行可拔、
   `SHIP_DAILY_GOLD=0`/`FUEL_EXPORT_GOLD=0` 可出廠而面板照報。
   → **冷凍場景絕對值斷言**:無人口純鏈城(零稅收、維護費全為固定常數)+`setDiff(1)`,
   穩態日 `Δmoney` **恰等**於「鏈收入−固定維護」的常數式(船 `shipCount×6` 與出口 `round(export×2.0)`
   都在式內);另補 `fin.shipDaily364===shipCount*SHIP_DAILY_GOLD` 鏡像恆等 + 兩常數行**原文釘**。
2. **F3 fuel/steel 無守恆帳(紅線級)**:`fuel-=fuelUse418` 可拔=白拿乘數+同批油日日轉賣。
   → **守恆恆等式**(消耗類紅線=行為計數守,T413a 鐵訓):全鏈場景連續 K 日逐日斷言
   `fuel[d]===fuel[d-1]+made−use−export` 與 `steel[d]===steel[d-1]+made−shipUse−constrUse`(全整數精確)。
3. **F4 供率中段零採樣**:比例式可退回純開關。→ **半供案**:造境使需求 6/日、供給 3/日,
   斷言 `freightTaxMul===1.04`(=1+0.08×0.5,精確等)。
4. **F5 常數下界不咬**:SHIP_STEEL∈[21,40]/PORT_CAP=1/FREIGHT_FUEL_USE=1/EXPORT_RATE=1 全綠。
   → **規格點精確斷言(=== 不用 ≤)**:首船邊界(第 29 個耗鋼日 count===0、第 30 日 ===1)、
   雙港跑滿 count===4、滿供 `fuelUse===frt×2` 恰等、盈餘富餘案 `export===tp×4` 恰等。
