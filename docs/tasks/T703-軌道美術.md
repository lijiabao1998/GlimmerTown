**claim**：Claude；分支 `claude/town-train-702`（延續，未另開分支）；base `eacb7ff`（v11.245）。

## 問題

T702 之後，**列車的動態**（逐節轉向、進彎減速、端點停頓折返）已達標，但**軌道本身**仍是舊素材：

| 問題 | 現況 | 應該 |
|---|---|---|
| 彎道 | 用直軌拼成 L，沒有真曲線 | 專用彎軌貼圖（內外弧對齊軌距） |
| 軌距 | 兩條細線，與車身比例不符 | 軌距 ≈ 車輪內緣，車身外擴 ≤ 0.1 格 |
| 枕木 | 稀疏、放大後像白色小棍 | 密度 ×2，顏色壓暗、與道碴同色系 |
| 道碴 | 一整片褐色帶 | 有邊緣不規則與明暗顆粒 |
| 交叉／端點 | 無專用貼圖 | 交叉段與止衝端點 |

## 做法

1. **素材**：新增 `SPR.rail703` 一組——直（4 向以旋轉覆蓋 2 向 + 斜向 2）、彎（4 種轉向）、交叉、端點止衝。尺寸對齊現有 64×32 格（2:1 等距）。
2. **繪製**：以 `t.rail` 的方向位元選貼圖；位元為 0 或不足時退回舊 `SPR.rail`（逃生路徑）。
3. **車身**：`SPR.trainLoco/trainCar` 以繪製時縮放（0.85 寬）對齊軌距，**不改原素材**（避免指紋基線大變）。
4. **閥**：`?noT703=1` 或 `window.__noT703` 時完全走舊軌道與原車寬。

## 驗收

- [ ] 直線、彎道、交叉、端點四種段在遊戲內對得上（相鄰格接縫無錯位）。
- [ ] 車輪落在鋼軌上（左右各差 ≤ 1px @ z=2）。
- [ ] `?noT703=1` 時逐位元回舊外觀。
