## 一句話

一棵 **36 節點、4 條路線、每線一組互斥對** 的科技樹：花錢啟動研究、按天推進、一次只研究一項、
研究速度由研究類建築座數決定；節點效果全部是掛在**既有計算點上的乘數／加項**（政策 `pol` 模式），
**零解鎖時全城逐位元恆等**。AI 市長完全不參與（另卡）。

## 設計總綱（五個已定案的決策，施工者不得自行更改）

### 決策 1：HOI4 節奏骨架

- **一次只研究一項**；每天推進 `speed` 點；節點需 `P` 點完成。
- 啟動花 `$C`（沙盒 `diff===3` 免費，先例 `placeCost` `index.html:8669` 的短路）。
- 切換研究不損失進度（各節點進度分別保留，HOI4 慣例）。
- **研究速度 `speed = 1 + min(7, 研究院×1 + 大學×1 + 科技園×2 + 大學城×2 + 數據中心×1 + 太空研究中心×2)`**。
  座數用第一經濟迴圈**現成的計數器**（k45 `inN` @`10631`、k32、k109、k113、k116、k51 —— 同段已有逐 k 計數，零新迴圈）。
  **不用 rank、不用 EDU 場**當速度來源 —— EDU 是髒快取（只在 `rebuildCov` 被寫、`stampCov` 不增量更新，
  X1 實測建校後恆 0 直到下次 load），在它修好前任何掛 EDU 的速率都不可驗收。
- 為什麼不能只用錢：X1 實測同一城市日淨值從 ~0 → +9,054（**跨距 3,000×**），固定價格節點必然壞掉；
  時間×建築座數才是穩定的第二閘。

### 決策 2：門檻只進 `buildToolbar`，不進 `canPlace`、不進 `aiStep`

- 本樹**不重鎖任何既有建築**（玩家昨天能蓋的今天全部照蓋 —— 重鎖＝對老玩家的 T378 型回歸）。
  節點效果只有加成與機制，沒有「奪走」。
- `canPlace`（8487-8655）與 `doPlace`（8779-9466）實測**零門檻檢查**（零 `rankIdx`/`unlockRank` 命中），
  整個測試 harness 依賴這件事（`test_fixde.js:217` findSpot、`:4246` 在 rank1 直接蓋 tvtower）。**不得動。**
- AI 市長不研究、不受科技影響。`aiStep` 的 30 處 `rankIdx+1>=N` 手抄鏡像（`10304-10376`）**一行都不碰**。
- ⇒ 兩個釘定種子（seed301 400天 `pop===4153` @`test_fixde.js:4170`、seed22 `pop===4550` @`:5135`）
  在零解鎖下天然不動 —— 這是本卡最重要的不變量。

### 決策 4：存檔＝一個可選欄位，svcFleet 級驗型

- 欄位 `tech343 = {act:'節點id或空', prog:{id:整數,…僅存非零}, done:[已完成id]}`。
- **零狀態不落欄位**（T364b 慣例 `index.html:17049-17051`：`if(fuel>0)data.fuel364=fuel` ⇒ 舊城存檔 bytes 逐位不變）。
- load 驗型**照 `svcFleet`（`17149`）逐鍵驗，禁止照 `rk`（`17158`）** —— X1 實測 `rk={a:1}` 時
  `{}|0===0` 會**靜默把玩家永久進度歸零**。驗型失敗 ⇒ 整欄棄用回零狀態，**不得拋例外**
  （load 還原段內任何例外會被外層 try 吞掉 → `return false` → `begin()` 直接 `newWorld` 蓋城，`17274`）。
- **不得動 `data.v`**（三個檢查點 `16955/17068/15922`；X1 實測 `v=2` 時 `_bak` 完好會**靜默載入上一份存檔**）。
- **不得往 `bl` 建築元組加位**。
- 鐵律7 成對歸零：`newWorld`（`8404` 附近）與 `load` 前置（`17161` 附近）兩處都歸零。
- 分享碼（`importShareCode` `15915-15942`）走整份存檔 ⇒ **科技進度跟著地圖走**，這是本卡定案的語意（記進指南）。
- 研究購買**不可 undo**（`undo()` `16880-16900` 只還原 tile 快照；先例：買地鐵列車/服務車輛都是面板按鈕不可撤）。

### 決策 5：UI 復用 `#info` 面板＋canvas 樹圖，零新 HUD 按鈕、零新 sprite

- **不加第 15 顆 HUD 按鈕**（T372 手機可達性剛落地，HUD 已滿）。入口＝統計面板新 tab（statTab 慣例，T323）。
- 樹畫在 `#infoBody` 內的一塊 canvas（先例 `drawHistChart` `16043`），拖曳平移、點選節點、
  按鈕啟動研究。面板開關必須走 `showInfoPanel()`（`test_fixde.js:4073-4076` 釘死
  `$('#info').style.display='block'` 全檔**恰好 1 次**）。
- **節點圖示只用 emoji／文字，不新增任何 sprite** ⇒ 整個鐵律2（亂數流）面消失，指紋比對預期**零變動鍵**。
- 新靜態 DOM id（若有）**必須同卡加進 `test_fixde.js:88` 的 `ids` 白名單**（本卡明示授權）——
  否則 Node harness 對未註冊 id 每次回傳一次性 div，「不報錯但永遠測不到」（T374 同型陷阱）。
- 新 CSS 不得插在 `#toolcats{…}` 與 `\n#tools{` 之前（`test_fixde.js:268/:286` 取第一匹配）。
