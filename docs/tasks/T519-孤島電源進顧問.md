# T519 孤島電源進顧問（新手殺手的回饋通道）

**日期**：2026-08-18　**發卡**：Claude（業主授權：自己玩→出卡→施工→合併）
**性質**：玩測 A/B 實驗抓到的**新手殺手**——不是 bug，是**沉默**。

## 0. 實驗（同種子、同建置、只差電廠位置）

| | A：電廠挨著路 | B：電廠離路 4 格 |
|---|---|---|
| 90 天人口 | **56** | **0** |
| 建築數 | 21 棟 | 2 棟（就是電廠與水塔本身） |
| 城市顧問說什麼 | 服務覆蓋缺口一串 | **「💰 財政吃緊 → 調高稅率或減少維護支出」** |

玩家付了錢蓋電廠、面板支出欄明明白白列著「⚡ 電廠 −4.0/日」、城市卻一棟房子都不長，
**而遊戲從頭到尾沒有一個字提到電**——顧問還把他推向「調高稅率」這個完全錯誤的方向。

T432「孤島電源不併網」的機制本身是對的（真實、且有守衛），缺的是**回饋通道**。

## 1. 先掃現況：能力早就有

`powerDiag432(x,y)`（T432a 純觀測診斷）**已經**能回傳
`{mode:'island', status:'孤島電源', detail:'發電廠周邊 1 格沒有帶電道路'}`——
但只有玩家**點到那一格**才看得到。顧問（`cityAdvisor()`）從不呼叫它。

⇒ 本卡＝**接線，不是造能力**（T456/T517 同型：整合既有系統）。

## 2. 落地

`cityAdvisor()` 既有全圖掃描迴圈中順便收集電源建築座標（零額外掃描），
對每個電源呼叫既有 `powerDiag432`：

- **⚡ 孤島電源**（`mode==='island'`）：`sev=1`（壓過所有既有建議，因為它會讓整座城歸零），
  文案給出「用道路連到電源旁 1 格」與可點擊跳鏡頭座標（沿用 `tp.x/tp.y` 既有機制）。
- **🔌 建築缺電**（zoned 建築中 `!b.pw` 佔比 >30%）：`sev` 隨比例，提示擴充電廠或接電網。

零新模擬：只讀既有場與既有診斷函式，顧問本來就只在面板開啟時跑 ⇒ 六哨兵位元恆等。

## 3. 驗收計畫

- G1 顧問必須呼叫既有 `powerDiag432`（**不得自建判定**——防第二套電網判定漂移）。
- G2 **行為 A/B（本卡靈魂）**：同種子同建置，電廠挨路 ⇒ 顧問**不出**孤島建議；
  電廠離路 ⇒ 顧問**必出** `sym==='islandPower'` 且 `sev` 為全表最高。
- G3 既有 13＋1 條 tip 原文回歸；T517 的 sym 雙向覆蓋不破（新症狀若無誠實政策則不掛 sym）。
- G4 六哨兵＋計數釘。
- 紅源三案：改成自建判定（不呼叫 powerDiag432）／severity 降到壓不過財政／孤島時不出建議。
