# T54 學校巴士與教育網路

## 目標
強化教育系統：學校巴士讓偏遠住宅也能享受教育加成，大學提供更高階升級與就業。

## 需求

### 1. 常數與工具列
- `COST.university=1200`。
- `KNAME[32]='大學'`。
- TOOLS 插入 `university`。

### 2. 建造邏輯
- 大學為 3×3 多格建築，需陸地、無建築、無道路。

### 3. 模擬邏擬
- 大學維護 $8/天，就業 20/座。
- 全圖住宅升級機率 ×1.2（與學校/圖書館疊加）。
- 大學半徑 15 內住宅幸福 +0.05、商業稅收 ×1.1（高教育勞動力）。
- 校車動畫：每座學校與大學生成校車，沿道路行駛，經過住宅格時給予當天臨時幸福 +0.01。

### 4. 視覺
- `buildSprites` 追加 `SPR.bld['32_1_v']`：大學 sprite（鐘樓＋校舍，3×3）。
- `SPR.schoolBus`：校車 sprite。

### 5. UI
- `inspect()`：「🎓 大學｜全圖升級加成｜半徑15幸福+稅收｜就業20｜維護$8/天」。

### 6. 存檔
- `bl` 存 root，sz=3。

### 7. 測試
- `test_t54.js`：驗證大學 3×3 建造、全圖加成、校車動畫、存讀檔。

## 驗收標準
- [ ] 大學 3×3 可建可拆。
- [ ] 提供全圖與區域加成。
- [ ] 測試通過。
