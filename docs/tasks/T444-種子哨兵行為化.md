## 0. 這張卡挑的債

`docs/ARCH.md` §10.14：

> **種子哨兵剛好卡在門檻上**（`MIN_SEED_PINS=2`，目前恰好 2 條），零餘裕；
> 而且哨兵是**正則數的**，把 `=== 3781` 改寫成 `=== POP_EXPECTED` 就合法地繞過了
> （T433 R02：原文舉的字面量是已退役的 4153，照著 grep 會找不到而先浪費一輪）。

`tools/verify.py:29` 的 `MIN_SEED_PINS = 2`，配上

```python
re.findall(r'assert\(window\.GV\.stats\(\)\.pop === \d+', test_text)
```

——這條哨兵**只讀原始碼的字面樣子**。它沒有辦法回答唯一重要的那個問題：
**那兩根釘今天真的跑過了嗎？跑出來的值真的等於釘的值嗎？**

把 `=== 3781` 改成 `=== POP_EXPECTED`（一個剛好等於 3781 的常數），
套件照樣全綠、兩根釘照樣成立，而**哨兵會回報 0 根，閘門直接紅**——它連方向都是反的：
它擋的是「有人把釘子寫得更好」，擋不住「有人把釘子拔掉」。

反過來也一樣：把兩條 assert 整段刪掉、再在註解裡貼一行
`assert(window.GV.stats().pop === 3781` 的**文字**，哨兵會數到 1；
貼兩行就數到 2，**閘門全綠而釘子一根都不在**。
