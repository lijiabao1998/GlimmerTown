## 目標

新增十座可在既有一格低密住宅中出現的英國地域住宅外觀；不改玩法種類、價格、密度、存檔、建築足跡或全局畫面風格。保留全部既有款式與像素指紋。不是十種招牌或十種配色，而是十個有量體、窗型、屋頂結構差異的原創模型。

候選模型為 Arnol blackhouse、Kent oast 改建住宅、Wealden hall、Scottish tower house、八角 lodge 改編、Moirlanich longhouse、Yorkshire laithe house、1930 年代現代住宅、Devon net-loft 改編、Kinver rock house。原型來自 Historic England／Historic Environment Scotland／National Trust／National Trust for Scotland。各款另記結構來源、藝術化修改與最相近舊款差異；oast、toll lodge、net loft 的遊戲住宅用途不假冒為原用途。blackhouse 不硬加歷史不存在的窗或煙囪；夜間門口可見光須局限於開口。岩屋只畫在本格精靈，不改地形。

十款依量體與結構區分：低圓草頂、圓筒錐頂加方翼、中央凹入雙端挑樓、圓底方頂石塔、八角寬簷、細長鐵皮屋面、前伸農倉不等坡、低平退台玻璃鼓、外石階抬高網閣、砂岩凹入住宅。不得重用 T634 或 T670 既有模型換色充數。
