# T405 — 類別標記可關(TheoTown 觀感對標 第一刀)

業主拿我們的實機圖與 TheoTown 並排:「建築物排列更接近 theotown 的感覺,你迭代到好位置」。

## 偵查定案(wf_abea8b7c 四向):畫面最大噪音源不是排列,是徽記

我原本猜是市民需求氣泡,**猜錯**。那些小方塊是 **T345 類別徽記**:
- 11×11 深底板 `#0d1220` + 9×9 類別色塊 + 白色象形符,畫在**屋頂線上方 11px**;
- 外加**基座類別色環**(alpha .9、lineWidth 2、類別色描邊整個 footprint + 內側暗描邊);
- **烘進 sprite 像素本身**(buildSprites 內加蓋),不是每幀 overlay ⇒ 任何 LOD 閘門都救不了,
  z=0.5/0.7 兩檔照樣滿畫面色塊(z<0.5 才因 lodMini 退化成色塊而消失)。

TheoTown 同等縮放**零徽記**——玩家看到的是城市本身。這是兩張圖最刺眼的差異。

## 設計

1. **開始畫面新增第四顆設定鈕「🏷️ 類別標記:開/關」**,沿用災害/畫質/地圖尺寸的
   localStorage 慣例(鍵 `SAVEKEY+'.badge'`),**預設關**(向 TheoTown 觀感靠攏;
   類別資訊仍可由懸停標籤/檢視面板/指南🎨類別圖例三處取得)。
   因徽記烘進 sprite,切換後 `location.reload()` 生效(開始畫面重載零損失)。
2. **補齊逃生閥漏網**:k121-123(煉油/鋼鐵/造船,`parity364`)與 k124-133(十座社區/防災,
   `parity364cd`)在 T345 區塊之外**硬畫色環與徽記、完全沒有 __noBadge 判斷**——
   偵查抓到的既有缺口,本卡一併補上,否則關了之後仍有 13 棟頂著方塊。
3. `window.__noBadge` 語意不變(truthy=不畫),測試釘的字面 `if(!window.__noBadge){` 原樣保留。

## 紅線

- 徽記加蓋段**零亂數**(T345 既有守衛,鐵律2):新增判斷不得引入任何 R()/ri()/rand()。
- 不動 KCAT/KCB/GLYPH 類別資料(指南圖例、kcat345 測試依賴)。
- 不動 drawHoverLabel(它本來就受 __noBadge 控制,關標記時懸停仍可查名)。
- 零模擬/零存檔影響;兩釘恆等(純繪製層)。
