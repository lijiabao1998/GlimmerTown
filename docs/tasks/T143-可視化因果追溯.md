# T143 可視化因果追溯（透明度旗艦化）
版本：v4.0 ｜ 難度：★★ ｜ 前置：T110/T129/T130 各場已落地 ｜ 建議模型：Sonnet

## 目標
把 TheoTown 的黑盒痛點反轉成賣點：inspect 面板中點某條負向幸福/財富因子→在地圖高亮貢獻來源格（污染→染 POL 源格；缺覆蓋→畫最近所需服務半徑缺口；壅堵→標紅路段）。本作透明度強項的旗艦呈現（判準 15）。

## 定位錨
- `inspect()` 面板（happyParts 分項顯示，T111）、`draw()` 疊圖層、drawCursor
- 各場：POL 源、COV 覆蓋、roadLoad 壅堵、犯罪 countNear

## 允許觸碰
- inspect 面板各負向因子行變可點擊；點擊設 `traceOverlay={factor, tiles}` 狀態，掃出該因子的貢獻來源格（污染→鄰近 POL 源格；缺服務→畫最近該服務缺口/所需半徑；壅堵→高 load 路段）。
- `draw()` 依 traceOverlay 高亮來源格（複用既有疊圖手法，如 T110 熱度/T126 半透明）；再點/關面板清除。
- `GV.trace(factor)` 鉤子（可觀測，判準17）。

## 硬性不變量
- 純資訊疊圖：不改任何模擬公式、不改存檔格式。
- traceOverlay 空時 draw 零迭代、無工具狀態渲染與改動前逐像素一致（像素回歸）。
- 只讀既有場，不新增模擬。

## 本卡驗收
1. 三件套照常。
2. 製造污染住宅→inspect 點「空氣污染」→地圖高亮 POL 源格（getImageData 驗高亮位置）；點「交通壅堵」→高亮紅路段；缺服務因子→高亮覆蓋缺口。關閉清除。
3. 無 overlay 狀態像素回歸與基準一致；零 console 錯誤。
