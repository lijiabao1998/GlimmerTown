# T155 載具與人物變體（街上不再千車一面）
版本：v4.2 ｜ 難度：★★ ｜ 前置：無 ｜ 建議模型：Sonnet

## 目標
載具從單一車型擴為多型多色，行人有形態差異：轎車/廂型車/卡車/機車 4 型 × 多色、公車與服務車保留識別色、行人 3 種形態（成人/孩童/推車）與行走兩幀、船隻 2 型、火車車廂變體。

## 定位錨
- 既有小車 sprite 與 `updCars`、公車 `SPR.bus`、服務車（救護/消防/垃圾，T119）、船 `updBoats`、火車 `updTrains`
- T146 街道行人（2px 點）、`buildSprites` 絕對尾端

## 允許觸碰
- 尾端新增載具 sprite 家族：轎車/廂型車/卡車/機車各 4-6 色（沿用既有小車生成手法換形換色）；車型依車輛 id 決定性挑選（**不消耗 R()**）。
- 行人升級：T146 的 2px 點改為 3 種 3×5px 小人 sprite（成人/孩童/推車）＋行走兩幀，依座標與 `visT` 決定性選幀。
- 船隻 2 型（貨船/漁船）、火車車廂 2 種塗裝。
- 服務車（救護/消防/垃圾）保留現有識別色不變（玩家靠顏色辨識，不可打亂）。
- LOD：`z<1` 行人退回點狀、`z<0.5` 不畫載具個體（沿用 T107）。

## 硬性不變量
- 新 sprite 絕對尾端；`__noVeh` 關閉時全 SPR 鍵位元一致。
- 車型/行人挑選用決定性雜湊，不消耗 R()；同一車輛 id 車型固定不閃爍（連續幀驗）。
- 服務車識別色不變（救護白紅/消防紅/垃圾深綠，實測比對）。
- 不改載具移動邏輯、尋路、模擬與存檔。

## 本卡驗收
1. 三件套照常。
2. `__noVeh` 開時位元一致；關時道路上出現多車型多色（區域取樣色彩多樣度上升）。
3. 同一車輛連續幀車型不變（無閃爍）；服務車識別色與改動前一致。
4. 行人三形態與行走兩幀可見；LOD 正確降級。
