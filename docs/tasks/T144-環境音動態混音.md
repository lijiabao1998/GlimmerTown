# T144 環境音動態分層混音（氛圍勝點）
版本：v4.0 ｜ 難度：★★ ｜ 前置：無 ｜ 建議模型：Sonnet

## 目標
TheoTown 音畫粗糙是評測公認弱項（研究#4）；本作已有程序化 BGM，再加指標驅動的環境音床即可把氛圍拉成明確勝點（判準 16）。交通密度→街噪、人口→人聲、工業→機械、公園/自然→鳥鳴；季節/天氣切換交叉淡化。

## 定位錨
- 音效系統：程序化 BGM composer、既有 3 段音效開關、WebAudio 節點
- 指標：交通 roadLoad、人口 pop、工業計數、公園覆蓋 COV.park、season（T136）/weather

## 允許觸碰
- composer 新增環境音匯流排（≥3 層）：各層一個程序化噪聲/振盪源（街噪=濾波噪聲、人聲=群集氣泡、機械=低頻脈衝、鳥鳴=高頻點綴），增益由即時指標驅動（平滑跟隨，避免突變）。
- 季節/天氣切換時交叉淡入淡出（複用既有 composer 情緒切換路徑）。
- 沿用既有音效總開關（關閉＝靜音）；`GV.ambientLevels()` 鉤子（可觀測各層增益，判準17）。

## 硬性不變量
- 音效關閉時完全靜音、無 WebAudio 節點洩漏；環境音疊加於既有 BGM 不取代。
- 增益平滑（無爆音）；指標為 0 時對應層靜默。
- 不影響模擬/存檔/渲染（純音訊）；同種子模擬位元不受影響。

## 本卡驗收
1. 三件套照常（音訊不阻塞 node/test）。
2. 瀏覽器：交通密集→街噪層增益上升、工業城→機械層、公園城→鳥鳴（GV.ambientLevels 驗各層隨指標變動）；季節切換交叉淡化無爆音；音效關閉全靜音。
3. 不影響渲染/模擬；零 console 錯誤。
