## T364a 精緻化管線（2× 內部解析度，全部後續建築的母管線）

目標：新建築的細節密度超過 TheoTown（其 1×1 素材 32×25），但不動既有 120 座。

1. sprite metadata 新增**可選** `sc` 欄（縮放因子）。繪製路徑對有 `sc` 的 sprite
   以 `s.w*sc*z`、`s.h*sc*z` 繪製，錨點換算同步乘 `sc`，**足印與錨點語意完全不變**。
   無 `sc` 的既有 sprite 路徑逐位元不變（靜態守衛：既有 `SPR.bld` 鍵不得出現 `sc`）。
2. 本波 13 座 sprite 以 **2× 內部解析度**生成（1×1＝144×224 畫布，`sc:.5`，依此類推），
   生成期允許亞像素筆觸；夜光圖層同規格。
3. 新波美術規格（我們的風格，非 TheoTown 臨摹）：程序化筆觸不變，但每座強制
   ①基座環境光遮蔽裙 ②雙色高光（頂面冷／立面暖）③至少一處材質紋理
   （磚／金屬板／木／混凝土擇適）④屋頂或立面至少一組功能細節（管線／梯／機組）。
4. **中繼點**：T364a＋T364b 完成後，atlas 圖鑑頁新舊並列截圖＋日夜實拍交業主，
   業主明確點頭才准開工 T364c/d；不點頭則調整規格重交，不得量產。

## T364b 資源深加工波（A：k121–123）— 管線首秀

- **k121 煉油廠**（3×3）：k49 油井的原油→燃料存量（`fuel`，接 T346 chain 同款式
  `gasSup/gasDem` 基礎設施），燃料→工業與貨運稅加成（固定決定性係數）。
  美術：管線塔群＋儲罐＋T363 同款 draw-time 決定性排氣（不進粒子管線）。
- **k122 鋼鐵廠**（3×3）：k50 礦場的礦→鋼材存量（`steel`），鋼材→工業稅加成＋
  所有走 `upCost()` 的**真實付費**升級費固定 ×0.85。美術：高爐＋冷卻塔＋鐵鏽暖色調。
- **k123 造船廠**（3×3，**需鄰水**，比照 k59 hydro 鄰水判定）：消耗鋼材→
  港口／貿易站稅加成。美術：船台＋龍門吊＋半成品船體。
- 三座的鏈數值進 `GV.chain346()` 同款可觀測鉤子（擴充不另造）。
