版本：v1.1 ｜ 難度：★★ ｜ 前置：無 ｜ 建議模型：Kimi

## 目標
人口里程碑加到 8 檔；新增 8 個一次性「成就」，達成時金色 toast＋號角音，進存檔（重讀不重複觸發）。

## 允許觸碰
第 1 節 `MILES` 常數與新增全域；第 5 節 `tick()`；第 11 節 `save`/`load`。

## 禁區
UI 版面（成就只用現有 toast 呈現）；`dem` 公式；紓困邏輯。

## 實作步驟
1. 定位錨 `const MILES=[[50,300],[150,600],[400,1000],[900,1600],[1600,2600],[2600,4000]];`
   → 追加 `,[4000,6000],[7000,10000]`。
2. 其下新增：
   ```js
   let ach={};   // 已解鎖成就 id → 1
   const ACHS=[
     {id:'bridge',  nm:'跨海工程師',   t:s=>s.bridges>=1},
     {id:'park10',  nm:'綠意之城',     t:s=>s.parks>=10},
     {id:'plant3',  nm:'電力大亨',     t:s=>s.plants>=3},
     {id:'rich',    nm:'金庫滿盈',     t:()=>money>=50000},
     {id:'pop5k',   nm:'大都會',       t:()=>pop>=5000},
     {id:'year3',   nm:'三年之約',     t:()=>day>=1080},
     {id:'ind20',   nm:'工業重鎮',     t:s=>s.nI>=20},
     {id:'happy',   nm:'幸福之都',     t:()=>pop>=500&&cityHappy>=.75},
   ];
   ```
3. `tick()` 經濟段。定位錨 `  let income=0,upkeep=0,roads=0,parks=0,plants=0;`
   → 改為 `  let income=0,upkeep=0,roads=0,parks=0,plants=0,bridges=0,nI=0;`
   迴圈內 `    if(t.road)roads++;` 後加 `    if(t.bridge)bridges++;`
   `    else if(b.k===5)plants++;` 的 else-chain 中，工業計數：在 `else income+=JOBSI[b.lv]*.15;` 所在分支不便插入，改在 `const b=t.bld; if(!b)continue;` 之後加一行 `    if(b.k===3)nI++;`。
4. `tick()` 里程碑段之後（定位錨 `  // 紓困保底（避免卡死）` 之前）插入：
   ```js
   // 成就
   for(const a of ACHS){
     if(ach[a.id])continue;
     if(a.t({bridges,parks,plants,nI})){
       ach[a.id]=1;
       toast(`🏆 成就解鎖：${a.nm}`,'gold');sFanfare();
     }
   }
   ```
5. 存檔：`save()` 的 data 物件加 `ach:Object.keys(ach)`；
   `load()` 在 `msIdx=d.msIdx||0;` 後加 `ach={};for(const id of d.ach||[])ach[id]=1;`；
   `newWorld()` 內 `msIdx=0;` 同行補 `ach={};`。

## 存檔相容性
新增可選欄位 `ach`（字串陣列）；舊檔無 → 空物件，全部成就可重新解鎖。`data.v` 不變。

## 本卡驗收
1. 冒煙腳本建城，造 1 座跨水橋（找水邊 `GV.place('road',x,y)` 到水格上）→ 出現「跨海工程師」toast。
2. Console `GV.place('park',...)` 放 10 座公園 → 「綠意之城」。
3. 💾 → 重新整理 → 繼續 → 已解鎖的成就**不再**彈 toast；`JSON.parse(localStorage['glimmerville.v1']).ach` 包含已解鎖 id。
4. 開新地圖 → 成就歸零可重新解鎖。
5. VERIFY.md 全套。
