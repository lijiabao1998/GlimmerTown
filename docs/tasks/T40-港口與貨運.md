# T40 港口與貨運

## 目標
加入水運貨港，讓臨水工業區擁有額外貨運出口收入，並鼓勵玩家沿海岸線規劃產業帶。

## 需求

### 1. 常數與工具列
- `COST.port=1100`、`COST.dock=80`（碼頭棧橋）。
- `KNAME[18]='貨運港'`。
- TOOLS 在火車站後插入 `port`（單點建築）與 `dock`（paint 工具）；快捷鍵 `y`。
- 小地圖色表：貨運港 `#5a7a8a`、碼頭 `#4a6a7a`。

### 2. 建造邏輯
- `port`：必須緊鄰至少 2 格水域（t===0），陸地、無建築、無道路。
- `dock`：僅水域（t===0）可放，且與港口或既有碼頭相連成線；形成貨船航道。
- `doPlace`：港口建立 `bld={k:18,...}`；dock 設定 `t.dock=1`。

### 3. 模擬邏擬
- 港口維護費 $5/天，就業 10/座。
- 碼頭維護費 $0.1/格。
- 港口半徑 10 內工業稅收 ×1.2；每座港口每天額外產生貨運收入 `工業就業數×0.05`。
- 貨船：每座有 dock 航道連通的港口生成 1 艘貨船，沿 dock 線往返港口與地圖邊界，動畫呈現。

### 4. 視覺
- `buildSprites` 追加 `SPR.bld['18_1_v']`（貨運港：起重機＋倉庫＋貨櫃，夜間作業燈）。
- `SPR.dock`：碼頭棧橋 sprite。
- `SPR.cargoShip`：貨船 sprite，沿 dock 繪製。

### 5. UI
- `inspect()` 港口：「🚢 貨運港｜半徑10工業稅×1.2｜貨運收入…｜就業10｜維護$5/天」。
- `showStats()` 加 `nPo`（注意與郵局區分，可用 `nPort`）、維護費行加港口。

### 6. 存檔
- 新增 `dk` 字串記錄 `t.dock`。

### 7. 測試
- `test_t40.js`：驗證臨水建造、工業加成、貨船生成、存讀檔。

- [ ] 港口提供工業稅收與貨運收入加成。
