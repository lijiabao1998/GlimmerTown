# T395 — 跨格連續大田(農業美術三期 R1;業主第一優先)

業主原文:「讓相鄰同作物格共享一套連續壟線(壟行方向與相位跨格對齊,streetHash 決定性取向,
零亂數)…邊緣再加草叢越界、田埂土路,網格感全消。」

## 偵查定案:網格感的三個真來源(wf_65f5580a 四向偵查)

田是 **per-sprite 烘焙**(`field(g,ax,ay,hw,hh,s)` 畫進 offscreen canvas,一張圖蓋整棟
k22 2×2 / k53 5×5),不是 per-tile 即時繪製。因此「跨格連續」不能靠讀鄰居畫,
只能靠**幾何週期與等距格對齊**。三個來源:

1. **烘焙的菱形田埂框**(8368-8371):每棟田四邊都畫 1px 亮土框 ⇒ 相鄰兩田間出現
   **兩條並排亮線**,是最強的網格線。
2. **壟行週期與等距格不可公度**:相位量 `(xx-2*yy)`,等距鄰格螢幕偏移
   x+1=(+32,+16) ⇒ Δ相位=0(**天然連續**);y+1=(-32,+16) ⇒ Δ相位=**-64**。
   現行週期 6:`-64 mod 6 = 2` ⇒ **南北向鄰田壟行永遠錯開 2px 相位**(農場間距 2 格則錯 4)。
3. 作物 `v=(x*5+y*11)%16` 使鄰田幾乎必然不同作物(**本卡不處理,留 T396x**)。

## 設計(零額外 sprite、零記憶體增加)

### A. 壟行週期 6 → 8(核心;數學上零成本全域連續)

`64 mod 8 = 0` ⇒ 南北向偏移歸零,南北+東西**兩軸皆天然連續**。
- `field()`:`const ph=(((xx-2*yy)%8)+8)%8;` 三段比例 `ph<1` 溝底 / `ph<5` 土面 /
  `ph>=5` 脊頂(1+4+3=8),保持既有暗溝-土-亮脊三級立體讀法。冬季雪脊條件同步改 `ph>=5`。
- `soil374`(大農場 base,5274):同步改 8 週期並保留 flip 參數語義
  (flip 版 `(xx+2*yy)`:x+1 ⇒ +64、y+1 ⇒ 0,同樣 `64 mod 8 = 0` ⇒ 兩軸皆連續)。

### B. 作物株格點 (3,2)/(5,-2) → (4,2)/(-4,2)

等距鄰格偏移 (±32,16) 正好是新基向量的 **8 倍整數組合** ⇒ 株行跨格對齊;
且兩基向量的壟相位皆 `4-4=0` / `-4-4=-8≡0` ⇒ **所有株種在同一壟相位(脊上)**,行列筆直。
`plantGrid` 步進改 `cx3=4*sc, cy3=2*sc, rx3=4*sc, ry3=2*sc`(r 取負向),
保留 `sc=hw/30` 等比放大與菱形裁切,大農場照樣放大不脫節。

### C. 田埂改為「只框田塊外緣」

移除 `field()` 尾端無條件菱形框;改由 draw 端依鄰接即時畫(1px 線,成本同水面浪花層):
四邊各自判定「該側鄰格是否同屬農田(k22/k53)」,**非農田才畫田埂**。
相鄰田之間無線 ⇒ 幾塊格子讀成一片。判定走 `w2v` 旋轉補償(T375 硬性)。

### D. 邊緣柔化(草叢越界)

田塊外緣(即畫田埂的那幾側)在田埂外側撒少量草色像素,`streetHash(x,y,鹽)` 決定性取向,
密度掛畫質檔位;`lodFar` 短路。

  取向一律 `streetHash`。

- **存檔零影響**:不改 `bd.v` 生成、不改 tile 欄位、不改生長階段語義(gst 仍 3 階 12 天)。
- **像素雜湊預期會變**(美術卡):改用「變更範圍證明」——無農地的種子/視角須逐位不變。
