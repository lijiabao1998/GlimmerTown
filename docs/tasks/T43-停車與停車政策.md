# T43 停車與停車政策

## 目標
加入停車場與路邊停車格，平衡商業區吸引力與住宅區擁擠懲罰。

## 需求

### 1. 常數與工具列
- `COST.parkingLot=150`（地面停車場）、`COST.parkingMeter=15`（路邊停車格）。
- `KNAME[20]='停車場'`。
- TOOLS 插入 `parkingLot`（單點，2×2 多格建築）與 `parkingMeter`（道路附屬）。
- 快捷鍵 `k`。

### 2. 建造邏輯
- `parkingLot`：2×2 陸地、無建築、無道路（比照體育場縮小版）。
- `parkingMeter`：僅普通道路格可放，設定 `t.parkMeter=1`。

### 3. 模擬邏擬
- 停車場：半徑 8 內商業稅收 ×1.1、住宅幸福 -0.02（擁擠）。
- 路邊停車格：所在道路格周圍 2 格內商業稅收 +1%。
- 停車場維護費 $1.5/天，就業 1/座。
- 若商業區附近無任何停車設施（停車場/停車格）且商業數≥3，則該區商業稅收 ×0.9。

### 4. 視覺
- `buildSprites` 追加：
  - `SPR.bld['20_1_v']`：停車場 sprite（2×2，劃線車位＋小車）。
  - `SPR.parkMeter`：路邊停車收費錶 sprite。

### 5. UI
- `inspect()` 停車場顯示加成範圍與就業。

### 6. 存檔
- 新增 `pm` 字串記錄 `t.parkMeter`。

### 7. 測試
- `test_t43.js`：驗證停車場 2×2 建造、商業加成、停車格效果、存讀檔。

## 驗收標準
- [ ] 停車場與停車格可建可拆。
- [ ] 商業區停車供需影響稅收。
- [ ] 測試通過。
