# T273 牧場變體擴充（3→5）

日期：2026-07-23  
狀態：完成  
風險：低（兩張尾端靜態 sprite＋一個座標決定性模數；不改經濟、存檔格式或 AI）

## 問題

農場已有 12 種作物與四季圖，牧場仍只有牛、羊、馬三種。內容密度失衡，
且「更多農作物」會同時牽動四張 base、十二張季節衍生圖與色彩 remap；
先補牧場的豬場、家禽場，能用更小的改動取得清楚的玩家價值。

## 施工邊界

1. 新增 `23_1_3` 豬場與 `23_1_4` 家禽場，像素構圖完全原創。
2. 新區塊只能放在 `SPR.bld['62_1_0']` 之後、T261 夜燈遮罩之前；
   可沿用 `plate()`，但不得插入既有 sprite 生成序列中段。
3. 牧場選型只由 `(x*7+y*5)%3` 改為 `%5`；不得新增
   `R()`／`ri()`／ambient `Math.random()`／既有共用 `rand()` 消耗。
4. 不改牧場價格、2×2 footprint、食物／金幣／就業、升級、季節、
   canPlace、save/load schema、AI 或 Service Worker。
5. T272 的「當卡 exact diff」改以本卡開工快照（post-T272）封存，
   current 的正式 reset/ambient/random-site 行為測試仍永久執行。
