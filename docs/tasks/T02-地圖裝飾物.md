# T02 地圖裝飾物（岩石／蘆葦／野花叢）
版本：v1.1 ｜ 難度：★★ ｜ 前置：無 ｜ 建議模型：DeepSeek

## 目標
地圖生成時隨機撒三種裝飾：草地岩石、水邊蘆葦、野花叢。純觀賞、建設時自動清除、可拆除、進存檔。

## 允許觸碰
第 1 節無；第 2 節 `buildSprites()`（**只新增** `SPR.deco`，不改既有 sprite）；第 3 節 `genWorld`；第 4 節 `canPlace`/`doPlace`；第 7 節物件層；第 11 節 `save`/`load`。

## 禁區
- 樹（tree）的一切邏輯——deco 是平行的新欄位，不要合併、不要重用 tree 欄位。
- `computeFoam`、道路 mask、電力，全都與 deco 無關，不要碰。

## 實作步驟
1. **欄位**：第 3 節定位錨
   `    const tile={t,tree:0,gv:ri(4),road:0,bridge:0,mask:0,zone:0,bld:null,rp:false,wm:0};`
   在 `wm:0` 後加 `,deco:0`。
2. **生成**：同函數內，樹判定行 `if(t===2&&noi2(...)...)tile.tree=1+ri(4);` 下一行加：
   `else if(t===2&&R()<.015)tile.deco=1;`（岩石）
   然後在 `return water/(N*N);` **之前**加後置掃描（此時全圖已生成，可查鄰居）：
   ```js
   for(let y=0;y<N;y++)for(let x=0;x<N;x++){
     const tl=tiles[idx(x,y)];
     if(tl.t===1&&!tl.deco&&R()<.25){
       for(const[dx,dy]of[[0,-1],[1,0],[0,1],[-1,0]])
         if(inMap(x+dx,y+dy)&&tiles[idx(x+dx,y+dy)].t===0){tl.deco=2;break;} // 蘆葦
     }else if(tl.t===2&&!tl.tree&&!tl.deco&&R()<.01)tl.deco=3;               // 野花叢
   }
   ```
3. **sprite**：第 2 節 `buildSprites()` 內、`/* ---------- 懸崖` 區塊之前，新增：
   ```js
   /* ---------- 裝飾物 3 種 ---------- */
   SPR.deco=[];
   { // 1 岩石
     const[c,g]=cv(32,24),[s,sg]=cv(32,24);
     sg.fillStyle='#8d959c';sg.fillRect(9,12,12,7);sg.fillRect(13,9,7,5);
     sg.fillStyle='#a8b0b8';sg.fillRect(10,12,5,3);sg.fillRect(14,10,3,2);
     sg.fillStyle='#6d757c';sg.fillRect(9,17,12,2);sg.fillRect(19,12,2,5);
     outlineSprite(s,44,48,56);g.drawImage(s,0,0);
     SPR.deco.push({img:c,ax:16,ay:21,w:32,h:24});}
   { // 2 蘆葦
     const[c,g]=cv(32,28),[s,sg]=cv(32,28);
     for(let i=0;i<5;i++){const x=8+i*4,h2=10+(i%3)*3;
       sg.fillStyle='#7a9d4f';sg.fillRect(x,24-h2,1,h2);
       sg.fillStyle='#a8845f';sg.fillRect(x-1,24-h2-3,2,4);}
     outlineSprite(s,40,52,30);g.drawImage(s,0,0);
     SPR.deco.push({img:c,ax:16,ay:25,w:32,h:28});}
   { // 3 野花叢
     const[c,g]=cv(32,18),[s,sg]=cv(32,18);
     sg.fillStyle='#4b8f45';sg.fillRect(8,10,16,5);sg.fillRect(11,8,10,4);
     const fc=['#e8e070','#e8907e','#d9a8e8','#f2f2f2'];
     for(let i=0;i<7;i++){sg.fillStyle=fc[i%4];sg.fillRect(9+(i*3)%15,8+(i*2)%6,2,2);}
     outlineSprite(s,36,64,32);g.drawImage(s,0,0);
     SPR.deco.push({img:c,ax:16,ay:16,w:32,h:18});}
   ```
4. **繪製**：第 7 節物件層定位錨 `    if(!t.tree&&!t.bld)continue;` → `if(!t.tree&&!t.bld&&!t.deco)continue;`
   然後在樹的繪製分支（`if(t.tree){ ... continue; }`）**之後**加：
   ```js
   if(!t.bld&&t.deco){
     const s=SPR.deco[t.deco-1];
     ctx.drawImage(s.img,o.sx+(32-s.ax)*z,o.sy+(32-s.ay)*z,s.w*z,s.h*z);
     continue;
   }
   ```
5. **建設清除**：第 4 節 `doPlace` 內共 5 處 `t.tree=0`（road、三種 zone 共用一處、park、plant），每處後面補 `t.deco=0;`。
   拆除分支定位錨 `      else if(t.tree)t.tree=0;` 改為：
   `      else if(t.tree)t.tree=0;`
   `      else if(t.deco)t.deco=0;`
   `canPlace` 的 doze 判定 `if(!t.road&&!t.bld&&!t.zone&&!t.tree)return '這裡沒東西';` 加上 `&&!t.deco`。
6. **存檔**：第 11 節 `save()` 定位錨 `      ter+=t.t;tre+=t.tree;zn+=t.zone;` 改為其後追加 `dc+=t.deco;`（並在上方宣告 `let ... ,dc='';`，且 data 物件加 `dc`）。
   `load()` tile 建構行的 `wm:0` 後加 `,deco:d.dc?+d.dc[i]:0`。

## 存檔相容性
新增可選欄位 `dc`；舊檔無此欄位 → 全部 deco=0，正常遊玩。`data.v` 不變。

## 本卡驗收
1. 開新地圖，Console：
   ```js
   let n=[0,0,0,0];for(let y=0;y<72;y++)for(let x=0;x<72;x++){const t=GV.tile(x,y);if(t)n[t.deco||0]++;}console.log('岩石/蘆葦/花叢:',n[1],n[2],n[3]);
   ```
   預期三者皆 > 0（岩石約 40±、花叢約 30±、蘆葦視水岸長度）。
2. 對一個有岩石的格 `GV.place('doze',x,y)` → `GV.tile(x,y).deco===0`。
3. 對一個有花叢的格 `GV.place('road',x,y)` → 路鋪上、deco 清 0。
4. 💾 存檔 → 重新整理 → 繼續 → 步驟 1 統計不變。
5. 跑 VERIFY.md 全套。
