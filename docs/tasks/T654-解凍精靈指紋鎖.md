## 起因

T643 讓 CI 的 fp 實算全部 SPR 鍵，並且用卡頭的 families／owner_ok 把關改圖。但還有凍結的鎖把任何改 SPR 家族的美術擋死：
- **scene603.js:297**（`browser` 三道）：上一版的 SPR_PINS 必須正好 1586 鍵、逐鍵不變、不准新增鍵。合理的美術 PR 一定紅；一旦有 PR 加了鍵並部署，「上一版正好 1586 鍵」之後每個 PR 都紅。
- **scene603.js:307**：上一版文件與候選在同一個 Chrome 裡的精靈指紋必須完全相同。
- **release635.cjs:66**（approved-fire-release）：候選的精靈指紋必須逐鍵等於批准前的 main（7ad6931）。

所以 T639 起「美術禁令延續到 T643b」。另外 T641 承諾的「gpt/ 分支可以提交 SPR_PINS」也一直延後。
