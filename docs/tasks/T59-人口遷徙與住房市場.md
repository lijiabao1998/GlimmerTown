# T59 人口遷徙與住房市場

## 目標
讓住宅入住率受幸福、就業、房價影響，模擬真實城市人口流動。

## 需求

### 1. 住房市場
- 每棟住宅新增 `occupancy`（入住率 0～1），初始 1.0。
- 入住率受以下因素影響：
  - 幸福 >0.6：入住率緩慢上升
  - 幸福 <0.4：入住率下降
  - 附近無就業（半徑 8 內無商/工）：入住率下降
  - 犯罪/空置/死亡附近：入住率下降
- 實際人口 = `POPS[lv] × occupancy × density`。

### 2. 人口遷徙
- 每天根據全國平均幸福，有極低機率發生「遷入潮」或「遷出潮」：
  - 遷入潮：空住宅入住率 +0.2
  - 遷出潮：低幸福住宅入住率 -0.2
- 城市評分達 4 星後，遷入潮機率上升。

### 3. 視覺
- 入住率低於 0.5 的住宅顯示「待售」標牌。
- 入住率為 0 的住宅變為空置（保留 zone）。

### 4. UI
- `inspect()` 顯示「入住率 X%」。
- `showStats()` 顯示平均入住率。

### 5. 存檔
- 入住率可選存入 `bl` 第 8 位，舊檔預設 1.0。

### 6. 測試
- `test_t59.js`：驗證入住率變化、遷徙事件、人口計算。

## 驗收標準
