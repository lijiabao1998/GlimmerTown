# T50 救護車與急救網路

## 目標
在醫院/診所基礎上加入救護車系統，縮短緊急醫療反應時間，降低死亡事件發生率。

## 需求

### 1. 常數與工具列
- `COST.ambulanceDepot=400`。
- `KNAME[28]='救護站'`。
- TOOLS 插入 `ambulanceDepot`。

### 2. 建造邏輯
- 單點建築，陸地、非道路、無建築。

### 3. 模擬邏擬
- 救護站維護 $3/天，就業 5/座。
- 半徑 8 內住宅：
  - 生病後轉為死亡的機率從 10% 降至 5%。
  - 已死亡事件若在有救護站覆蓋的墓園半徑內，安葬時間從 10 天縮短為 5 天。
- 救護車動畫：每座救護站生成 1 輛救護車，沿道路巡邏，遇生病住宅時短暫停靠。

### 4. 視覺
- `buildSprites` 追加 `SPR.bld['28_1_v']`：救護站 sprite（車庫＋紅十字）。
- `SPR.ambulance`：白色車身＋紅十字＋警示燈。

### 5. UI
- `inspect()`：「🚑 救護站｜半徑8降低死亡轉化｜就業5｜維護$3/天」。

### 6. 存檔
- 無新欄位。

### 7. 測試
- `test_t50.js`：驗證死亡轉化率降低、救護車生成、存讀檔。

## 驗收標準
- [ ] 救護站可建，降低死亡風險。
- [ ] 救護車視覺正確。
- [ ] 測試通過。
