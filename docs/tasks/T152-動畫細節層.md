# T152 動畫細節層（讓城市會動）
版本：v4.2 ｜ 難度：★★★ ｜ 前置：無 ｜ 建議模型：Sonnet

## 目標
靜止的城市看起來像圖，會動的才像活著。加入低成本高感知的動畫：旗幟飄動、噴泉水花、雷達/風車旋轉、屋頂警示燈閃爍、樹梢搖曳、水面波光、鳥群飛過、船隻航行。

## 定位錨
- `visT` 相位／既有兩幀動畫先例（T105 噴泉 `SPR.decoFtn`、水面 `waterF`、龍捲風三幀）
- `buildSprites` 絕對尾端；`draw()` 物件層與地面層；T107 LOD（遠景跳過動畫）
- 既有載具動畫（車/船/火車）

## 允許觸碰
- 新增多幀 sprite（尾端生成）：旗幟 3 幀（市政廳/學校/體育場掛點）、噴泉水花 3 幀（公園變體升級）、雷達天線 4 幀旋轉（機場/氣象站）、風車葉片 4 幀（既有風力發電）、屋頂警示燈 2 幀閃爍（高樓/塔樓）、鳥群 3 幀（隨機飛過天空層）。
- 樹梢搖曳：對既有樹 sprite 做**輕微水平位移**（±1px，依 `visT` 正弦＋座標相位偏移），不新增 sprite。
- 水面波光：既有 `waterF` 幀外，疊加依 `visT` 的高光點閃爍（低成本）。
- 幀選取一律用 `visT`＋座標決定性相位，**不消耗 R()**；LOD：`z<1` 停動畫用靜態首幀、`z<0.5` 全跳過。

## 硬性不變量
- 新 sprite 絕對尾端；`__noAnim` 關閉時全 SPR 鍵 checksum 位元一致。
- 動畫不消耗 R()、不改模擬／存檔；同一 `visT` 下重繪結果一致（連續兩幀同相位 checksum 相等）。
- 效能：動畫層每幀增量 <1ms（60 幀採樣記錄）；低效能檔（quality=0）自動停用動畫。

## 本卡驗收
1. 三件套照常。
2. `__noAnim` 開時位元一致；關時連續取樣不同 `visT` 相位畫面 checksum 互異（真的在動），同相位重繪一致（無抖動）。
3. 各動畫件逐一實機確認（旗幟/噴泉/雷達/風車/警示燈/鳥群/樹搖/水光）。
4. LOD 與低效能檔正確停用；幀時間增量實測 <1ms。
