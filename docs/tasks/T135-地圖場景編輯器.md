# T135 地圖/場景編輯器＋分享碼（模式軸單向超越）
版本：v3.7 ｜ 難度：★★★ ｜ 前置：T132（場景系統）｜ 建議模型：Sonnet

## 目標
內建編輯器：用既有地形筆刷＋放置工具編關卡，設定目標與起始條件，經分享碼匯出/匯入自製場景並在戰役模式執行。TheoTown 論壇證實本體無內建編輯器——再添一項它缺席的模式。

## 定位錨
- 地形筆刷（T121 tdig/tland/traise）、放置工具、`begin()`、沙盒 diff=3 免費放置先例
- 既有分享碼（base64 匯出/匯入序列化）
- 場景系統 SCENARIOS/scenario（T132）

## 允許觸碰
- 編輯器模式旗標 `editMode`：進入後免費放置＋地形筆刷全開＋不跑經濟（複用沙盒短路）＋顯示編輯工具列。
- 目標設定 UI：選勝利條件型別＋目標值＋起始資金（複用 T132 goal 結構）。
- 序列化：把當前地圖（tiles/建築）＋目標打包進**擴充版分享碼**（沿用既有 base64 路徑，加版本前綴，舊碼仍可解）；匯入自製場景→載入戰役模式執行。
- 開始畫面「🛠 編輯器」入口。

## 硬性不變量
- 編輯器是獨立模式，不影響一般/沙盒/場景正常遊玩。
- 分享碼格式**版本化**：新版碼含編輯器資料，舊版碼（無此段）仍能正常解析載入（向後相容必驗）。
- 畸形/超長分享碼優雅拒絕不崩潰。
- 存檔格式：編輯器產物走分享碼字串，不侵入常規存檔。

## 本卡驗收
1. 三件套照常。
2. 進編輯器→地形筆刷＋放置全開＋免費→設目標→匯出分享碼；新分頁/清存檔後匯入該碼→載入為可玩場景、目標生效。
3. 舊版分享碼（既有格式）仍能正常匯入（向後相容）；畸形碼給錯誤提示不崩潰。
4. 一般模式不受影響；零 console 錯誤。
