# T149 光影與氛圍（感知品質躍升）
版本：v4.1 ｜ 難度：★★★ ｜ 前置：無 ｜ 建議模型：Sonnet

## 目標
同一批素材，靠光影就能拉開一個檔次：夜間窗燈/路燈在地面投出光暈、建築投射方向性陰影、日出日落色調漸變、天氣反應性調色。這是「看起來貴不貴」的關鍵。

## 定位錨
- `draw()` 夜間圖層（'screen' 合成）、`visT` 晝夜相位、既有天氣色調段
- T96 `groundCache`（**光暈屬動態層，不得烘進地面快取**）、T107 LOD
- 路燈/窗燈掛點（既有 sprite 附帶偏移）

## 允許觸碰
- **地面光暈**：夜間在有窗燈/路燈的格下方畫徑向漸層暖色光斑（'screen' 或 'lighter' 合成），強度隨 `visT` 夜深度；畫在建築之前（地面之上）避免蓋住建築。
- **方向性陰影**：建築依固定光向（如西北）在地面投半透明暗色菱形偏移剪影；白天強、夜間弱。用既有 sprite 的 alpha 剪影縮放偏移繪製，不新增 sprite。
- **日出日落色調**：`visT` 在晨昏區間時全屏疊暖橙/冷藍漸層（沿用既有天氣色調段手法，加入晨昏兩檔）。
- LOD：`z<0.5` 跳過陰影與光暈（沿用 T107）；效能檔（T97 quality）低檔關閉陰影。

## 硬性不變量
- **正午無天氣時（visT 在日間、weather=0）渲染與改動前逐像素一致**（光暈/陰影/晨昏在該相位強度為 0，像素回歸必驗）。
- 光暈與陰影**不烘進 `groundCache`**（動態層，每幀畫；快取鍵結構不動）。
- 不新增 sprite、不消耗 R()、不改模擬與存檔。
- 效能：開啟陰影＋光暈後 60 幀平均幀時間增量可測且在中/高效能檔可接受；低檔自動關閉。

## 本卡驗收
1. 三件套照常。
2. 正午基準像素回歸與改動前位元一致（硬不變量）。
3. 夜間：窗燈下方地面出現光暈（getImageData 驗亮度隆起）；建築有方向性陰影（偏移側暗度上升）；晨昏出現暖橙/冷藍調。
4. `z<0.5` 與低效能檔正確跳過；幀時間增量實測記錄。
