# T11 小鎮名字生成
版本：v1.2 ｜ 難度：★ ｜ 前置：無 ｜ 建議模型：Sonnet

## 目標
每張新地圖隨機生成原創小鎮名（詞庫組合，非 AI 權重），顯示在瀏覽器標題、統計面板、開新圖 toast，並存檔。

## 允許觸碰
第 1 節新增常數與變數；第 3 節 `newWorld()`；第 10 節 showStats 標題行；第 11 節 save/load 各一處。

## 禁區
HUD 日期 chip 不動（名字太長會擠爆窄螢幕）；attic/ 的 char-RNN 權重方案不採用。

## 實作步驟
1. 定位錨 `let ach={};   // 已解鎖成就 id → 1` → 其後新增：
```js
let townName='微光小鎮';
const NM1=['微光','晨曦','雲杉','風鈴','石楠','銀月','翠嶺','暖泉','星港','霧谷','楓橋','鹿鳴','燕泊','柳蔭','螢澤','嵐坡','鯨落','棠梨'];
const NM2=['小鎮','村','城','港','丘','灣','岸','屯','里','洲'];
```
2. `newWorld()` 內定位錨 `  computeFoam();` → 其後新增：
```js
  townName=NM1[ri(NM1.length)]+NM2[ri(NM2.length)];
  document.title=townName+' · 微光小鎮';
  toast(`🏙️ 歡迎來到「${townName}」！`,'gold');
```
3. showStats 內定位錨字串 `小鎮統計`（在 `<h3>` 行）→ 標題改為 `<h3>📊 ${townName}</h3>`（注意該 innerHTML 是模板字串，直接嵌入 `${townName}`）。
4. save()：定位錨 `bl,ach:Object.keys(ach)};` → 改為 `bl,ach:Object.keys(ach),nm:townName};`
5. load()：定位錨 `money=d.money;day=d.day;` 所在行之後（或行尾）新增：
   `townName=d.nm||'微光小鎮';document.title=townName+' · 微光小鎮';`

## 存檔相容性
新增可選欄位 `nm`；舊檔無 → 預設「微光小鎮」。

## 本卡驗收
1. 開新地圖 → 出現「歡迎來到「XX」」金色 toast，document.title 變為該名字。
2. 📊 面板標題顯示鎮名。
3. 💾 → 重新整理 → 繼續 → title 恢復同名。
4. VERIFY.md 第 1、2、3 項。
