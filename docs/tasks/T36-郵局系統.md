# T36 郵局系統

## 目標
新增城市服務設施「郵局（post office，k=15）」，提升附近商業稅收與居民幸福，並提供少量就業。

## 需求

### 1. 常數與工具列
- `COST.post = 320`。
- `KNAME[15] = '郵局'`。
- `TOOLS` 在圖書館工具後插入郵局；快捷鍵 `o`（post office）。
- 小地圖建築色表擴充到索引 15，使用顏色 `#d4a24c`（郵政黃）。

### 2. 建造邏輯
- `canPlace` / `placeCost` / `doPlace` 支援 `post`：僅陸地、非道路、無建築。
- `doPlace` 建立 `t.bld = {k:15, lv:1, v:ri(3), age:0, pw:true, h:1}`。
- 拆除邏輯正確清除郵局。

### 3. 模擬邏輯
- tick 主迴圈早期計數 `posts`（與 schools/libraries 同一階段），供就業與維護費使用。
- 就業：`jobs += posts * 5`。
- 住宅幸福公式追加：半徑 8 內有郵局則 `+0.03`。
- 商業稅收加成：半徑 8 內有郵局的商業建築，稅收 ×1.15。
- 經濟段：郵局計數 `posts`，每日維護費 `posts * 3`；統計面板 `fin.upPo` 顯示郵局維護費。

### 4. 視覺
- `buildSprites()` 尾端追加郵局 sprite：72×112，外觀為小型郵政建築（黃色主調＋郵政徽＋大窗＋門前郵筒），夜間窗內暖黃燈光，3 變體。
- `draw()` 物件層正確繪製 `k=15`。

### 5. UI
- `inspect()` 加郵局分支：「📮 郵局｜半徑 8 內商業 +15% 稅收、住宅 +幸福｜就業 5｜維護費 $3/天」。
- `showStats()` 計數加 `nPo`、維護費行加「📮 郵局 -$fin.upPo.toFixed(1)」、建築行加「郵局${nPo}」。
- `showHelp()` 追加郵局說明一行。

### 6. 存檔
- 郵局是正常 1×1 建築，k=15 已透過 `bl` 陣列儲存，無需新增欄位。

### 7. 測試
- 新增 `test_t36.js` DOM mock 測試（沿用 T35 的 mock）：
  - 固定種子建造郵局與商業區。
  - 測量郵局半徑8內商業稅收與外側差異（內側應較高）。
  - 測量郵局半徑8內住宅與外側住宅的幸福差異（內側應較高）。
  - 存讀檔後郵局保留。
