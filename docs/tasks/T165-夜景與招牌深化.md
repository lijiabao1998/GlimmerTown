# T165 夜景與招牌深化（夜晚才是城市最美的時候）
版本：v4.4 ｜ 難度：★★ ｜ 前置：T149（光影）｜ 建議模型：Sonnet

## 目標
深化夜景：更多樣的窗燈圖案（不同建築不同亮燈節奏）、商業霓虹招牌閃爍變化、地標泛光照明、街道節慶燈串、車頭燈/尾燈光跡、廣告看板輪播。讓夜城從「窗戶亮」升級為「霓虹都市」。

## 定位錨
- T149 光影層（`nightDepth`/`fxOn`/窗燈光暈）、night 圖層（'screen' 合成）、`nightSprites`
- T147 霓虹招牌（商業立面 night 層）、`visT`、`buildSprites` 尾端；T107 LOD

## 允許觸碰
- 窗燈多樣化：不同建築類型/等級不同的亮燈比例與閃爍節奏（依 `streetHash`＋`visT`，決定性，不消耗 R()）——住宅溫暖疏落、商業明亮密集、工業冷白。
- 霓虹招牌閃爍：T147 招牌 night 層加 `visT` 相位的明滅/跑馬變化（商業 lv2-3）。
- 地標泛光：大型公共建築（pBig）夜間底部向上泛光照亮建築本體（'lighter' 疊加，沿用 T149 手法）。
- 車燈光跡：夜間車輛前白後紅小光點（沿用 T149 'lighter'，複用既有車輛座標）。
- 街道節慶燈串（可選，稀疏掛於商業區道路上方）。
- LOD：`z<0.5` 夜景細節退化為既有簡單窗燈。

## 硬性不變量
- **日間（nightDepth=0）渲染與改動前逐像素一致**（所有夜景增強在日間強度為 0，像素回歸必驗）。
- 夜景層每幀動態、不烘進 `groundCache`；不消耗 R()、不改模擬/存檔。
- 新招牌/燈串 sprite（若有）絕對尾端＋`__noNight2` 開關證明日間位元一致。
- 效能：夜景全開 60 幀採樣增量可接受；低效能檔降級。

## 本卡驗收
1. 三件套照常。
2. 日間基準像素回歸與改動前位元一致（硬不變量）。
3. 夜間：窗燈多樣（不同建築不同節奏）、霓虹閃爍、地標泛光、車燈光跡可見（getImageData 夜間取樣驗）。
4. LOD/低效能檔降級正確；幀時間增量記錄。
