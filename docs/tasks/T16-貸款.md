# T16 銀行貸款
版本：v1.3 ｜ 難度：★★ ｜ 前置：無 ｜ 建議模型：Sonnet

## 目標
統計面板底部提供貸款：借 $2000、20 天每天自動還 $120（總還 $2400）；同時最多一筆。缺錢時的自救手段。

## 允許觸碰
第 1 節新增全域 `loan`；第 5 節 tick 經濟段（扣款）；第 10 節 showStats 尾部（按鈕與狀態行）；第 11 節 save/load（可選欄位）；紓困提示文案一行。

## 行為規格
1. 全域：`let loan=null; // {remain:天數, daily:120}`
2. 借款：showStats 的 innerHTML 末尾加一行貸款區：
   - 無貸款：顯示【🏦 貸款 $2000（20天每天還$120）】按鈕（addEventListener 綁定，不用內聯 onclick）→ 點擊：`money+=2000;loan={remain:20,daily:120};` toast＋sBuild 音效，面板即時刷新（重呼 showStats）。
   - 有貸款：顯示「🏦 貸款還款中：剩 {remain} 天，每天 -$120」。
3. 還款（tick 經濟段 money+=income-upkeep 之後）：`if(loan){money-=loan.daily;if(--loan.remain<=0){loan=null;toast('🏦 貸款已還清！','gold');}}`
4. 允許 money 因還款變負（現有 UI 已能顯示負數；紓困保底條件不變）。
5. 紓困 toast 文案改為「🏦 小鎮銀行送來 $250 紓困金（也可到 📊 面板貸款）」。
6. 存檔：data 加可選 `ln:[remain,daily]`；load：`loan=d.ln?{remain:d.ln[0],daily:d.ln[1]}:null;`；newWorld 重置 `loan=null;`。

## 硬性不變量
稅收/維護公式一分不動；同時只能一筆（有貸款時不顯示借款按鈕即天然保證）。

## 本卡驗收
1. 📊 → 點貸款 → 錢 +2000、面板顯示還款狀態、再開面板無借款按鈕。
2. 加速 20+ 天 → 「還清」toast、面板恢復借款按鈕；全程每天 -$120（用兩次 stats().money 差值粗驗）。
3. 貸款中 💾 → 重新整理 → 繼續 → 還款狀態延續。
4. VERIFY.md 第 1、2、3 項。
