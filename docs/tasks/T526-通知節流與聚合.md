## 1. 落地：在唯一漏斗裡節流，不在呼叫點

`toast()` 是全檔唯一寫 `log` 的地方（`log.push` 僅一處）——節流只寫在這裡。

- **同類判定**：訊息前 N 字為 kind key（同一句重複＝同類）。
- **首次永不抑制**：第一次出現一定即時顯示 ⇒ 罕見事件（瘟疫/隕石/升級）天然不受影響，
  **不需要任何白名單**（白名單＝人為判斷，會過期）。
- **窗內重複折疊**：`NOTIF_WIN526` 天內的同類重複不再彈窗，累計次數；窗口結束後的下一次同類事件
  帶上「（近 N 天共 M 起）」一次呈現——**被抑制的次數必須被看見，不能靜靜吞掉**。
- 狀態 `notif526`（lastDay/pending/計數）於 `newWorld`／`load` 成對歸零（鐵律7），不進存檔
  （`log` 本來就不進存檔，已查證）。

## 2. 驗收計畫

- G1 節流必須在 `toast()` 單一漏斗內（呼叫點零改動）。
- **G2 行為（靈魂）**：同一場 600 天困難城，通知總數必須顯著下降；
  **且訊息種類數不得減少**——不准靠「整類丟掉」來降低數字。
- G3 被抑制的次數必須出現在後續訊息文字裡。
- G4 首次出現永不被抑制。
- G5 六哨兵位元恆等＋鐵律7 歸零。
- 紅源三案：抑制不記數（靜靜吞）／首次也抑制／節流寫在呼叫點。
