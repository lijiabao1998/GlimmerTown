# T58 犯罪與司法系統

## 目標
深化犯罪後果：犯罪不僅影響幸福，還會導致商店倒閉、監獄關押、更生機制。

## 需求

### 1. 犯罪後果
- 犯罪標記 `b.crime` 持續 5 天後，若未被警察/監獄清除，該建築每天有 20% 機率「倒閉」：商業/工業降 1 級，住宅變為空置（bld=null，保留 zone）。
- 犯罪事件會像火災一樣「蔓延」：半徑 2 內每天 5% 機率傳播。

### 2. 司法流程
- 監獄（T53）可關押犯罪事件，關押後 3 天內有 50% 機率「更生」清除犯罪標記。
- 警察局可「處理」犯罪（現有按鈕），處理後犯罪標記立即清除。

### 3. 空置建築
- 新增 `t.abandoned=1` 標記：建築因犯罪/破產清空後，zone 保留但需重新生長。
- 空置建築影響鄰近幸福 -0.1。

### 4. 視覺
- 空置建築顯示破敗外觀（灰階、破窗）。
- 犯罪蔓延時顯示短暫紅色閃爍。

### 5. UI
- `inspect()` 顯示犯罪剩餘天數與倒閉風險。

### 6. 存檔
- 新增 `ab` 字串記錄 `t.abandoned`。

### 7. 測試
- `test_t58.js`：驗證犯罪倒閉、空置標記、更生機制。

## 驗收標準
- [ ] 犯罪可導致建築倒閉與空置。
- [ ] 監獄可更生清除犯罪。
- [ ] 測試通過。
