# T399 — 水田家族:水稻田淺水面+田字埂+白鷺+夏夜螢火蟲(農業美術三期 R7)

業主原文:「水稻田=淺水面+天空反色(晝夜/天氣自動聯動…水面反光是白撿的氛圍)+
田字埂+白鷺點綴。夏夜螢火蟲粒子低飛田面——微光小鎮,名字都對上了。」

## 事實基礎

- 水稻已存在:k22 變體 v10(CCLASS[10]='rice'),但現在畫在**旱地犁溝**上——
  「稻田沒有水」正是本卡要修的。
- 晝夜聯動是白撿的:全屏 multiply 調色(15278)作用於一切,烘進 sprite 的水色
  自動跟著晝夜/天氣走(與 T186/T187 冬冰夏水同理),不需 draw-time 反射。
- 螢火蟲已有 T361c 夏夜格點掃描版(seaL===1&&nightDepth>0),擴其判定即可,
  **不開第三套**(設計文檔紅線)。

## 設計

1. **paddy399 淺水面**(doFarm 內 cls==='rice' 時**替代** field() 犁溝——field() 本體
   不動,T395 G1 壟相位守衛無涉):菱形內淺水色(基色+streetHash 決定性漣漪斑點
   亮/暗兩級),田埂沿用原 edge 色。**冬季不替代**(si===3 走原 field=放水休耕,
   語義正確且雪田管線零改動)。
2. **田字埂**:過田心的兩條等距軸向堤線(1px 亮土),把水面分成四格=「田」字。
3. **白鷺**:每片水田 1-2 隻(key 雜湊決定性),白身 4px+黑喙黑腿,
   畫在 plantGrid 之後(立於稻秧之上;T398a 埋人教訓直接吸收)。
4. **夏夜螢火蟲低飛田面**:T361c 格點掃描的准入條件擴一種——水稻田格
   (含 ref 解引用),密度與既有樹格同檔。

## 紅線

- field()/plantGrid/stages 呼叫結構不動(T397/T398a 守衛在);零亂數(T395 G7 覆蓋);
  T361c 擴充段零亂數且座標過 w2v(T375 硬性,測試有斷言)。
- 記憶體零增(不加精靈鍵,替代繪製)。

## 驗收

機器軌:1) paddy399 定義+rice 分支在場且冬季不替代;2) 白鷺在 plantGrid 之後;
3) T361c 擴充含 ref 解引用且零亂數;4) 既有守衛(T395/397/398a/375)全綠;
5) 破壞性:rice 分支拆除→紅;冬季守衛拆除→紅。
人眼軌:水田特寫樣張(日景)交業主。
