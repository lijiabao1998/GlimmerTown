# T702 列車關節化：每節車廂各自沿軌道走
<!-- card: families=none; valve=?noT702 / window.__noT702; owner_ok=業主 2026-10-22「我覺得按照你的來好了，繼續」與「做到精細度一模一樣（參考 TheoTown，不抄代碼）」; removed_asserts=0 -->

**claim**：Claude；分支 `claude/town-train-702`；base `eacb7ff`（v11.245）。

## 問題

現在的列車是「一個方向向量 + 沿直線退 `ci*.62`」：

```js
const fx = tr.x + DIRV[tr.d][0]*(tr.p-back), fy = tr.y + DIRV[tr.d][1]*(tr.p-back);
```

所以整列車永遠朝同一個方向、車廂排在一條直線上，**轉彎時不會有折角**。這是我們與 TheoTown 觀感差距最大的一點（TheoTown 每節車廂是獨立實體，各自沿路徑前進，四向貼圖各自由所在格決定）。

## 做法（不抄任何代碼，只取原理）

1. **軌道圖**：把 rail tile 依方向位元串成有向圖（相鄰格 + 方向），得到「路段」與「節點」。
2. **每節車廂一個弧長參數**：`s_i = s_head - Σ(carLen_j + gap)`。
3. **各自求位置與方向**：由 `s_i` 找所在段與段內比例 → 該節的 `(x,y)` 與**自己的方向** `d_i`。
4. 摺角自然出現：各節落在不同段 → `d_i` 不同；不需要另外畫轉彎圖。
5. 保留既有性質：
   - 每節各自 `dep`（T344c）→ 長車轉彎不穿前景
   - 幀由行進進度驅動（T581：`fr581 = floor(p*4)&3`），停車輪子就停
   - 夜光 `nightSprites` 管線不變

## 驗收

- [ ] 轉彎時相鄰車廂**方向不同**（可在樣張/錄影上肉眼確認）。
- [ ] 車廂間距不因轉彎而拉長或重疊（以弧長守恆）。
- [ ] `?noT702=1` 或 `window.__noT702` 時，完全回到現在的行為（逐位元相同）。
- [ ] 既有 `frame`／`scene602`／`fp` 全綠；`test_fixde` 全綠。
- [ ] 效能：40 列車 × 8 節不使 tick 超時（可量 `performance.now()`）。
