## 問題

GitHub runner 有一部分會分到很慢的 `azure.archive.ubuntu.com`。實測 68.8 kB/s，61.2 MB 的 `fonts-noto-cjk` 要下載 14 分 50 秒，正常約 10 秒。

- `scene602` 的 job 上限 20 分鐘，測試本體正常要 7～10 分鐘。抽到慢鏡像時只剩 4～5 分鐘，測試被截斷，gate 紅。
- `fp` 的上限 25 分鐘，裡面要裝字型，還要 `playwright install --with-deps`（也走 apt）。2026-10-22 main（0d6954e）那一輪卡在安裝 Chromium，被取消。
- 2026-10-22～23 一天內出了 6 次：T704 PR 兩次、main 一次、T705 PR 一次、T706 PR 兩次。T706 後面幾輪也有 browser(core)、fp、frame 抽到慢鏡像，字型下載 12～15 分鐘，靠上限較長才沒斷。
- 上限較長的 `approved-art-release`（40 分鐘）同樣抽到慢鏡像，下載了 14～22 分鐘，但跑完了。

## 做什麼

`.github/workflows/town-main-pages-candidate.yml`：

- `scene602` 的 `timeout-minutes` 從 20 改成 40；
- `fp` 的 `timeout-minutes` 從 25 改成 45；
- `frame` 的 `timeout-minutes` 從 30 改成 45（見施工紀錄：卡面推上後、施工前補進來）。

只改這三個數字，步驟、命令、套件、測試都不動。

- [ ] `python tools/verify.py` ALL GREEN。
