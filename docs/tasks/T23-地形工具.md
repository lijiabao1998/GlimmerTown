# T23 地形工具（種樹／填草）
版本：v1.4 ｜ 難度：★ ｜ 前置：無 ｜ 建議模型：Sonnet

## 目標
兩個美化工具：🌲 種樹 $5（草地上種隨機樹）、🟩 填草 $20（沙地變草地）。玩家能修景。

## 允許觸碰
第 1 節 COST/TOOLS；第 4 節 canPlace/placeCost/doPlace 各加兩個分支；快捷鍵表。

## 行為規格
1. `COST.tree=5`、`COST.fill=20`；TOOLS 追加 `{id:'tree',ic:'🌲',nm:'種樹',pr:'$5'}`、`{id:'fill',ic:'🟩',nm:'填草',pr:'$20'}`（皆 rect 框選工具——把兩個 id 加進 `isRectTool`）。
2. tree：僅 `t.t===2 && !t.tree && !t.road && !t.bld && !t.zone && !t.ruin && !t.deco` 可放；效果 `t.tree=1+ri(4)`。
3. fill：僅 `t.t===1`（沙）可用；效果 `t.t=2; t.gv=ri(4);` 並呼叫 `computeFoam()`（地形變了）。
4. 種樹提供微幸福（已有樹不加成也行——**不**動 h 公式，樹本身純觀賞；此行為在卡內明示，不要自作主張加）。
5. 撤銷天然支援（doPlace 路徑）；存檔天然支援（tree/t 已在格式內）。

## 硬性不變量
computeFoam 只在 fill 成功時呼叫（rect 大面積填草會多次呼叫——可接受，或 commitRect 後統一一次：允許在 doPlace fill 分支不呼叫、改在 commitRect 尾部判斷 tool==='fill' 呼叫一次，二選一並在 CHANGELOG 註明）。

## 本卡驗收
1. 草地種樹 → tree>0 扣$5；沙地種樹失敗；框選種一片樹成功。
2. 沙地填草 → t=2 扣$20、鄰接水岸泡沫正確更新（像素或 GV.tile wm 檢查）。
3. Ctrl+Z 撤銷一片種樹 → 樹消失退款。
4. VERIFY.md 第 1、2、3 項。
