## 問題

T149 建築投影（夜晚每棟建築一次；高畫質白天也畫）與 T163 水岸倒影（縮放 ≥1），每次都用 `ctx.filter='brightness(0)'` 即時把精靈壓成黑剪影。

- Chrome 的畫布濾鏡每次都會開一層和目前裁切範圍一樣大的中間層。沒有裁切時就是整張畫布，畫完再合成回來。
- 成熟城夜晚每幀 56～170 次，每次都是整張畫布的開層、清空、合成。
- 雲端真 Chromium（軟體繪圖）：72 格成熟城夜晚縮放 1，每幀約 0.9～1 秒；把這兩處拿掉中間層後約 0.08 秒。
- macOS 真 GPU 的數字：本卡 dispatch 的 native-acceptance（施工紀錄回填）。

## 做什麼（`index.html`）

- `clip716(g,dx,dy,dw,dh)`：畫之前把裁切縮到這次繪製在裝置像素上的外接矩形（外擴 2px，整數像素邊界）。
  - 用獨立的 `Path2D`，不動畫布目前的路徑。
  - 濾鏡照用，顏色運算和原本同一條路。
- T149 投影、T163 倒影兩處，在設 `filter` 前呼叫 `clip716`。
- 閥：`t716On()`，`?noT716=1`／`window.__noT716` 退回原本做法。

## 畫面差異（如實說明）

逐像素並不完全相同。原因是原本整張畫布大的中間層，在某些列會有細微接縫：倒影少一列、色階差 1～3。縮小中間層後接縫消失。

### 試作原文（沒有推上去，留給之後施工用）

放在 `function viewDep(x,y){...}` 後面（T422 G1 守衛會抽 `farNightRect422` 到 `function draw(` 之間的文字，放那裡會紅）：

```js
function t716On(){if(t716On.off===undefined){const q=(typeof location!=='undefined'&&location.search)||'';t716On.off=/(?:^|[?&])noT716(?:=1)?(?:&|$)/.test(q);}return !window.__noT716&&!t716On.off;}
function clip716(g,dx,dy,dw,dh){
  if(typeof g.getTransform!=='function'||typeof Path2D==='undefined')return; // 沒有這兩個 API 的環境（測試用的假畫布）就照原本做法
  const m=g.getTransform();
  const ax=m.a*dx+m.c*dy+m.e,ay=m.b*dx+m.d*dy+m.f,bx=ax+m.a*dw,by=ay+m.b*dw,cx=ax+m.c*dh,cy=ay+m.d*dh,ex=bx+m.c*dh,ey=by+m.d*dh;
  const x0=Math.floor(Math.min(ax,bx,cx,ex))-2,y0=Math.floor(Math.min(ay,by,cy,ey))-2,x1=Math.ceil(Math.max(ax,bx,cx,ex))+2,y1=Math.ceil(Math.max(ay,by,cy,ey))+2;
  const r=new Path2D();r.rect(x0,y0,x1-x0,y1-y0);
  g.setTransform(1,0,0,1,0,0);g.clip(r);g.setTransform(m);
}
```
