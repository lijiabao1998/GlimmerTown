# T56 自然災害：地震

## 目標
加入第一個自然災害：地震。隨機發生，破壞建築與道路，考驗城市韌性。

## 需求

### 1. 觸發機制
- 每天極低機率（0.02%）發生地震；人口>500 後機率升至 0.05%。
- 地震發生時：`toast('💥 地震！多處建築受損','bad')`、`sThunder()`。
- 屏幕震動效果：`shakeT=1.0`，`draw()` 中相機隨機偏移。

### 2. 破壞效果
- 隨機選擇 1–3 個震央，每個震央半徑 4 格內：
  - 建築有 30% 機率降 1 級（Lv1 直接變焦土 ruin）。
  - 道路有 20% 機率損毀（road=0，變焦土）。
  - 水電設施有 10% 機率損毀。
- 學校/醫院等公共設施不會被直接摧毀，但會暫停效果 1 天。

### 3. 韌性機制
- 每座警察局/消防局半徑 12 內，建築損毀機率 ×0.7。
- 地震後 3 天內，全城住宅幸福 -0.1。

### 4. 視覺
- `SPR.debris`：瓦礫 sprite，疊加在受損建築上直到修復。
- 屏幕震動動畫。

### 5. UI
- `showStats()` 加「災害韌性」分數。
- `showHelp()` 說明地震機制。

### 6. 存檔
- 無新欄位，損毀狀態由 `ruin`/`bld.lv` 體現。

### 7. 測試
- `test_t56.js`：驗證強制觸發地震、破壞範圍、韌性減傷。

- [ ] 屏幕震動與瓦礫視覺正確。
