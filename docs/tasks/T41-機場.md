# T41 機場

## 目標
加入後期大型機場，提供城際客運與觀光加成，成為高星級城市的門面設施。

## 需求

### 1. 常數與工具列
- `COST.airport=3500`。
- `KNAME[19]='機場'`。
- TOOLS 在貨運港後插入 `airport`；無快捷鍵（大型設施）。
- 小地圖色表：機場 `#8a8a8a`（4×4 區塊）。

### 2. 建造邏輯
- 機場為 4×4 多格建築（比照體育場 2×2 架構擴充）。
- `canPlace`：16 格全為陸地、無建築、無道路、無焦土。
- `doPlace`：root 格在西北角，其餘 15 格存 `ref:[rx,ry]`。
- 拆除：找 root 一次清除 16 格。

### 3. 模擬邏擬
- 維護費 $25/天，就業 40/座。
- 全圖住宅幸福 +0.03、商業稅收 ×1.1（觀光客效應）。
- 每座機場每天帶來觀光收入 `$50 + pop×0.02`。
- 僅限城市評分達 3 星後可建造（若未達星等，提示「需3星城市」）。

### 4. 視覺
- `buildSprites` 追加 `SPR.bld['19_1_v']`：272×300 大型 sprite（跑道十字、航廈塔台、停機坪飛機剪影），夜間跑道燈。

### 5. UI
- `inspect()`：「✈️ 機場｜全圖住宅+幸福、商業稅×1.1｜觀光收入…｜就業40｜維護$25/天」。
- `showStats()` 加 `nAir`。

### 6. 存檔
- `bl` 存 root，第 6 位存 `sz=4`，`load()` 重建 16 格 ref。

### 7. 測試
- `test_t41.js`：驗證 4×4 建造/拆除、星等限制、收入與幸福加成、存讀檔。

## 驗收標準
- [ ] 4×4 機場可建可拆，無殘留 ref。
- [ ] 3 星以下無法建造。
- [ ] 提供全圖加成與觀光收入。
- [ ] 測試通過。
