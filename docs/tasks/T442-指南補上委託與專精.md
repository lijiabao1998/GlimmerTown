## 0. 這張卡為什麼存在

玩家點 `❓` 打開的「📖 玩法指南」有六個分頁，而 **T385 市長委託／T386a 城市專精／T386b 外貿合約**
在裡面**一個字都沒有**——第 0 頁只有一行「統計分頁：🏙 城市／🔬 科技／📦 流向／📋 委託」告訴他有這個頁籤，
至於委託是什麼、怎麼解鎖、有幾種、獎金多少、專精選了之後不能反悔——全部沒寫。

這是這一夜的第一張**玩家看得到**的卡。前面九張都在修「我怎麼知道自己沒弄錯」，
這一張修「他怎麼知道這遊戲在幹嘛」。

## 1. 一個順手撿到的真 bug（指南寫出來才會被看見）

`index.html:840` 的專精表：

```js
edu:{nm:'教育科技城',ic:'🎓',fx:'教育場+8%・研究速度+1｜政策日費+$12'},
```

而 `:13648` 的實際計算是

```js
const eduFee394=Math.min(40,Math.max(6,Math.round(pop/100)));
```

——T394b 已經把它從**固定 $12** 改成**隨人口規模縮放（$6–$40）**，
但**專精表裡的敘述沒跟著改**。玩家看到的是一個過期三十幾張卡的數字。
它一直沒被發現，正是因為**沒有任何地方把這段文字印給玩家看**。
