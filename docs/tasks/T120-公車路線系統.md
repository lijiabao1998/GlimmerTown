# T120 公車路線系統（交通從調味到策略）
版本：v3.3 ｜ 難度：★★ ｜ 前置：T119 ｜ 建議模型：Sonnet

## 目標
公車站從被動裝飾升級為可規劃路線：玩家把站點串成路線，公車沿路線行駛，路線覆蓋的住宅減少小車生成——實際降低壅堵。

## 定位錨
公車站（t.bus）；updTrains 雙站巡迴（推廣為多站）；小車生成上限 capC；TOOLS。

## 允許觸碰
「路線」工具：點選既有公車站按順序串線（存為站點 idx 陣列，**存檔可選欄位** bus_rt，上限 3 條路線×8 站）；公車實體沿路線道路尋路往返（BFS 沿路，複用鐵路巡迴思路推廣多站）；路線站點半徑 3 內住宅的小車生成率×0.7（多路線不疊加）；選中路線工具時畫面用彩色折線描出路線走向；拆站自動從路線剔除；公車 sprite（黃色長車身）buildSprites 尾端。

## 硬性不變量
存檔只加可選欄位（舊檔無路線正常）；無路線時交通行為與改動前一致；路線斷路（中途道路被拆）時公車就地折返不崩潰。

## 本卡驗收
1. 三件套照常。
2. 串 3 站成線→公車沿路行駛（座標軌跡驗證）；覆蓋住宅小車生成率下降（統計對比）；拆中途路→公車折返不拋錯；拆站→路線自動剔除；存讀檔往返路線保持。
3. 折線描畫與路線一致；零 console 錯誤。
