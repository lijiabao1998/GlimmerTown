## 1. 設計（採 GPT 提案骨架，四處主線化修正）

**四型嚴格分離**（枚舉、守衛機械驗證）：
- `research`：學術文獻真正改變玩法架構——**不重抄引用，`sciRefs` 指回 SCI451 條目**（單一真相源）。
- `methodological`：研究方法影響框架（如 T460 配對差量測），不硬掛論文。
- `design`：競品／工程轉譯（TheoTown 對標、移動線移植）——**禁 sciRefs/DOI**（產品對標與
  學術證據是兩種認識論對象，守衛機械禁止混型）。
- `internal`：內部綜合，不為顯得學術而找 paper。

**主線化修正**：①號碼 T516；②新增 `line` 欄（desktop/mobile/cross）掛 LINEAGE §5；
③**時間戳不自我申報**——主線「出卡先行＋卡面 §0 聯網核實」紀律讓 literature-first 有
git commit 時間戳背書，佐證欄直接引 commit；④覆核狀態如實分層（主線親自核實 vs
Grok/Codex 自審未經獨立覆核）。

**origin mode 枚舉**：literature-first / blind-first / mixed / internal-synthesis / design-derived。
**Independent convergence 不設本卡**——五條件（pre-literature 凍結時戳等）成立前不准掛，
枚舉裡刻意不含此值＝機械上不可能偽造。

**四句標準模板**（常數 `ANCESTRY_NOTES516`，頁面由常數導出）：轉譯聲明（參數皆遊戲設計值）、
證據狀態（非實證重現）、資料使用（未導入微觀資料）、**歸屬邊界**（引用不代表作者背書實作）。
