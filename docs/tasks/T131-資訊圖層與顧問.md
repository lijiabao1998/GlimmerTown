# T131 資訊圖層與顧問面板（讓深度模擬可讀）
版本：v3.6 ｜ 難度：★★ ｜ 前置：T129、T130 ｜ 建議模型：Sonnet

## 目標
把散落的模擬場統一成一組小地圖疊加視圖 + 一個「城市顧問」面板。TheoTown 有多種資料視圖與顧問；本作已有 POL/LAND/財富但視圖切換零散、缺顧問彙總。讓玩家一眼看懂城市問題。

## 定位錨
- `drawMini`/`miniView`（T110/T130 已有普通/污染/地價切換）
- `showStats`（統計面板）、`checkHints`（提示系統，T94）
- 各場：COV 家族、POL、LAND、crime、congestion load、財富

## 允許觸碰
- 小地圖視圖切換擴為循環多檔（普通/地價/污染/壅堵/犯罪/服務覆蓋），按鈕循環＋當前視圖標籤；各視圖用既有場數據上色（不新增模擬）。
- `showStats` 新增「🧭 城市顧問」區塊：掃描全城指標（最缺的服務、最嚴重的污染/犯罪/壅堵熱點、RCI 最緊缺類別、財政趨勢），輸出排序後的 3-5 條建議（複用 hints 文案風格），最嚴重項標紅。
- 顧問建議帶座標時可點擊跳鏡頭（複用小地圖跳轉）。

## 硬性不變量
- 純資訊層：不改任何模擬公式、不改存檔格式。
- 視圖切換與顧問面板只在對應 UI 開啟時計算（不加每幀成本）。
- 無城市（空圖）時顧問面板不崩潰、給合理空態文案。

## 本卡驗收
1. 三件套照常。
2. 六種小地圖視圖逐一切換，色彩與對應場數據吻合（抽樣比對）；標籤正確。
3. 顧問面板：人為製造污染熱點/服務缺口→對應建議出現且排序合理、最嚴重標紅；帶座標建議點擊跳轉正確。
4. 空圖不崩潰；零 console 錯誤。
