# T343d — 科技樹畫布清晰化（修 v11.5 玩家回報「像素很糊」）

狀態：**已完成（v11.6）。業主直令（附截圖）⇒ Claude 出卡＋施工＋自審。**

## 根因（實測）

T343b 的樹圖 canvas 後備存儲寫死 640×420，CSS 卻是 `width:100%`＋DPR ——
玩家環境（面板 ≈858 CSS px、Windows 顯示縮放 DPR≈1.5）實體拉伸 ≈2 倍，文字/框線全糊。
出卡缺陷：卡面決策 5 自己寫死了 640×420。

## 修法

邏輯空間恆定 640×420（pan/clamp/命中/focus 全部不變），後備存儲＝`CSS寬×DPR`
（`techScale343`，上限 3×），繪製經 `setTransform(q,0,0,q,0,0)` 放大；
`techPoint343` 一律映射到邏輯空間（與後備解析度脫鉤，否則高 DPR 點選錯位）。
Node 端（DPR=1、無 gBCR）q=1 ⇒ 與原行為逐位一致，T343b/c 全部既有測試零改動通過。

## 驗證

- 破壞性三案（判紅含 exit code，依 COLLAB 新規）：回退固定 640→紅；命中映射改回 cv.width→紅；上限 3 改 99→紅。
- 瀏覽器機制證明：DPR 覆寫 2 → 後備 1296×851（2.02×），還原→648；648 CSS 視口後備 648×425。
- 閘門：套件全綠、verify ALL GREEN（11.6 三處同步）、seed pins 原值。

## 誠實邊界

我的驗證環境 DPR=1 無法目視重現玩家原始糊度，清晰性由「後備 ≥ CSS×DPR」機制保證；
若玩家更新後仍覺得糊，優先查 `:has()` 支援度與面板實寬回報。
