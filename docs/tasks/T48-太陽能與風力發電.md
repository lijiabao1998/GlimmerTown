# T48 太陽能與風力發電

## 目標
加入再生能源設施，提供替代電力來源，減少對傳統電廠的依賴並降低污染懲罰。

## 需求

### 1. 常數與工具列
- `COST.solar=450`、`COST.wind=600`。
- `KNAME[25]='太陽能電廠'`、`KNAME[26]='風力電廠'`。
- TOOLS 插入 `solar`、`wind`。

### 2. 建造邏輯
- 太陽能：僅草地（t===2）可放，2×2 多格建築。
- 風力：陸地或高地（t.el===1）可放，單點建築，不可相鄰（至少間隔 2 格）。

### 3. 模擬邏擬
- 太陽能：每座供電 30 棟，維護 $1/天，無污染；夜間供電量減半（需搭配儲能或傳統電廠）。
- 風力：每座供電 40 棟，維護 $1.5/天，無污染；冬季與雨天發電量 ×1.3。
- 再生能源不計入傳統電廠 `PLANT_CAP`，獨立計算容量。
- 電廠附近住宅幸福懲罰：傳統電廠 -0.18，太陽能 -0.05，風力 -0.08。

### 4. 視覺
- `buildSprites` 追加：
  - `SPR.bld['25_1_v']`：太陽能板陣列。
  - `SPR.bld['26_1_v']`：風力發電機（3 變體，葉片可旋轉動畫）。

### 5. UI
- `inspect()` 顯示供電量與維護費。
- `showStats()` 加再生能源計數與供電量。

### 6. 存檔
- `bl` 存建築；太陽能 2×2 用 sz=2。

### 7. 測試
- `test_t48.js`：驗證供電量、夜間減半、風力季節加成、存讀檔。

## 驗收標準
- [ ] 太陽能/風力可建，獨立供電。
- [ ] 夜間與季節影響發電量。
- [ ] 測試通過。
