# T115 沙盒模式與難度分檔
版本：v3.2 ｜ 難度：★ ｜ 前置：無 ｜ 建議模型：Sonnet

## 目標
開場加難度選擇：簡單/標準/困難（起始資金 5000/3000/1500＋災害機率 ×0.5/×1/×1.5）＋沙盒檔（建造免費、無維護費、忽略資金，但保留電/水/服務需求與模擬全貌），沙盒開放災害手動觸發鈕。

## 定位錨
開始畫面（#start 按鈕區，挑戰按鈕先例）；begin()；placeCost 扣款處；upkeep 結算處；GV.quake/flood 先例。

## 允許觸碰
start 畫面難度列（四鈕，選中高亮，預設標準）；全域 `diff`（0-3）入存檔**可選欄位** `df`（舊檔視為標準）；扣款與維護費處：沙盒短路為 0；災害機率乘難度倍率；沙盒時統計面板顯示「沙盒」徽記＋三顆手動災害鈕（呼叫現有 GV 鉤子路徑）；**沙盒單向**：存檔一旦是沙盒永遠是沙盒（防刷錢），非沙盒檔不可轉入。

## 硬性不變量
標準難度行為與改動前完全一致（回歸基準）；存檔只加可選欄位；挑戰模式與難度互斥時以挑戰為準。

## 本卡驗收
1. 三件套照常；舊檔按「標準」載入。
2. 三檔起始資金正確；沙盒建造不扣錢、無維護、災害鈕可用且能觸發；沙盒存檔重載仍是沙盒；標準檔同種子 30 天與基準 GV 序列一致。
3. 零 console 錯誤。
