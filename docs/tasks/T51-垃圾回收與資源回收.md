# T51 垃圾回收與資源回收

## 目標
延續垃圾場系統，加入資源回收中心與垃圾車路線，降低垃圾對幸福的衝擊並提供回收收入。

## 需求

### 1. 常數與工具列
- `COST.recycling=350`。
- `KNAME[29]='資源回收中心'`。
- TOOLS 插入 `recycling`。

### 2. 建造邏輯
- 單點建築，陸地、非道路、無建築。

### 3. 模擬邏擬
- 資源回收中心維護 $2/天，就業 4/座。
- 每座處理 30 棟建築的垃圾，並將其中 30% 轉化為回收收入（每單位垃圾 $0.1）。
- 半徑 8 內垃圾場超載懲罰減半。
- 垃圾車動畫：每座回收中心生成 1 輛垃圾車，沿道路巡邏。

### 4. 視覺
- `buildSprites` 追加 `SPR.bld['29_1_v']`：回收中心 sprite（三色回收桶＋分類輸送帶）。
- `SPR.recycleTruck`：垃圾車 sprite。

### 5. UI
- `inspect()`：「♻️ 資源回收中心｜處理30棟｜回收收入…｜就業4｜維護$2/天」。

### 6. 存檔
- 無新欄位。

### 7. 測試
- `test_t51.js`：驗證回收收入、垃圾懲罰減半、存讀檔。

## 驗收標準
- [ ] 回收中心可建，產生回收收入。
- [ ] 垃圾車動畫正確。
- [ ] 測試通過。
