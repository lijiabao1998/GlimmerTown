# T524 科學頁篩選（5.7 屏的牆，給玩家一把梳子）

**日期**：2026-08-18　**發卡**：Claude（業主授權：自己玩→出卡→施工→合併）

## 0. 玩測量到的問題

📚 城市科學頁：**4,574 px（≈5.7 屏）、7,318 字、53 條研究、無搜尋、無篩選、無分類**。
玩家想知道「我開了哪些政策」或「跟交通有關的有哪些」，只能從頭捲到尾。
（對照：CS2 只有 12 個政策，社群仍普遍反映找不到。）

## 1. 先掃現況

- 分組真相源**早就有**：`SCI_GRP514` 六組（住房與土地／勞動與機會／交通與可達／
  環境與健康／產業與財政／社會與文化），是 T514 指揮台在用的。
- 但它只涵蓋 **51/53**：`oppAtlas455`（機會地圖）與 `mobility456`（世代流動）**不在任何組**
  ——它們沒有 `polKey`（一個是唯讀圖層、一個是常駐機制）。
  **不能為了湊分組把它們塞進 `SCI_GRP514`**：那張表同時驅動指揮台的政策卡片，
  塞進去會讓非政策條目長出開關。

## 2. 落地

科學頁頂部加一列篩選鈕，**全部由 `SCI_GRP514` 導出**＋一個機械化回退桶：

- `全部（53）`／六個分組鈕（各帶條目數）／`🧭 唯讀與常駐`（回退桶＝不屬於任何組者）
- `✅ 只看已啟用`（玩家最常問的那個問題）

狀態 `sciFilter524` 預設 `'all'`、不進存檔、零模擬（顧問/tick 完全不碰）。

## 3. 驗收計畫

- **G1 完備性（本卡靈魂）**：53 條研究每一條都必須恰好被一個篩選涵蓋
  （分組 51 條＋回退桶 2 條＝53，無孤兒無重複）——機械複算，未來往 SCI451 加條目
  而忘了分組時，它會落進回退桶而不是消失。
- G2 篩選鈕與組名由 `SCI_GRP514` 導出（不手寫）。
- G3 行為：選「交通與可達」後頁面只剩該組條目數；「只看已啟用」在零政策時顯示 0 條、
  開一個政策後顯示 1 條。
- G4 六哨兵位元恆等。
- 紅源三案：回退桶拿掉（兩條唯讀研究從頁面消失）／組名手寫（與表脫鉤）／篩選漏算計數。
