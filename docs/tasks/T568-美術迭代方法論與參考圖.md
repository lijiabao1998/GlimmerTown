## 2. 標準迭代環（每張美術卡必走的九步）

1. **進場探針**：對現行 sprite/繪製鏈做像素與結構實測（逐行寬度剖面、顏色表、掛點）。
   禁止憑印象出卡——T567 的牆帶偵測參數（±3 抖動、≥4 行下限）全部來自 108 鍵實測剖面。
2. **出卡**：病灶（附樣張證據）／手法／白名單族宣告／驗收計畫（G 釘清單）／回滾路徑。
3. **施工**：**烘焙加蓋優先**（boot 跑一次、零 draw-time 成本、T523 預算天然免疫）；
   必須 draw-time 的件（要隨鄰居/季節/縮放變的）先過預算戰（T565 的 8289→7474 是範例）。
4. **守衛**：行為釘為主（真造境或合成台架計數/像素斷言），原文釘為輔（掛點互鎖、零亂數掃）；
   舊鏈釘被新環節插入時**同步收緊為完整新鏈**（T563 G3b→T565→T567 已演習兩次）。
5. **紅源演習**：每卡至少兩案——拔掛載案＋主段合法 no-op 案；「車位本體：位元備份→突變→
   跑→還原（sha256 驗位元）」，整倉複本在暫存區會逾時（實錘兩次）。
6. **樣張 A/B**：同種子同造境雙跑（對照＝部署現版另起 origin）、visT 凍同一相位、
   像素差分定位＋全解析度裁決；逐件帶開關常數，不理想者當場砍或回調。
7. **指紋審計**：fp_snapshot 差異逐鍵對白名單，新增 0／移除 0／族外 0 才算過。
8. **收束鏈**：verify.py → bump → arch_map --fix → ARCH.md 第 3 行實數 → fp 基線重建 → 套件終跑。
9. **卡面 §5 如實記**：落點行號（核實過的真值，不許寫猜的）、逐件裁決、紅源實得值、
   失敗與誤判（T566 的 .99h 筆誤、T567 的行號修正都進了卡）。

## 4. 波次路標（建議序；每波獨立成卡、獨立裁決去留，不打包）
