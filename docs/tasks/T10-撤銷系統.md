# T10 撤銷系統（Ctrl+Z / ↩️）
版本：v1.2 ｜ 難度：★★★ ｜ 前置：T08 ｜ 建議模型：Opus

## 目標
建造/拆除可撤銷：一次手勢（一筆畫、一次框選）＝一步，最多 40 步，撤銷退還花費。

## 允許觸碰
第 4 節 doPlace 兩處掛鉤；第 8 節手勢開閉點（pointerdown/endPointer/commitRect）；第 10 節新增 undo()＋HUD 按鈕＋快捷鍵；HTML 加一顆按鈕。

## 設計（按此實作）
1. 全域：`let undoStack=[],undoGroup=null;`（第 8 節宣告區）。
2. 快照掛鉤（doPlace 內，**唯一資料變更點**）：
   - 定位錨 `  const zoneOf={zr:1,zc:2,zi:3};` → 其前插入：
     ```js
     if(undoGroup&&!undoGroup.seen[idx(x,y)]){
       undoGroup.seen[idx(x,y)]=1;
       undoGroup.snaps.push({i:idx(x,y),s:JSON.stringify(t)});
     }
     ```
   - 定位錨 `  money-=cost;` → 其後插入 `  if(undoGroup)undoGroup.spent+=cost;`
3. 手勢分組：
   - `const openUndo=()=>{undoGroup={snaps:[],seen:{},spent:0};};`
   - `const closeUndo=()=>{if(undoGroup&&undoGroup.snaps.length){undoStack.push(undoGroup);if(undoStack.length>40)undoStack.shift();}undoGroup=null;};`
   - pointerdown 的 paint 分支（`const m0=money;` 之前）呼叫 `openUndo();`
   - pointerdown 的 isRectTool 分支不開（框選在 commitRect 才動資料）。
   - `commitRect()` 的第二個施工迴圈之前 `openUndo();`、`if(done){sBuild();}` 之前 `closeUndo();`
   - `endPointer` 的 `if(pointers.size===0){` 內呼叫 `closeUndo();`
   - 進入雙指 pinch 的分支（已有 firstPaint 撤銷）追加 `undoGroup=null;`（放棄本手勢分組，避免與 firstPaint 退款重複）。
4. `undo()`（第 10 節）：
   ```js
   function undo(){
     const g2=undoStack.pop();
     if(!g2){toast('沒有可撤銷的操作');return;}
     for(const sn of g2.snaps){
       tiles[sn.i]=JSON.parse(sn.s);
       const x=sn.i%N,y=(sn.i/N)|0;
       recalcMask(x,y);recalcMask(x,y-1);recalcMask(x+1,y);recalcMask(x,y+1);recalcMask(x-1,y);
     }
     money+=g2.spent;
     computePower();
     if(typeof drawMini==='function')drawMini();
     toast('↩️ 已撤銷（退還 $'+Math.round(g2.spent)+'）');sTick();
   }
   ```
5. UI：HTML 定位錨 `<button class="hbtn" id="bHelp">❓</button>` → 其後插 `<button class="hbtn" id="bUndo">↩️</button>`；綁定 `$('#bUndo').onclick=()=>undo();`；鍵盤（現有 keydown 監聽內）：`if((e.ctrlKey||e.metaKey)&&e.key==='z'){e.preventDefault();undo();}`
6. 清空點：`newWorld()` 與 `load()` 成功路徑各加 `undoStack.length=0;undoGroup=null;`

## 硬性不變量
- GV.place 不進撤銷棧（undoGroup 僅手勢期間非 null，GV 呼叫時必為 null——不要另外加鉤）。
- 撤銷只還原格子與金錢，**不**回滾人口/天數（下一 tick 自然重算）。
- 快照還原後 tile 物件必須含全部欄位（JSON 快照天然滿足）。

## 本卡驗收
1. 畫一條 10 格路（$150）→ Ctrl+Z → 路消失、錢退還、toast 顯示金額。
2. 框選 3×3 住宅區 → ↩️ 按鈕 → 分區消失退款。
3. 連續撤銷到空 → toast「沒有可撤銷的操作」，不崩。
4. `GV.place('road',...)` 後 Ctrl+Z → 不會撤銷 GV 放的（棧為空提示）。
5. 撤銷一片已長出建築的舊分區操作 → 建築同格恢復為快照狀態、不報錯（可接受）。
6. VERIFY.md 全套。
