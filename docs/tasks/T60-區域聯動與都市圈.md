# T60 區域聯動與都市圈

## 目標
讓多個存檔槽之間可產生區域聯動，形成都市圈概念，提供跨城收入與挑戰。

## 需求

### 1. 都市圈概念
- 當槽 1、2、3 都有存檔時，遊戲自動視為「都市圈」。
- 每個存檔槽的城市名稱、人口、星等會影響其他槽的遊戲：
  - 鄰近槽城市人口越高，本槽商業稅收 ×1.02～1.1（區域市場）。
  - 鄰近槽有機場/港口，本槽觀光收入 +10%。
  - 鄰近槽犯罪率高，本槽犯罪率 +5%。

### 2. 跨城通勤
- 若鄰近槽有鐵路/機場連接（存檔中記錄 `hasRailLink`/`hasAirLink`），本槽住宅幸福 +0.02。

### 3. UI
- `showStats()` 顯示「都市圈」區塊，列出三槽城市名與人口。
- `showSlots()` 顯示槽位間的聯動摘要。

### 4. 存檔
- 每個存檔新增 `region:{pop,star,hasAir,hasPort,crimeRate}` 摘要，用於跨槽計算。
- 載入時讀取其他槽摘要，但不載入完整地圖。

### 5. 測試
- `test_t60.js`：驗證都市圈加成計算、跨槽摘要讀取、存讀檔。
