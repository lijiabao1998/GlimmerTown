## 實測(施工後補;三版探針的方法學全記錄)

**v1 教訓**:終點經濟量(pop/money)是混沌噪音——vri 是全域共享流,B 臂警車多消耗
Math.random 就位移了所有車輛的流,壅堵回饋走上完全不同軌跡,三種子方向互相矛盾。
(跑檯記憶「終點差是混沌噪音」再次驗明。)改用抗混沌指標:**單案平均壽命**
(犯罪日積分÷新發案數,率正規化)與**廢棄日積分**。

**v2 教訓(更大發現)**:探針每天 12 幀 × dt上限0.05 = 0.6 車輛秒/天,但 `DAYLEN=0.9` 秒/天
⇒ **服務車輛用真實時間移動,不隨遊戲速度縮放**。1× 速車輛每天 0.9 秒(2.4 格/秒 ≈ 2.2 格/天),
5× 速只剩 0.18 秒(0.43 格/天)。跨城 60 格在 5× 下要 140 天——**整個服務車層在高速遊玩下
近乎凍結,此為全車隊(消防/救護/警察/垃圾)既有結構限制,非本卡引入**。

**v3 定案**(800 天,幀預算校準:18 幀/天=1× 速、4 幀/天≈5× 速;Math.random 種子化 LCG):

| 檔位 | seed | 壽命 A→B(天) | 廢棄日 A→B |
|---|---|---|---|
| 1× | 301 | 31.0 → **27.6** | 0 → 0 |
| 1× | 22 | 30.1 → **28.4** | 0 → 0 |
| 1× | 7(窮鎮) | 52.4 → **29.6**(−44%) | 1861 → **671**(−64%) |
| 5× | 301 | 30.5 → 31.6(噪音內) | — |

**結論**:①機制修復成立(功能案:40 格 Manhattan 第 39 幀到場清案;舊過濾=永不出車);
②1× 速下方向三種子一致,健康城小勝、**窮鎮大勝**(積案清運對缺覆蓋的城最有價值,
正是弱開局玩家);③**5× 速下零效果**——吞吐被「真實時間移動」卡死,車速才是下一刀:
**建議下一卡=服務車輛移動改遊戲時間縮放(dt×速度因子)或派遣搬 tick**
(T402 早已標記的「決定性派遣+固定步長」方向,現在有了定量開場白)。
