# T133 城市等級階梯（後期進度曲線）
版本：v3.7 ｜ 難度：★★ ｜ 前置：無 ｜ 建議模型：Sonnet

## 目標
城市等級 ≥24 級：由累積城市點數（人口＋幸福＋服務覆蓋）晉升，每級解鎖一項加成或建築、給長線目標與節奏。對標 TheoTown 65 級 rank 的進度感（本作僅 8 里程碑）。

## 定位錨
- 里程碑 MILES/成就系統、`cityStar`/`bestStar` 評分先例
- TOOLS 解鎖判定、存檔可選欄位

## 允許觸碰
- 新增 `RANKS` 陣列（24-30 級）：每級 `{name,threshold,unlock?}`；`cityPoints` = f(pop, cityHappy, 服務覆蓋率) 於 tick 每日重算。
- 當前等級存檔可選欄位 `rk`；升級 toast（含新解鎖說明）＋等級面板（進度條，複用里程碑 UI）。
- 解鎖**只 gate 新建築的放置面板可見性**（後續 MU 波的大型文化/研究/megaproject 建築鎖在對應等級後）；**既有全部建築保持解鎖，不 re-lock**——避免懲罰老玩家。
- `GV.rank()`/`GV.cityPoints()` 鉤子。

## 硬性不變量
- 舊檔載入時由當前城市狀態即時算出等級（不因缺欄位降級、已建建築絕不消失/降級）。
- 等級解鎖只影響「未來可放的新建築」，既有 34 種建築在任何等級都可放（本卡不新增被鎖建築，只搭框架＋預留 unlock 掛點）。
- cityPoints 計算不消耗 R()、不影響既有模擬；同種子 30 天經濟序列與基準位元一致。

## 本卡驗收
1. 三件套照常。
2. 養城市→cityPoints 上升→逐級晉升，升級 toast＋面板進度條正確；GV.rank 隨城市規模單調上升。
3. 存讀檔往返等級連續；舊檔（無 rk）載入算出合理等級。
4. 既有建築在低等級仍全部可放（不被誤鎖）；同種子位元回歸。
