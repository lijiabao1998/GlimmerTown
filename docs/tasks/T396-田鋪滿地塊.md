# T396 — 田鋪滿地塊(讓 T395 的跨格連續真正兌現;農業美術三期 R2)

T395 已把壟行與株行做到與等距格公度(數學連續)。但離線樣張證實:**現況田半寬 hw=40
只佔 2×2 footprint 約 62%,田塊之間有大間隙,連續性在視覺上兌現不了**。本卡讓田鋪滿。

## 樣張證據(T395 附;離線渲染器抽 index.html 的 field/plantGrid 原文 eval)

- hw=64(鋪滿):**新版連成一片**、壟與株行跨塊對齊;舊版被高對比田埂切成 9 塊且塊間錯位。
- hw=40(現況):九塊獨立小田,間隙比田還寬——像九個菜園,不像一片農場。

## 設計

1. **F22 十六筆 [ax,ay,hw,hh] 由 [68,144,40,20] 改為 [68,132,64,32]**。
   - 2×2 footprint 在 k22 畫布(136×150)上是 |x−68|/64 + |y−116|/32 ≤ 1,中心 (68,116)。
     舊 ay=144 使田心 cy=128＝**最前一格的中心**(T380 慣例),只覆蓋約一格;
     改 ay=132 使 cy=116＝footprint 真中心,田才可能鋪滿整個 2×2。
   - **hw 必須恰為 64 而非 60**:離線預覽證實 hw=60 時九塊田之間仍留 8px 綠縫,
     仍讀作九塊;hw=64 時田菱形與 footprint 菱形重合,相鄰田零縫接合。
   - clipBase 邊界核算:界為 `y = 148 − |px−68|×0.5`。x=68 處田最低 148(僅該點被
     `rowB<=0` 清 1px,可忽略);x=4/132 處田僅到 y=116,界為 116/118 ⇒ 不溢出。
   - 「草叢越界」(D 項)因此改為畫在田的最外圈像素上(草長進田裡),而非田外留空。
2. **自帶美術的處置(T379 回退的真因)**:T378 曾放大到 52/26,被 T379 回退,理由是
   蓋掉 base 自帶穀倉/溫室/乾草捆 57~100%。**關鍵事實**:T276 農莊套件(農舍/紅穀倉/
   筒倉/木圍籬/乾草捆/拖拉機)是在 T279 田層【之後】stamp 的,壓在田上、不受放大影響;
   被蓋掉的只有 base 自帶那組。故本卡的裁決是:**接受 base 自帶組被田覆蓋,由 T276 套件
   提供建築細節**——這同時消除了「自帶穀倉 + 套件穀倉」的重複感。須以樣張逐變體確認
   T276 套件仍完整可見,任一變體出現「田上空無一物」即退修。
3. **株距密度**:fsc395 現以 hw/30 分級,fsc395(64)=2 ⇒ 株距 8px,放大後反而比現況稀疏
   (離線預覽已證)。改分母為 hw/64 ⇒ hw≤64 恆回 s=1(4px 密植),維持 T279b
   「密植成行」原意;G3 守衛(只回 8 的因數)不受影響。
4. **邊緣柔化(D)**:田最外圈之外撒少量草色像素,`streetHash` 決定性、掛畫質檔位、
   `lodFar` 短路——讓田與草地的交界不是一條硬邊。

100% 兌現。成本:屬新建築(KNAME/COST/工具列/AI wants/指南全套),超出美術卡範圍。
