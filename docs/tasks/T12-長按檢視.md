# T12 觸控長按檢視
版本：v1.2 ｜ 難度：★★ ｜ 前置：T08 ｜ 建議模型：Sonnet

## 目標
框選類工具（分區/公園/拆除）下，按住不動 550ms＝取消框選並開啟該格檢視面板。手機上不用切回檢視工具就能查建築。

## 允許觸碰
第 8 節：全域宣告行、pointerdown 的 isRectTool 分支、pointermove 的 moved 判定處、endPointer。

## 禁區
paint 工具（road/plant）不加長按（按下即放置，語義衝突）；pan 工具本來就是點擊檢視，不動。

## 實作步驟
1. 定位錨 `let panBase=null,pinchBase=null,paintLast=null,downInfo=null,firstPaint=null,dozeArm=null;`
   → 行尾加 `let longPressT=null;`（獨立一行宣告亦可）
2. pointerdown 內定位錨：
```js
  }else if(isRectTool(tool)){
    rect.on=true;rect.x0=rect.x1=x;rect.y0=rect.y1=y;
  }else{
```
   替換為：
```js
  }else if(isRectTool(tool)){
    rect.on=true;rect.x0=rect.x1=x;rect.y0=rect.y1=y;
    clearTimeout(longPressT);
    longPressT=setTimeout(()=>{           // 長按＝取消框選、改為檢視
      if(rect.on&&downInfo&&!downInfo.moved){
        rect.on=false;paintLast=null;
        inspect(x,y);sTick();
      }
    },550);
  }else{
```
3. pointermove 內定位錨 `  if(downInfo&&Math.hypot(e.clientX-downInfo.x,e.clientY-downInfo.y)>6)downInfo.moved=true;`
   → 替換為：
```js
  if(downInfo&&Math.hypot(e.clientX-downInfo.x,e.clientY-downInfo.y)>6){
    downInfo.moved=true;
    clearTimeout(longPressT);
  }
```
4. endPointer 內定位錨 `  if(pointers.size===0){` → 該行之後加一行 `    clearTimeout(longPressT);`
