# T118 暴亂事件（社會型災害）
版本：v3.3 ｜ 難度：★★ ｜ 前置：T116 ｜ 建議模型：Sonnet

## 目標
第六種災害：暴亂——幸福 < 閾值且高犯罪的住宅群觸發，封鎖鄰接道路（車速歸零、車輛繞行），警局覆蓋可自然平息，或付一次性鎮壓費（$200）立即解除。

## 定位錨
犯罪系統（crime/COV.police）；幸福值；道路車速；T116 災害結構；inspect。

## 允許觸碰
觸發條件：cityHappy<0.3 且存在 crime 高的住宅簇（複用既有犯罪場）；暴亂狀態＝受影響住宅格集合＋剩餘天數（**存檔可選欄位** riot）；受影響格鄰接道路車輛不通行（車輛尋路/速度處打標）；受影響住宅停稅收；警局覆蓋格每日高機率自愈；統計面板出現「鎮壓 $200」鈕全體解除；暴亂格繪製火把/煙效果（複用既有煙粒）；GV.riot() 鉤子＋沙盒鈕；通知帶座標。

## 硬性不變量
存檔只加可選欄位；觸發走種子流；幸福高時永不觸發（500 天統計 0）；解除後道路/稅收完全恢復。

## 本卡驗收
1. 三件套照常；舊檔正常。
2. GV 構造低幸福高犯罪→暴亂觸發；封路生效（車數/通行驗證）；警局覆蓋自愈；鎮壓鈕立即全解＋扣 $200；存讀檔往返暴亂狀態保持。
3. 正常城市 500 天 0 觸發；解除後稅收恢復與暴亂前一致。
