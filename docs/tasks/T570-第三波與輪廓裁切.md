## 1. 手法：`buildSpritesS13()`（S12 同構骨架，四件）

1. **輪廓裁切（CLIP）**：全 SPR.bld 鍵（豁免族外）按 v3 判準把容差外 opaque 像素 alpha 清 0
   （帶內超 allow+3、below 超 ay+3；**垂直區不裁**＝塔尖天線豁免）。
   **win563 冬側版同步裁**（同幾何同判準）——否則冬季輪廓回歸。night 畫布同步裁
   （夜燈不得亮在被裁區）。容差內的 1-3px 描邊/尖端自然保留。
2. **女兒牆環線（PARAPET）**：`[123]_[23]_*` 鍵（lv2/3）平頂偵測（頂緣同 y 連續 ≥8 欄）→
   頂緣列壓暗 −20 成環線、其下一行提亮 +8 作頂面反光。
3. **前庭灌木叢（SHRUB）**：k1 鍵 plate 帶前緣左右 1/4 處各一團 3×2 深淺綠叢；
   位置由 key 字串雜湊決定（**零 R()**，同鍵恆定）。
4. **屋頂瓦紋（TILE）**：坡頂族（非平頂）屋頂段每隔 3 行整行壓暗 −8——幅度保守起步，
   **樣張先證不髒再上**（T568 原文），髒即砍件。

- 掛載：`buildSpritesS12();buildSpritesS13();` 雙開機路徑；T563 G3b 鏈釘再收緊；
  `__t570BakeCount/__t570Keys/__t570ClipPx` 計數釘；`__t570Proc` 台架橋。
- fp 白名單：**CLIP 觸鍵清單**（審計 310 鍵集合內）＋PARAPET/TILE 的 `[123]` 族
  ＋SHRUB 的 k1 族＋對應 win563 鍵——落筆鍵由 `__t570Keys` 記錄、與 fp diff 逐鍵對帳，
  帳不平＝紅。
