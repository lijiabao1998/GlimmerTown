### 5.2 G1 從寫下來的第一刻就是空跑的假綠——紅源當場抓到

紅源①（在徽記 pass 之後多生成一個 `SPR.bld` 鍵、不加進 parity 清單）**完全沒紅**。

原因：我在**剝乾淨的原始碼**上配 `SPR.bld\['([0-9_]+)'\]=`。
剝除器的工作就是把字串內容換成空白 ⇒ 那個正則永遠 0 命中 ⇒ `explicit446` 恆為空 ⇒
`missing446.length === 0` 恆真。**這條守衛沒有在守任何東西。**

**同一個病 T441 G2 踩過一次**，當時的正解是
「**位置由剝除器（保證那是程式碼）、內容由原文（保證讀得到）**」。這裡照抄，
並另加 **G1a**：掃到的賦值筆數不得少於 4——讓它下次壞掉時自己喊，而不是安靜地全綠。

修好之後紅源①立刻點名 `["199_1_0"]`。
