# T137 災害擴充至 10+ 種（皆因果觸發）
版本：v3.8 ｜ 難度：★★ ｜ 前置：T136（季節性災害用 season）｜ 建議模型：Sonnet

## 目標
災害 6→10+：新增瘟疫、乾旱、暴風雪/沙暴、工業洩漏，皆因果觸發（服務不足/環境/季節）而非隨機純視覺。延續本作既有因果設計。

## 定位錨
- 災害結構（T116-118：tornado/crater/riot 全域＋tick 觸發＋disastersOn 開關＋DIFF_HAZ 倍率＋GV 鉤子＋沙盒鈕）
- 診所/醫院覆蓋（COV）、供水系統、火險、工業起火、season（T136）

## 允許觸碰
- **瘟疫**：高密度＋低診所覆蓋住宅簇間蔓延（複用犯罪簇掃描手法），感染格降幸福/產能，隔離工具或醫院覆蓋平息；存檔可選欄位 `plague`。
- **乾旱**：夏季低機率，一季內壓低供水上限＋火險倍率×N；季末自動解除；運行時狀態。
- **暴風雪/沙暴**：冬/特定季，全屏視覺＋癱瘓路段車速（複用壅堵 load 置頂或車速歸零）；運行時狀態。
- **工業洩漏**：工業起火時觸發，該格 POL 尖峰＋持續數日（複用 POL 場＋隕石坑持續危害樣板）。
- 各接 disastersOn＋DIFF_HAZ；GV.plague/drought/blizzard/leak 鉤子；沙盒災害鈕列各加一顆；通知帶座標。

## 硬性不變量
- 存檔只加可選欄位（plague 等），運行時狀態不入存檔或讀檔即消散；舊檔正常。
- 各災走種子流 R()；disastersOn=false 時全部 0 觸發（各災 500 天統計驗）。
- 正常城市（服務齊全）因果災害不誤觸發；不動既有 6 災邏輯。
- 新狀態在 newWorld/load 成對重置（鐵律7）。

## 本卡驗收
1. 三件套照常；舊檔正常。
2. GV 逐一觸發四新災：瘟疫蔓延＋醫院/隔離平息；乾旱壓供水＋抬火險＋季末解除；暴風雪癱瘓車速；工業洩漏 POL 尖峰。皆通知帶座標可跳轉。
3. 每災 disastersOn=false 時 500 天 0 觸發；因果條件不滿足時不誤觸發。
4. 災害總數達 10（GV 可枚舉）。
