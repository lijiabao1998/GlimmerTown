## 1. 結構性缺陷（五條，皆有程式碼佐證）

1. **模式選擇散落三處**：開拓新地圖在頂部主鍵、戰役/編輯器在右欄 extras、挑戰在最底獨立 section。
   四者是同一類問題「我要開哪一種局」，卻分屬三個容器、三個層級。
2. **一個容器裝兩件事**：`.startConfig515` ＝ 難度（這一局的參數）＋ 快速設定（這台機器的口味），
   只用一行 10px 小標題隔開。
3. **規則沒跟上元件**：桌面 line 366 寫死 `repeat(5,minmax(0,1fr))`，而 `grid.appendChild` 實際掛了
   **6 顆**晶片（`ds/ri/q/ms/bg/nc`——夜景是後加的）。**6 的因數只有 6/3/2/1，寫 5 必留洞**，
   這條規則是「元件變了、規則沒跟」的化石。
4. **`.help` 三行混裝三種資訊**：操作鍵位／上手步驟／機制說明，同字級同顏色擠在一起。
5. **繼續 vs 新地圖無主次**：兩顆同尺寸、同綠、同 `startGlow` 動畫。

**最終結構 ＝ 勝案的容器骨架 ＋ 落選案的資訊軸與六項具體做法**（見§3）。

### 評審抓到、我原本會踩的地雷

`#start .startPrimary button`（line 318）與 `#start .startMore button`（line 325）**特異度同為 (1,1,1)**，
而 325 在原文更後面故獲勝。把 `#bNewGame` 搬進 `.startMore` 轄區後若無覆寫，它會**無聲變成 13px 小鈕**、
與難度鍵同大、主次反轉——而 headless 與 fake DOM 都量不到，只有真瀏覽器看得見。
處方：`#start .startConfig515>#bNewGame{…}` ＝ (2,1,0) 穩壓 (1,1,1)。

**難度為什麼貼著新地圖**：`begin()` 只有 `#bNewGame` 這條吃 `DIFF_MONEY[diff]`；戰役與挑戰強制標準、

**視覺層級五階**（不新增任何色相，只重新分派既有兩個角色）：
`#bContinue`（琥珀＋唯一動畫）→ `#bNewGame`（綠、大、無動畫，靠形狀差而非亮度）→ 難度四鍵（不動）→

**永不與可點物同亮度＝「這行不能點」的唯一視覺契約**。

## 4. 跟版聲明

### 必改（三條，理由入卡）
- **T515 G2**：`config515.appendChild(grid)` → `prefs551.appendChild(grid)`，並補釘 `setLabel`。
  判準由「難度與偏好同屬設定」改為「**難度是這一局的參數、偏好是這台機器的口味**」。
- **T515 G3**：刪兩條子句（`>.startChallenge515{grid-column:1/-1}` 巢狀後永久不匹配＝死規則；
  `.startChallenges515` 桌面三欄在 255px 窄欄內會把挑戰標籤擠成三行）；
  新增 `>.startPrefs551{grid-column:1/-1}`。CSS 端同步刪除對應規則——**不留死規則**。
- **T515 G1（加嚴，不是放寬）**：除原本三 role 順序外，另釘
  (a)`#bNewGame` 在 config section 內、(b)`#bContinue` 在 `.startPrimary` 內且該容器**不在** `#startMore` 內、
  (c)`#bEditorMode` 與 `#bCampaign` 同在 `.startAltRow515`、(d)challenge 巢狀在 extras 內。
  沒有 (a)(b)，下一張卡可以無聲把難度搬回繼續鈕旁邊，本案的分類理由就白寫了。

### 新釘（三條，防靜默壞版）
- `#start .startConfig515>#bNewGame{…}` 必須在場（特異度倒掛，見§2）。
- `.startPrefs551 .settingsGrid` 的 3 欄／6 欄同時在場，且全檔不得再出現 `#start .startConfig515 .settingsGrid`。
  訊息寫明：**欄數只能取晶片數的因數**。
- `#start #diffDesc547{font-size:11px;letter-spacing:0;text-transform:none}`——它在 :22615 以
  `className='startMoreLabel'` 生出，等於把 10px/letter-spacing:3px/uppercase 的**標籤樣式套在一整句中文說明上**。

## 5. 驗收計畫

- **G1（靈魂）結構釘**：四條巢狀關係（見§4 T515 G1 加嚴）逐條斷言。
- **G2 欄數與晶片數綁定**：桌面 6 欄、手機 3 欄同時在場；`repeat(5` 在 settingsGrid 語境絕跡。
- **G3 特異度覆寫在場**（防 13px 靜默壞版）。
- **G4 死規則絕跡**：`.startMore>.startChallenge515` 選擇器不得殘留。
- **G5 事件歸屬**：所有既有 id 與 onclick 由原物件承接（沿用 T515 G2 手法）。
- **G6 零亂數**：開始畫面注入不得消耗亂數流（T515 G6 沿用）。
- **G7 六哨兵位元恆等**（開始畫面不在 tick 路徑）。
- **行為證明**：重跑六視窗量測——晶片零空洞、手機捲動量下降、無水平溢出、主鍵不得小於難度鍵。
- 紅源：①拿掉特異度覆寫 → G3 應紅；②桌面欄數改回 5 → G2 應紅；③把挑戰搬回 startMore 直屬 → G1 應紅。
