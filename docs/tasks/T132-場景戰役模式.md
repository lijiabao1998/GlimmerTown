# T132 場景/任務戰役模式（模式軸單向超越）
版本：v3.7 ｜ 難度：★★★ ｜ 前置：無 ｜ 建議模型：Sonnet

## 目標
結構化戰役：≥8 個目標導向關卡，各含預設地圖種子、起始資金、勝負條件、開場/結局敘事。TheoTown 本體缺結構化戰役——這是研究證據最紮實的單向超越點。

## 定位錨
- 挑戰模式：`challenge` 全域、tick() 挑戰達標評估（bCh1/bCh2/bCh3 開場按鈕、達標 toast+獎金+一次性）
- `begin(fresh)`、`newWorldSeeded`、開始畫面（#start 按鈕區）
- 存檔可選欄位（ach/df/hi/nl 先例）

## 允許觸碰
- 新增 `SCENARIOS` 資料表（≥8 條）：`{id,name,seed,cash,goal:{type,target,byDay},fail:{type,byDay},intro,win,lose}`。目標型別複用並擴充既有挑戰評估（人口/資金/星級/幸福維持/零負債/災後重建/服務覆蓋率…）。
- 開始畫面新增「🎯 戰役」入口 → 場景選單（列 8 關、顯示鎖定/已通關狀態、簡介）；選關 begin() 到該 seed＋cash＋設 `scenario={id,startDay}`。
- tick() 內評估 active scenario 勝負（複用挑戰管線，達標→勝利 toast+標記通關+可選解鎖；失敗→提示可重試）。
- 存檔可選欄位：`sc`（當前場景 id/進度）、`scDone`（已通關 id 集合，跨局持久，落 localStorage 獨立鍵或存檔）。
- 開場/結局敘事 toast（複用通知系統，可帶座標）。

## 硬性不變量
- 存檔只加可選欄位；舊檔無場景＝一般模式，行為與改動前一致。
- **非場景模式（一般/沙盒/挑戰）模擬與改動前逐位元一致**（scenario=null 時零評估開銷、零 R() 影響）。
- 場景模式複用既有系統，不新增模擬公式。
- scenario/scDone 在 newWorld/load 正確處理（鐵律7 成對）。

## 本卡驗收
1. 三件套（node --check / test_fixde 380+ / 瀏覽器零錯誤）。
2. 8 關可選、各目標相異；GV 觸發某關達標→勝利標記＋通關記錄；觸發失敗條件→失敗提示；通關集合存讀檔/跨局持久。
3. 一般模式同種子 30 天位元回歸與基準一致。
4. 敘事 toast 開場/結局正確顯示。
