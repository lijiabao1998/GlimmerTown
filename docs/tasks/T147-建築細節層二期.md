# T147 建築細節層二期（風化、招牌、生活痕跡）
版本：v4.1 ｜ 難度：★★ ｜ 前置：T128（detailPass）｜ 建議模型：Sonnet

## 目標
在 T128 既有屋頂/立面雜件之上再疊一層「生活感與時間感」：建築隨 age 風化（污漬/鏽蝕/苔痕）、店面遮陽棚與霓虹招牌（夜間發光）、低層牆面海報/塗鴉、屋頂菜園/衛星天線/儲水槽變體、陽台雜物與晾衣。密度依等級、財富、年齡三軸調變。

## 定位錨
- T128 `detailPass()`（buildSprites 絕對尾端）、`__noDetail` 開關先例
- `DRAFTS` 幾何（hw/h/roofStyle）、`roofHalfW()`/`wallCol()` 安全範圍推算函式（T128 既有）
- PAL 派生色、night 圖層（'screen' 合成）

## 允許觸碰
- 於 T128 `detailPass()` **之後**新增 `detailPass2()`（同樣絕對尾端、同樣受開關 `__noDetail2` 閘門）：沿用 `roofHalfW()`/`wallCol()` 安全範圍，疊加——
  - **風化層**：依該 draft 的等級/財富推一個「陳舊度」，在牆面隨機（尾端 R()）灑低透明污漬/鏽點/苔痕（貧宅重、富宅輕）
  - **商業招牌**：k=2 立面加遮陽棚＋霓虹字條（night 層發光，色從 SIGNC 派生）
  - **牆面痕跡**：低層加海報/塗鴉小色塊（僅貧/中產、僅 lv1-2）
  - **屋頂二期**：菜園（綠點陣）/衛星天線/儲水槽變體，依 lv 遞增
  - **陽台雜物**：晾衣繩延伸、盆栽、堆放箱
- 財富（T123 `we`）三檔各自密度/色調不同（富=整潔亮色＋屋頂花園，貧=風化重＋雜物多）。

## 硬性不變量
- 絕對尾端、接在 T128 `detailPass()` 之後；`__noDetail2=true` 時全 SPR 鍵 checksum 與改動前**位元一致**。
- 疊加像素**不越出建築剪影**（改動像素全部落在改動前非透明區，逐鍵驗，0 violations）。
- 夜光件同步進 night 圖層；不新增 SPR 頂層鍵（原畫布疊加）。
- 生成耗時增量 <1.5s；存檔格式零變更。

## 本卡驗收
1. 三件套照常。
2. `__noDetail2` 開／關雙態：開＝全鍵 checksum 與基準位元一致；關＝目標鍵 checksum 互異且改動像素 0 violations（不越界）。
3. 抽 10 鍵區域取樣：風化在牆面、招牌在店面、屋頂件在頂部菱形內；夜層霓虹發光存在。
4. 貧/中/富三檔外觀可辨差異（checksum 互異）；生成耗時增量 <1.5s。
