# T32 警察局系統

版本：v2.1 ｜ 難度：★★ ｜ 前置：T31（供水系統）｜ 建議模型：Kimi/DeepSeek

## 目標

新增第三種公共服務建築：警察局。警察局提供治安覆蓋，降低其半徑內犯罪事件的發生率；未受覆蓋的住/商/工建築有機率發生犯罪，短暫降低幸福並產生視覺標記。

## 允許觸碰

- 第 1 節：`COST`、`TOOLS`、`KNAME` 相關常數與全域狀態宣告
- 第 2 節：`buildSprites()` 內警察局 sprite 生成區塊
- 第 3 節：`genWorld()`、`newWorld()` 的地磚初始化（本卡無新增欄位）
- 第 4 節：`canPlace`、`placeCost`、`doPlace`、拆除分支
- 第 5 節：`tick()` 模擬（犯罪事件、幸福修正、經濟計數）
- 第 7 節：`draw()` 物件層／犯罪標記繪製
- 第 8 節：`inspect()`、快捷鍵
- 第 10 節：小地圖
- 第 11 節：`save()` / `load()` 建築列表 `bl`（k=11 零格式變更）

## 禁區

- 不改電力/供水網路
- 不改道路系統（T29）
- 不改核心日夜循環、煙霧粒子系統
- 不改存檔版本號 `data.v`

## 實作步驟

### 1. 常數與工具列

定位錨：
```js
const COST={road:15,bridge:60,zone:8,park:60,plant:550,water:400,wpipe:10,doze:2,fire:400,school:350,dump:300,rdec:25,hwy:45,hwyBridge:180,stad:1200,tree:5,fill:20,bus:80};
```

追加 `police:500`：
```js
const COST={...,bus:80,police:500};
```

`KNAME` 追加 `11:'警察局'`。

`TOOLS` 於 `fire` 後插入 `police`：
```js
  {id:'fire', ic:'🚒', nm:'消防局', pr:'$'+COST.fire},
  {id:'police',ic:'🚓', nm:'警察局', pr:'$'+COST.police},
  {id:'school',ic:'🏫', nm:'學校', pr:'$'+COST.school},
```

快捷鍵追加大寫 `P`（不與小寫 `p`=水管衝突）：
```js
const map={...,'p':'wpipe','P':'police'};
```

### 2. 資料模型

本卡無新增 tile 欄位。犯罪標記使用建築現有 `crime` 欄位（若不存在則新增於 `bld` 物件）。

### 3. 建造邏輯

`canPlace` 於 `fire` 分支後新增：
```js
    case 'police':
      if(t.t!==2&&t.t!==1)return '只能蓋在陸地上';
      if(t.road)return '道路上不能建造';
      if(t.bld)return '已有建築';
      return null;
```

`placeCost` 新增：
```js
    case 'police':c=COST.police;break;
```

`doPlace` 新增：
```js
    case 'police':
      t.bld={k:11,lv:1,v:ri(3),age:0,pw:true,h:1};t.tree=0;t.zone=0;t.deco=0;
      break;
```

拆除分支於 `else if(b.k===10)` 後追加 `else if(b.k===11)`（零邏輯，只為清晰）。

`doPlace` 結尾 computePower/Water 條件不需改（警察局不依賴連通網路）。

### 4. 模擬影響

`tick()` 主建築迴圈於消防局計數附近新增 `policeStations` 計數：
```js
    if(b&&b.k===6)fireStations++;
    if(b&&b.k===11)policeStations++; // 警察局（T32）
```

於火災段之後、經濟段之前新增犯罪段：
```js
  // 犯罪（T32）：未受警察局半徑10覆蓋的 k≤3 建築每天小機率發生犯罪
  let crimeAlert=false;
  for(let i=0;i<N*N;i++){
    const b=tiles[i].bld;
    if(!b||b.k>3||b.crime)continue;
    const x=i%N,y=(i/N)|0;
    if(countNear(x,y,10,tt=>tt.bld&&tt.bld.k===11)>0)continue; // 半徑10內有警察局則受保護
    if(R()<.001*(b.k===2?2:1)*b.lv){ // 商業犯罪率加倍
      b.crime=1;
      if(!crimeAlert){toast('🚓 '+townName+'發生犯罪！點擊受害建築處理','bad');sErr();crimeAlert=true;}
    }
  }
```

犯罪建築在住宅幸福公式中追加懲罰項（與工業/電廠類似）：
```js
      const crime =countNear(x,y,4,tt=>tt.bld&&tt.bld.k<=3&&tt.bld.crime);
      b.h=clamp(...-crime*.05,...);
```

升級條件不變（犯罪本身不阻止升級，但幸福下降間接影響）。

經濟段新增 `policeStations` 計數與維護費：
```js
  let income=0,upkeep=0,...,policeStations=0;
  ...
    else if(b.k===11)policeStations++;
  ...
  upkeep=... +policeStations*4;
  fin={...,upPol:policeStations*4,net:income-upkeep};
```

### 5. 視覺

`buildSprites()` 尾端追加警察局 sprite：72×112，藍白外牆+警徽+門前警車閃燈，夜間頂部藍燈閃爍。

`draw()` 物件層於 `else if(bd.k===10)s=SPR.water;` 後追加：
```js
    else if(bd.k===11)s=SPR.police; // 警察局（T32）
```

犯罪標記繪製：於建築繪製後，對 `b.crime` 建築在螢幕座標疊畫一個小黃色驚嘆號 `!`（或紅色手銬圖示），不進 sprite 表。

### 6. UI

`inspect()`：
- 警察局格：仿消防局樣式，顯示「治安覆蓋半徑 10」「維護費 $4/天」
- 犯罪建築：面板追加「⚠️ 發生犯罪！幸福 -5%（鄰近）」與【處理】按鈕，點擊清除 `b.crime=0` 並 toast「已處理犯罪」
- 普通建築：顯示「治安覆蓋中」或「⚠️ 缺乏治安」

小地圖：警察局格上 `#3a5a9c` 色點。

`showStats()`：統計面板追加「警察局${nPol}」與維護費「🚓 警察局 -${fin.upPol.toFixed(1)}」。

`showHelp()`：追加警察局說明一行。

### 7. 存檔相容

k=11 建築直接沿用現有 `bl` 格式（[i,k,lv,v,age]），零格式變更；`crime` 欄位若存在於 bld，可選存於第 6 位之後，舊檔無則視為 0。

## 本卡驗收

1. 開新地圖，放置警察局，Console 無錯誤。
2. `GV.tile(x,y)` 檢查警察局格 `bld.k=11`；半徑10內住宅犯罪率顯著低於未覆蓋區域。
3. 移除警察局後，原受保護區域一段時間後開始發生犯罪。
4. 犯罪建築的 inspect 面板可點擊【處理】清除犯罪標記。
5. 💾 → 重新整理 → 繼續 → 警察局位置與犯罪標記保留。
6. VERIFY.md 全套通過。
