# T13 火災系統
版本：v1.3 ｜ 難度：★★★ ｜ 前置：v1.2 完成 ｜ 建議模型：Opus

## 目標
建築會小機率起火：燃燒動畫→蔓延→燒毀成焦土。玩家點擊滅火（$30）或等它燒完。城市第一次有「壓力事件」。

## 允許觸碰
第 2 節 buildSprites 末尾（新增火焰 sprite）；第 5 節 tick()（新增火災段）；第 7 節物件層（火焰/焦土繪製）；第 8 節 inspect()（滅火交互）；第 11 節 save/load（可選欄位）；GV 加測試鉤子。

## 行為規格
1. 資料：`t.bld.fire = 0|1..6`（0 不燃，≥1 為已燃天數）；`t.ruin = 0|1` 焦土（建築燒毀後殘留）。
2. 起火（tick 內、升級段之後）：每天對每棟 k≤3 建築擲骰：`p = 0.0005*(b.k===3?3:1)*b.lv`；起火時 `b.fire=1`、金色改紅色 toast「🔥 {townName}發生火災！點擊燃燒的建築滅火」＋sErr（每天最多提示一次）。
3. 燃燒：`b.fire++` 每天；`fire>=5` → 建築移除、`t.ruin=1`、該格 zone 保留；燃燒中：不繳稅、不升級（在稅收/升級處各加 `!b.fire` 條件）。
4. 蔓延：燃燒中建築每天 20% 機率點燃 Chebyshev 1 格內一棟未燃 k≤3 建築。
5. 滅火：pan 工具點擊燃燒建築（inspect 路徑）：面板顯示「🔥 燃燒中」＋一顆【滅火 $30】按鈕（#infoBody 內、addEventListener 綁定），點擊：錢夠→`b.fire=0`、toast、關面板；錢不夠→toast 資金不足。
6. 焦土：畫深灰燒焦地塊（覆蓋在地形上）；不能建造（canPlace 對 ruin 格回「焦土需先清理」，doze 可清、費用照舊 $2 並清 ruin）；分區生長跳過 ruin 格。
7. 視覺：火焰＝2 幀程序化 sprite（橙 #ff9d3c/黃 #ffd45f/紅 #e05252 像素簇，約 20×28，錨點底中），繪製在建築 sprite 之後同格疊加，幀由 `visT*6&1` 切換；夜間把火焰也 push 進 nightSprites（rect 或 img 皆可）發光；燃燒建築的煙改深色（可選）。焦土＝64×32 菱形深灰 #3a3a38 帶碳黑斑點，畫在地形之後（terrain pass，t.ruin 檢查）。
8. 存檔：bl 條目擴為 `[i,k,lv,v,age,fire]`（fire 為 0 可省略——寫入時僅 fire>0 才附加第 6 元素）；load 兼容 5/6 元素。ruin 存為新字串欄位 `rn`（0/1），load 容錯。
9. GV 測試鉤子：`GV.ignite=(x,y)=>{const b=T(idx(x,y)).bld;if(b&&b.k<=3){b.fire=1;return true}return false};` 且 `GV.stats()` 回傳增加 `fires`（燃燒中數量）與 `ruins`。
10. 小地圖：燃燒建築格畫 '#ff5030'（T06 的 drawMini 建築色判斷處加一個條件）。

## 硬性不變量
- 不動需求/電力公式；焦土不影響 computeFoam/mask；k=4/5 永不起火。
- 所有新繪製走現有管線（cv/dia/outlineSprite 可用）；不加全域每幀配置大物件。
- 舊存檔（無 fire/rn）讀入後一切如常。

## 本卡驗收（Console）
1. `GV.ignite(x,y)` 對一棟建築 → 畫面出現火焰動畫（截 dataURL 目測或亮度取樣該區域偏橙）；toast 出現。
2. `GV.setSpeed(3)` 等 3 秒 → `GV.stats().fires`≥1；再等 → 建築消失、`ruins`≥1、原格 deco/zone 保留。
3. 對焦土格 `GV.place('zr',...)` → 失敗；`GV.place('doze',...)` → ruin 清除、可再分區。
4. 滅火：ignite 另一棟 → pan 工具點它 → 面板有【滅火 $30】→ 點擊 → fire=0、錢 -30。
5. 存讀檔：ignite 後 💾 → 重新整理 → 繼續 → fires/ruins 數量一致。
6. VERIFY.md 全套＋像素檢查。
