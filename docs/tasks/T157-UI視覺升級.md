# T157 UI/HUD 視覺升級（框住整個體驗）
版本：v4.3 ｜ 難度：★★ ｜ 前置：無 ｜ 建議模型：Sonnet

## 目標
UI 是玩家全程都在看的框。升級 HUD 與面板的視覺質感：更精緻的面板邊框/陰影/圓角、工具列圖示統一風格、按鈕 hover/active 過渡、資源數值圖示、面板進出動畫、配色統一到一套主題變數。純 CSS/DOM，不碰 canvas 遊戲渲染。

## 定位錨
- `#hud`/`#toolcats`/`#tools`/`#zoomer`/`#start` 等 DOM 與其 CSS（`<style>` 區）
- 統計/成就/顧問/戰役/編輯器面板（`#info`/`.row` 等既有樣式）
- 既有 emoji 圖示、toast 樣式

## 允許觸碰
- `<style>` 區：新增一組 CSS 主題變數（`--panel-bg`/`--accent`/`--border`/`--shadow` 等）並套用到既有元件；面板加細邊框＋柔和陰影＋圓角統一；按鈕 hover/active `transition`；面板顯示加淡入/滑入動畫（`@keyframes`）；HUD 數值排版對齊優化。
- 工具列按鈕：統一 padding/圓角/選中態高亮；分類頁籤視覺區隔。
- 不動 canvas 繪製、不動任何 JS 邏輯與 DOM 結構（只改 class/style 與新增 CSS，必要時加 className）。

## 硬性不變量
- **純視覺 CSS**：不改遊戲模擬、canvas 渲染、存檔、任何 GV 行為。
- 所有既有按鈕/面板功能不變（點擊行為、id、事件綁定不動）。
- 不破壞 RWD（視窗縮放/手機尺寸仍可用，`#start overflow-y` 等既有修復保留）。
- test_fixde 380 不受影響（純 CSS）。

## 本卡驗收
1. 三件套（node --check / test_fixde 380 / 瀏覽器零錯誤）。
2. 視覺對比：面板邊框/陰影/圓角統一、按鈕有 hover/active 回饋、面板進出有動畫（截圖或 getComputedStyle 驗關鍵屬性）。
3. 所有面板（統計/成就/顧問/戰役/編輯器/幫助）開關正常、按鈕功能不變（逐一點擊驗）。
4. 手機尺寸（resize 375×812）HUD 不破版。
