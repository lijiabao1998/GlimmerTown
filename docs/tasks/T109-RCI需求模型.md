# T109 RCI 需求模型與需求條（玩法核心迴圈）
版本：v3.2 ｜ 難度：★★ ｜ 前置：無 ｜ 建議模型：Sonnet

## 目標
補上「看需求→劃區」的核心反饋迴圈：每日推導住/商/工三值需求（-1~+1），HUD 常駐三色迷你需求條，需求驅動分區生長速度。

## 定位錨
simDay()（每日統計已算 pop/jobs）；growZones 候選生成機率處；HUD div（#hud）。

## 允許觸碰
simDay 尾端新增需求計算：住宅需求＝就業盈餘與幸福加權；商業需求＝人口/商業格數比；工業需求＝商業貨源缺口。歸一化 -1~+1，存全域 demand={r,c,i}（**不入存檔**，每日重算）。growZones 生長機率乘 (1+demand×0.6)，需求 <-0.5 時該類停長。HUD 加三條 4×24px 豎條（DOM 或 canvas 皆可，綠正紅負），tooltip 顯示數值。

## 硬性不變量
不新增存檔欄位；demand 全零時生長行為與改動前一致（回歸基準）；不動稅收公式。

## 本卡驗收
1. 三件套照常（node --check / test_fixde 380+ / 瀏覽器零錯誤）。
2. 端到端：只劃住宅區→商業需求條轉正；補商業區→工業需求上升；全城失業→住宅需求轉負且住宅停長（GV.step 驗證生長計數）。
3. 需求條顏色與正負對應、數值在 -1~+1。
