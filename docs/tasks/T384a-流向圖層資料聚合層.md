## 五個已定案的設計決策(施工不得自行更改)

1. **快照寫入點=12340 `aiStep()` 之後、12341 `hist.push` 之前**,單一物件字面量賦值
   `flowStat384={...,ok:true}`,只抄已算好的變數,零重算零副作用。與 hist 同視角(aiStep 後)。
2. **學 demWhy 不學 fin**:宣告 `let flowStat384={ok:false};`(~603 demWhy 旁);
   `newWorld`(9264 叢集)與 `load`(18203 叢集)成對歸零(鐵律7);**不得順手幫 fin 補歸零**
   (那是改 fin 行為,另卡;本卡卡面記這條舊債即可)。
3. **區塊 const 最小鏡像集**(tick 區塊內部值外面讀不到,只鏡像這些,單行、零副作用):
   - `gFlow284` 加鍵 `made:gGain*2, need:gNeed284`(既有快照只准加鍵不改不刪;
     既有 `gain` 是「售前庫存」語義陷阱,made 才是真產量——L17299 面板註釋已載);
   - 新 `let indFlow384={d:0,u:0};` 於 T140 塊(11670-11673)內賦 `{d:indSupplyDemand,u:indSupplyUsed}`;
   - 新 `let foodFlow384={surplus:0,gold:0};` 於 T336 塊(12219-12221)內賦值。
   其餘欄位(oilGain/oreGain/suppliesGain=tick 頂層 let;fuel/steel/氣鏈=GV.chain346 同源模組變數;
   busRtCovPop/railCovPop/metroCovPop/transitRidership=模組全域)直讀,不建鏡像。
4. **掃描類聚合一律 lazy、在 tick 外**(面板開啟才算,零 tick 成本):
   - `GV.flowNodes384()`:掃 tiles 回 `[{k,x,y,role}]`,role∈produce(49/50)/process(121/122/123)/
     store(64)/export(18/91/110)/consume(lv2+ 供電工商);
   - `GV.flowRoads384()`:道路逐級聚合 `[{rc,n,avgLoad,overN}]`+jamTop/corridorTop 各 10 筆
     (roadLoad 與 commuteLoad 分開報——**語義誠實**:roadLoad 含隨機走車,命名「壅堵」;
     commuteLoad 才是通勤走廊訊號);
   - `GV.flowStat()`:回傳 `JSON.parse(JSON.stringify(flowStat384))` 深拷貝(防面板改活物件)。
5. **快照欄位表**(流量/存量分離;缺口=need−use 可導出;為 T385 委託/T386 外貿預留同源數字):
   `{ok,day, raw:{oil,ore,made,stock}, goods:{made,sold,need,stock,cap,mul},
     ind:{demand,used,mul}, fuel:{made,stock,mul}, steel:{made,used,stock,mul},
     ship:{gold,mul,ports}, gas:{sup,dem,ratio,fert,cooked}, food:{points,surplus,gold,price},
     transit:{ridership,bus,rail,metro}}`
   欄位可在 ±20% 內增刪(施工時以實際可讀變數為準),但 ok/day 與「不塞 UI 字串」不可變。
