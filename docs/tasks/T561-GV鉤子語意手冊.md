**日期**：2026-08-25　**發卡**：Claude（馬拉松；純文件卡，不碰程式碼）

## 0. 病灶

2026-08-22 十小時玩測馬拉松的三張 P2 卡**全數撤銷/結案為探針誤用**（T555 clamp 型誤呼叫、
T556 setter 型誤清狀態、T554 座標型誤當投影），P3 清單又有三條同因假象（P3-3 紅游標語意、
P3-4 診斷餵法、P3-6 rAF 殘影）。**六個獨立指控、一個根因：鉤子語意沒有文件，
每個探針作者都在原始碼外猜。** 猜錯的成本是三張卡的施工考古＋兩輪判決實驗。

## 1. 落地

新增 `docs/GV-HOOKS.md`：
- 六個語意類型（setter／clamp／查詢含 null 語意／座標／面板轉儲／時間），各配已判決的誤用案例；
- 八條造境規則（關開始畫面＋遮擋審計、閉環驗屍法、canPlace 含資金、完工 age≥9、
  電廠 1×1 貼路、槽 3 與自動存檔、rAF 殘影、紅游標語意）；
- 已判決案例索引（T554/T555/T556/P3-3/P3-4/P3-6/P3-8 七條，含 P3-8 定性為設計語意：
  `GV.place` 是測試橋不走手勢堆疊，測 undo 用 `pointer()`）。

**刻意不做**：不給逐鉤子 API 文件——鉤子隨卡演化，逐條文件必然過期（「過期線索比沒有
線索更貴」，ROADMAP 稽核剛驗證過）；手冊只記**類型與規則**，逐鉤子行為以 `String(fn)`
現場原文為準，手冊開頭就這麼教。
