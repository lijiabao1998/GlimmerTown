1. **容量公式**:`medCap=clinics*4+hospitals*10+am*6+mhN*30`(權重呼應維護費比;
   cemCap 11476 同構;四計數皆 tick 函式層變數,快照點直讀零鏡像)。
   **k102 寵物醫院不入族**(非醫療容量,偵查點名)。
2. **病患計數**:tick 區域 `let sickN387=0`,在既有讀 b.sick 的計數迴圈搭一行
   `if(b.bld&&...sick)sickN387++`(住宅 sick 專計,**與 death 分開**——統計頁 sickN 是
   sick‖death 合併口徑陷阱,不沿用);區域變數=免鐵律7/免存檔/免模組面。
3. **快照**:flowStat384 錨塊內加 `med:{cap:medCap,sick:sickN387}`(只加鍵;
   3 處 ok:false 字面量計數不動;禁亂數 regex 自動繼承;數字葉自動入有限性斷言)。
   **覆蓋率不進 tick**(scenarioCoverage 是掃描)——面板 lazy 呼叫。
4. **顯示**:流向 tab 加「🏥 服務容量(醫療)」節:床位/病患/bar(sick/cap)+
   覆蓋率(lazy scenarioCoverage('hospital'))+超載 warn(sick>cap);
   城市 tab 不動(17608-17634 巨型模板改動面大,記卡)。
5. **效果留白(本卡不做,記給 T387b)**:容量不足→醫院級「次日必癒」(12169,零 R)降級
   為機率癒——動它=改 R() 消耗結構,需 12 種子回歸,獨立卡;svcBudget→容量係數同批。
