# T45 高密度辦公區

## 目標
將商業區細分為低密度商業與高密度辦公區，讓後期城市能建立 CBD。

## 需求

### 1. 常數與工具列
- 新增 `ZONE_CLASS`：商業區可分 `office`（高密度）與 `commercial`（低密度）。
- TOOLS 將現有 `zc` 改為低密度商業，新增 `zo`（辦公區）。
- 快捷鍵 `z` 切換 `zc`，`O`（大寫）切換 `zo`。

### 2. 建造邏輯
- `zo` 僅可在有 `tram` 或 `rail` 或主幹道（rc≥3）鄰近的區域劃設。
- `doPlace` 設定 `t.zone=2` 且 `t.office=1`。

### 3. 模擬邏擬
- 辦公區生成的建築 `b.office=1`，外觀為高樓大廈。
- 辦公區稅收係數 ×1.3（相較普通商業），但需供水供電穩定（若停電，當日稅收 ×0）。
- 辦公區附近（半徑 4）住宅幸福 -0.03（通勤擁擠）。
- 辦公區需要更多就業人口：Lv1 10 人、Lv2 28 人、Lv3 70 人（覆蓋 `JOBSC` 之外額外 table `OFFICE_JOBS`）。

### 4. 視覺
- `buildSprites` 追加 `SPR.bld['2_office_lv_v']`：玻璃幕牆高樓，夜間窗燈密集。

### 5. UI
- `inspect()` 辦公區顯示「🏢 辦公區｜高密度商業｜稅收×1.3」。

### 6. 存檔
- `zn` 字串沿用 zone=2，新增 `of` 字串記錄 `t.office`。

### 7. 測試
- `test_t45.js`：驗證辦公區劃設條件、稅收加成、高樓外觀、存讀檔。

## 驗收標準

- [ ] 辦公區稅收與就業數值正確。
