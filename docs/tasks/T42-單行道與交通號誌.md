# T42 單行道與交通號誌

## 目標
強化道路微觀管理：單行道可疏解壅塞，號誌燈可提升路口安全與車流效率。

## 需求

### 1. 常數與工具列
- `COST.oneway=20`（單行道標示）、`COST.trafficLight=60`（路口號誌）。
- TOOLS 插入 `oneway` 與 `trafficLight`（皆為道路附屬工具，類似 rdec/bus）。
- 快捷鍵 `n`（one-way）、`j`（traffic light）。

### 2. 建造邏輯
- `oneway`：僅已鋪設普通道路（非橋、非高速）可放，設定 `t.oneway=direction`（1=右上、2=右下、3=左下、4=左上，沿用位向約定）。
- `trafficLight`：僅十字路口（mask 有 3 或 4 個方向連接）可放，設定 `t.light=1`。
- `doze`：先清 oneway/light 再清道路。

### 3. 模擬邏擬
- 單行道：車輛只能沿指定方向行駛；`updCars` 需判斷 `t.oneway` 並過濾非法轉向。
- 號誌燈：路口車輛速度減半通過，但事故率降低（若未來有車禍系統）；目前先提升商業稅收 +3%（物流效率）。
- 單行道旁住宅幸福 -0.02（噪音），商業稅收 +2%（車流順暢）。

### 4. 視覺
- `buildSprites` 追加：
  - `SPR.oneway[4]`：路面箭頭 sprite。
  - `SPR.trafficLight`：路口號誌（紅黃綠燈），夜間燈光層。
- `draw()` 在道路層上方、zone 下方繪製。

### 5. UI
- `inspect()` 道路格顯示單行道方向或號誌狀態。

### 6. 存檔
- 新增 `ow` 字串記錄 `t.oneway`（0-4），`tl` 字串記錄 `t.light`（0/1）。

### 7. 測試
- `test_t42.js`：驗證單行道方向限制、號誌燈建造、存讀檔。
