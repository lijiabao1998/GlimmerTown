## 一句話

每完成/過期一輪就從池中決定性抽三個委託供玩家選一(seed+輪次雜湊,零亂數流消耗),
限期達標得一次性獎金(失敗不毀城只過期);進度累計/連續天數自帶存檔欄位;
UI=統計面板第四顆 tab。全部復用既有機制(挑戰/場景/cityEvent/tech343/flowStat 先例)。

## 設計決策(八條,施工不得自行更改)

1. **委託池 v1 五型九條**(`CMS385` const 表 `{id,nm,ic,type,target,days,bonus,minRank}`):
   - `steel`×2:累計造船耗鋼 N(源=`steelUsed` 日值,文案「造船用鋼」——**誠實命名**,
     steelUsed 是耗鋼非出口,偵查警告在案);
   - `trade`×2:累計糧食出口金 $N(源=`tradeGold` 日值,已含造船放大,文案言明);
   - `transit`×2:公共運量≥N 維持 M 天(源=`transitRidership`+hold);
   - `happy`×2:幸福≥N% 維持 M 天(源=`cityHappy`+hold,scenario.hold :12265 同款);
   - `tech`×1:完成指定科技(源=`hasTech343(id)`,零新累計器)。
   **被否決:污染維持型**——全城無現成 tick 日值標量,補一個要動主幸福迴圈(高危區)或
   加 tick 掃描(違 T384a 精神);記此為 v1 取捨,日後有日值再回鍋。
   bonus 階梯保守($800~$2500),一次性。
2. **抽選=districtName 型整數雜湊**(:12379 先例):`offers=pick3(seed, cms385.n, rankIdx)`
   ——同 seed 同輪次恆同三條(去重、`minRank≤rankIdx` 過濾)、**offers 不落盤**(重算恆同);
   `n`=輪次計數器(完成或過期時 +1 ⇒ 自動換一組),入存檔。零 `R()/ri()/Math.random`
   (loop 帳本紅線+鐵律2;靜態禁亂數守衛同 T384a p1a 案)。
   開委託門檻:`rankIdx>=2 && pop>50 && diff!==3`(**沙盒不出委託**——免費建造白拿獎金,
   本卡明立新慣例並記卡,與「既有一次性獎勵沙盒照付」先例刻意分道)。
3. **tick 掛載**:尾端唯一錨 `/* T385 cms BEGIN */`↔`END`,放 flowStat END 之後、
   `hist.push` 之前。內容:active 委託逐日累計(`acc+=steelUsed` 型/`hold` streak 型,
   直讀本 tick 已算值,零重算)、到期判定、完成發獎、過期換輪。零亂數、單一區塊。
4. **獎勵=一次性 `money+=bonus`**(里程碑 :12281 先例):不走 `income+=`(污染 fin/hist,
   偵查點名)、toast('gold')+sFanfare()+spawnConfetti() 三件套;過期=toast('bad') 零城市副作用
   (場景 lose :12271 先例)。**AI 市長不接委託**(aiStep 零觸碰)。
5. **存檔欄位 `cms385={act,st,acc,hold,n,done}`**(T343a tech343 同構):
   `emptyCms385()` 零狀態 ⇒ save 端 return null 不落欄位(舊檔 bytes 逐位不變);
   load 驗型 svcFleet 級逐鍵(act 白名單、非空須不在 done、st/acc/hold/n 皆 int≥0、
   done 去重白名單),**任何非法=整欄棄用回零、不拋例外**(load 外層 try 會吞→蓋城);
   newWorld(:9286 tech343 旁)/load(:18258 旁)成對歸零(鐵律7 兩條字串釘同 T384a)。
   **不與 challenge 共用心智**(它不入檔=已知缺口,不沿用)。
6. **UI=第四顆 tab `statsComm385`「📋 委託」**(statsTabs343+bind 各一行+
   `showCommPanel385()` 照 showFlowPanel384 模板):無 active ⇒ 三張卡各一段 statTab
   (名/目標/期限/獎金)+三顆固定接受鈕 `bCommAcc385_0/1/2`;有 active ⇒ 進度 `{bar}`+

   完成數顯示 done.length。門檻未達(rankIdx<2/沙盒)⇒「等級 3 解鎖/沙盒無委託」dim 列。
   四個新 id 全入 test ids 白名單(mock 陷阱)。新 offers 輪替日 toast('📋 新委託','gold')。
7. **零接單恆等紅線**:未接單(act='')時 T385 tick 塊只做「有無新輪 toast」判定,

## 驗收清單

1. **決定性**:同 seed 同 n 兩次呼叫 offers 恆同;不同 n 不同組(Node 斷言)。
2. **零亂數**:錨塊靜態 regex 守衛;破壞性=塞 `R()` 字串字面量→紅於 T385 靜態守衛
   (p1a 同型;真 R() 會被種子釘先咬,fail-fast 順序意識)。
3. **功能鏈**:造境接單(steel 型)→直寫造船鏈→step N 天→acc 遞增→達標日 money 增加
   bonus 且 done 收錄、n+1、act 清空;過期案:step 超 deadline→過期、無 money 變化、n+1。
4. **驗型八畸形**:非物件/act 非白名單/act∈done/負數/浮點/done 重複/陣列型/超界
   →整欄棄用回零且 load 不拋(T343a 同構)。
5. **存讀往返**:接單有進度→save→load→acc/hold/st/n/done 逐鍵相等;零狀態→save→
   存檔字串無 `cms385`。
6. **UI**:白名單綁定真實性(d1 破壞性同 T384b)/面板禁 NaN/undefined/沙盒與低等級 dim 列/
   undo 全等斷言。
