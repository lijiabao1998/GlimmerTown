## 差異規格
1. `KNAME[7]='學校'`；`COST.school=350`；TOOLS 在 fire 之後插 `{id:'school',ic:'🏫',nm:'學校',pr:'$'+COST.school}`；快捷鍵順延（9=學校、0=拆除，keydown map 同步）。
2. 維護費 $2.5/天；就業：tick 中 `jobs` 總數把每所學校 +8（加在 jobsC 之後彙總處，不參與 C/I 需求公式的 jobsC/jobsI 本身——直接 `jobs=jobsC+jobsI+schools*8`）。
3. 升級加成：tick 升級判定 `R()<.035` 處改為 `R()<.035*(b.k===1&&countNear(x,y,8,tt=>tt.bld&&tt.bld.k===7)>0?1.6:1)` ——注意升級迴圈目前只有索引 i，需在迴圈內補 `const x=i%N,y=(i/N)|0;`（僅當該迴圈尚無 x,y 時）。
4. Sprite：黃牆＋旗杆（頂部小紅旗 2×3px）＋大窗；3 變體；`SPR.bld['7_1_0..2']`。
5. inspect：「🏫 學校｜半徑 8 內住宅更快升級｜就業 8｜維護費 $2.5/天」。
6. 小地圖色 '#ffd45f'；統計面板加「學校 n」。
