# T126 放置遮擋修復（玩家實測反饋）
版本：v3.5 ｜ 難度：★★ ｜ 前置：無 ｜ 建議模型：Sonnet

## 問題（用戶親測）
建造時前方的高樓會擋住目標格：游標高亮/預覽被物件層蓋住，看不見自己在往哪放。

## 目標
1. 建造/分區/拆除工具激活時，游標格高亮與 ghost 預覽**永遠畫在最上層**（物件層之後）。
2. 擋住游標格的前方建築半透明（alpha≈0.35）：物件層繪製時，凡 sprite 螢幕包圍盒覆蓋游標格錨點、且等距繪製序在游標格之後（=在其前方）者降透明度。
3. 檢視工具點選建築後，遮擋該建築的前方物件同樣半透明（看得見選中誰）。

## 定位錨
draw() 物件層排序繪製迴圈；drawCursor；inspect 選中狀態。

## 允許觸碰
物件層繪製迴圈（加 alpha 判定，僅工具激活＋有 hover/選中時啟用）；drawCursor 的繪製時機（移至物件層後）；透明判定用螢幕包圍盒對游標格錨點的覆蓋測試（每幀對可見物件一次，O(可見物件數)）。

## 硬性不變量
- 無工具激活（檢視且無選中）時渲染與改動前**逐像素一致**（像素回歸必做）。
- 透明只影響「畫」，不影響點擊判定與模擬。
- 不動等距排序本身（透明不是重排）。

## 本卡驗收
1. 三件套照常（node --check / test_fixde 380+ / 瀏覽器零錯誤）。
2. 端到端：在高樓（lv3 塔樓）正後方一格放建築——游標高亮與 ghost 全程可見（getImageData 驗游標格位置出現高亮色）；前方高樓透明可透視；鬆開工具恢復不透明。
3. 檢視點選被擋建築：前方物件半透明、面板資訊正確。
4. 無工具狀態像素回歸與基準一致。
