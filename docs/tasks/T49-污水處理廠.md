# T49 污水處理廠

## 目標
延續供水系統，加入污水處理，讓城市在擴張時必須處理廢水，否則影響健康與幸福。

## 需求

### 1. 常數與工具列
- `COST.sewage=500`。
- `KNAME[27]='污水處理廠'`。
- TOOLS 插入 `sewage`。

### 2. 建造邏輯
- 僅陸地、非道路、無建築、緊鄰至少 2 格水域（排放口）。

### 3. 模擬邏擬
- 污水處理廠維護 $3/天，就業 4/座。
- 每座處理 80 棟建築的污水。
- 若污水量 > 處理容量，未處理污水使全城住宅幸福 -0.05～-0.15（依超載比例）。
- 污水處理廠半徑 6 內住宅幸福 -0.05（異味）。

### 4. 視覺
- `buildSprites` 追加 `SPR.bld['27_1_v']`：圓形處理池＋過濾塔。

### 5. UI
- `inspect()`：「🛢️ 污水處理廠｜處理 80 棟｜就業4｜維護$3/天」。
- `showStats()` 加污水量/容量。

### 6. 存檔
- 無新欄位，建築由 `bl` 儲存。

### 7. 測試
- `test_t49.js`：驗證超載懲罰、容量計算、存讀檔。

## 驗收標準
- [ ] 污水處理廠可建，需臨水。
- [ ] 超載降低全城幸福。
- [ ] 測試通過。
