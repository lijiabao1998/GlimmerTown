# T117 隕石災害
版本：v3.3 ｜ 難度：★★ ｜ 前置：T116（災害鈕列/機率結構沿用）｜ 建議模型：Sonnet

## 目標
第五種災害：隕石——隨機落點爆炸（半徑 2 摧毀），留下「隕石坑」地物並持續起火數日，需付費剷除（$120）。

## 定位錨
T116 的災害觸發結構；t.deco/地物欄位；火災 ignite 先例；doze 拆除鏈；placeCost。

## 允許觸碰
落點半徑 2 內建築→廢墟、樹清除、中心格設隕石坑地物（新 tile 欄位 `crater:1`，**存檔可選欄位**——序列化仿 flood/焦土先例）；坑存在期間每日對鄰域擲火（複用 ignite）；拆除工具可剷坑（$120，剷後停火）；墜落瞬間全屏閃光＋震屏（複用地震 shakeT）；隕石坑 sprite（焦黑環＋餘燼夜光）在 buildSprites 尾端；GV.meteor(x,y) 鉤子＋沙盒災害鈕。

## 硬性不變量
存檔只加可選欄位（舊檔無 crater 正常）；坑的擲火走種子流；災害開關/難度倍率管轄；不動既有火災蔓延參數。

## 本卡驗收
1. 三件套照常；舊檔正常。
2. GV.meteor：半徑 2 摧毀、坑出現、次日起鄰域可起火、剷除 $120 後停火；存讀檔往返坑保持；通知帶座標可跳轉。
3. 開關關閉 0 觸發；沙盒鈕可用。
