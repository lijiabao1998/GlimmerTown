# T160 建築地面銜接與廣場（消除「貼上去」感）
版本：v4.3 ｜ 難度：★★ ｜ 前置：T146（街道細節）｜ 建議模型：Sonnet

## 目標
目前建築像直接「貼」在草地上。加入地面銜接：建築周邊地坪/鋪磚、大型公共建築的前庭廣場、入口通道連到最近道路、建築落地陰影底座、圍欄/綠籬邊界——讓建築與地面自然融合。

## 定位錨
- `buildSprites` 絕對尾端（新地坪 sprite）；`draw()` 建築繪製**之前**畫地坪（地面之上、建築之下）
- 多格建築 footprint、T96 `groundCache`（地坪屬靜態地面層，可入快取；快取鍵不動）、T146 街道細節
- 建築 k 分類（公共建築 vs RCI）

## 允許觸碰
- 新增 `SPR.plaza` 家族（尾端生成）：建築佔格周邊的鋪磚/地坪菱形（依建築類型不同材質——公共建築石板、RCI 水泥邊）、圍欄/綠籬邊界小件。
- `draw()` 在建築 drawImage **之前**、地面層之後畫該格地坪（大型/公共建築畫前庭廣場，覆蓋佔格＋外擴一圈）；入口通道：從建築朝最近道路方向畫一小段步道（依 road mask 決定方向，決定性）。
- 落地底座陰影：建築底部菱形加一圈柔和暗邊（貼合 footprint）。
- LOD：`z<0.5` 只畫底座陰影、跳過鋪磚細節；`z<1` 跳過圍欄小件。

## 硬性不變量
- 新 sprite 絕對尾端；`__noPlaza` 關閉時全 SPR 鍵位元一致。
- 地坪畫在建築之前（不蓋建築）；不越出合理範圍（廣場外擴 ≤1 圈，抽查不蓋到其他建築/水面）。
- 地坪挑選/入口方向用決定性邏輯（road mask/座標雜湊），不消耗 R()。
- 若入 `groundCache` 則快取鍵結構不動；存檔零變更。

## 本卡驗收
1. 三件套（node --check / test_fixde 380 / 瀏覽器零錯誤）。
2. `__noPlaza` 開時位元一致；關時建築周邊出現地坪/廣場（getImageData 驗建築周邊像素變化）。
3. 大型公共建築有前庭廣場、入口通道朝向道路；落地底座陰影貼合；不蓋鄰近建築/水面。
4. LOD 分級正確；連續兩幀 checksum 相等（無抖動）。
