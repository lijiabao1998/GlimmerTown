# T30 住宅密度分級

版本：v2.1 ｜ 難度：★★ ｜ 前置：T29（道路五級分級）｜ 建議模型：Kimi/DeepSeek

## 目標

住宅建築依其誕生時鄰近最高道路等級，分為五級密度（低密度田園小屋 → 高密度公寓大樓）。
密度影響該棟住宅的人口產出，並在資訊面板顯示；視覺上 Lv3 高密度追加高層塔樓外觀。

## 允許觸碰

- 第 1 節：POPS、DEN_POP、DEN_NAME 等常數宣告
- 第 2 節：`buildSprites()` 內住宅 sprite 生成區塊（僅擴充 DRAFTS 資料表）
- 第 4 節：`doPlace`／生長產生的 `bld` 設定
- 第 5 節：`tick()` 人口計算、住宅生長與升級
- 第 8 節：`inspect()` 資訊顯示
- 第 11 節：`save()` / `load()` 建築列表 `bl` 的可選第 7 位

## 禁區

- 不改道路系統（T29 已負責）
- 不改商業、工業建築外觀與人口
- 不改存檔版本號 `data.v`
- 不改核心日夜循環、煙霧、粒子系統

## 實作步驟

### 1. 常數

定位錨：
```js
const POPS =[0,8,22,54];
```

替換為：
```js
const POPS =[0,8,22,54];
const DEN_POP=[0.70,0.85,1.00,1.25,1.60];
const DEN_NAME=['低密度','中低密度','中密度','中高密度','高密度'];
```

### 2. 住宅生長與升級

定位錨 `tick()` 生長段：
```js
T(idx(x,y)).bld={k:z,lv:1,v:ri(4),age:0,pw:true,h:.6};
```

住宅（z===1）追加 `den`：
```js
const den=clamp(getMaxRoadClass(x,y,3),1,5);
T(idx(x,y)).bld={k:z,lv:1,v:ri(4),age:0,pw:true,h:.6,den};
```

升級段保留既有 `den`：
```js
b.lv++;b.age=0;b.v=ri(4);
```

改為：
```js
b.lv++;b.age=0;b.v=ri(4);if(b.den===undefined)b.den=3;
```

### 3. 人口計算

定位錨：
```js
if(b.pw){popN+=POPS[b.lv];}
```

改為：
```js
if(b.pw){popN+=Math.round(POPS[b.lv]*(b.den?DEN_POP[b.den-1]:1));}
```

### 4. 視覺差異

定位錨 PAL 色表與 DRAFTS 表尾（花園商場示範行之後）。

住宅色盤追加第 5 組給 `v=4`：
```js
1:{walls:[...,['#d8d0c0','#b8b0a0']],
   roof:[...,'#7a5a4a']},
```

追加 Lv3 高密度住宅外觀：
```js
{k:1,lv:3,v:4,hw:28,h:56,parts:['windowsStd','flatParapet','waterTank','antenna','aviationLamp','balconyRows'],win:{litP:.55,w:4,ht:5,gx:5,gy:6},trim:'#c9d4e0'}
```

並將 k1 lv3 基準行改 `vn:4`，使 `v=4` 專屬高密度塔樓；其餘 density 使用既有 4 變體，由 `den` 決定 Lv3 時是否選用 `v=4`。

繪製查找邏輯（`draw()` 物件層）：
```js
else s=SPR.bld[bd.k+'_'+bd.lv+'_'+bd.v];
```

改為住宅依密度取鍵：
```js
else if(bd.k===1&&bd.lv===3&&bd.den>=4)s=SPR.bld['1_3_4'];
else s=SPR.bld[bd.k+'_'+bd.lv+'_'+bd.v];
```

### 5. 存檔相容

定位錨 `save()` 建築列表：
```js
const e=[i,t.bld.k,t.bld.lv,t.bld.v,t.bld.age];
```

住宅追加可選密度（無火災時補 0 占位，避免 `den` 誤判為 `fire`）：
```js
if(t.bld.k===1&&t.bld.den&&t.bld.den!==3){
  if(!t.bld.fire)e.push(0);
  e.push(t.bld.den);
}
```

`load()` 解碼：
```js
}else tiles[i].bld={k,lv,v,age,pw:true,h:.6,fire:rec[5]||0};
```

改為：
```js
}else{
  if(k===1){
    const fireVal=rec.length>=7?rec[5]:(rec.length===6?rec[5]:0);
    const denVal=rec.length>=7?rec[6]:3;
    tiles[i].bld={k,lv,v,age,pw:true,h:.6,fire:fireVal,den:denVal};
  }else tiles[i].bld={k,lv,v,age,pw:true,h:.6,fire:rec[5]||0};
}
```

舊檔無第 7 位 → `den=3`（中密度）。

### 6. 資訊面板

定位錨 `inspect()` 住宅分支：
```js
if(b.k===1)html+=`<div class="row">居民 ${b.pw?POPS[b.lv]:0} 人 ・ 幸福 ${Math.round((b.h||0)*100)}%</div>`;
```

改為：
```js
if(b.k===1){
  const den=b.den||3;
  html+=`<div class="row">居民 ${b.pw?Math.round(POPS[b.lv]*DEN_POP[den-1]):0} 人 ・ 幸福 ${Math.round((b.h||0)*100)}%</div>`;
  html+=`<div class="row">${DEN_NAME[den-1]}住宅</div>`;
}
```

## 存檔相容性

新增建築欄位 `den`（僅 k=1 可選第 7 位）。舊檔無第 7 位 → `den=3`（中密度）。`data.v` 不變。

## 本卡驗收

1. 開新地圖，小巷旁生成的住宅 `den` 計數多為 1-2；快速路旁多為 4-5。
2. `GV.tile(x,y)` 檢查 Lv1 住宅有 `den` 欄位，範圍 1-5。
3. 高密度 Lv3 住宅人口 > 低密度 Lv3 住宅人口（同級對比）。
4. 💾 → 重新整理 → 繼續 → `den` 保留。
5. VERIFY.md 全套通過。
