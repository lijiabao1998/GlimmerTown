# T274 農場作物變體擴充（12→16）

日期：2026-07-23  
狀態：完成  
風險：中低（四張靜態 base sprite＋十二張既有色重映射季節圖；
不改經濟、存檔格式或 AI）

## 問題

農場已有綠田、麥、菜畦、玉米、南瓜、果園、番茄、草莓、葡萄、
向日葵、稻田與高麗菜十二種外觀，但仍可在不增加模擬複雜度的前提下
擴充內容密度。這張卡補胡蘿蔔、西瓜、棉花與薰衣草四種原創像素外觀，
並完整接入既有春／夏／秋／冬顯示管線。

## 施工邊界

1. 新增 `22_1_12..22_1_15`，畫布 136×150、錨點 68/148；
   牧場、停車場與其他既有 sprite 不得改變。
2. 新 base 與其三季衍生圖只能置於 k62、T273 之後且在 T261
   夜燈遮罩之前。不得把四次 `plate()` 插入既有生成序列中段，
   以免位移 T272 私有紋理流造成舊 sprite 漂移。
3. 夏／秋／冬圖由新 base 的精確色重映射生成；春季沿用 base。
   每一新作物四季必須有鍵、固定幾何、可辨且至少一季像素不同。
4. 農場選型只由 `(x*5+y*11)%12` 改為 `%16`。不得新增
   `R()`／`ri()`／ambient `Math.random()`／既有共用 `rand()` 消耗。
5. 不改農場價格、2×2 footprint、食物／金幣／就業、灌溉升級、
   canPlace、save/load schema、AI、Service Worker 或 GAME_VER。
6. T273 的當卡 exact diff 改由本卡開工快照（post-T273）封存；
   current 的 T273 正式 source／trace／mutant／放置測試仍永久執行。
