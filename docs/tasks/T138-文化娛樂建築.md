# T138 文化娛樂建築（建築型別擴充 上）
版本：v3.8 ｜ 難度：★★★ ｜ 前置：無（T133 等級解鎖若已落地則掛鉤）｜ 建議模型：Sonnet

## 目標
新增 7 種文化娛樂型別（k=35-41），各綁一項模擬效果：博物館、劇院、水族館、動物園、遊樂園、電影院、圖書總館。把建築機制相異型別從 34 推向 41。對標 TheoTown 規模（非美術變體，是機制新型別）。

## 定位錨
- 多格建築架構（root+ref+sz、MSZ 表、KNAME、MINI_BLD_PAL、doze 多格鏈、save/load ref 重建）
- 經濟 else-if per k 分支（防 T61 幽靈稅）、COST/upkeep 表、TOOLS 工具列
- 觀光 tourists、幸福 happyParts、buildSprites 尾端、inspect

## 允許觸碰
- 7 新型別各定義：k 值、名稱、尺寸（1×1~3×3 多格）、COST/upkeep、sprite（buildSprites 絕對尾端，含夜光/細節）、效果——博物館/劇院/電影院=觀光+幸福半徑；水族館/動物園/遊樂園=強觀光吸引（tourists 係數）；圖書總館=大範圍教育/升級加成。
- 經濟鏈**每個 k 顯式加 else-if 分支**（造價/維護/稅/就業，防幽靈稅）；TOOLS「大型」或新「文化」分類加按鈕；MSZ/KNAME/MINI_BLD_PAL/inspect 同步；若 T133 已落地，掛 rank 解鎖。

## 硬性不變量
- 沿用既有多格建築通用機制（doze/draw/save/load）零改動，只加資料與 k 分支。
- 新 sprite 尾端生成、SPR 鍵 grep 查撞名、dia hw 偶數。
- 存檔 bl 元組格式不變（sz/ref 既有支援）；舊檔正常。
- 未放置新建築的城市模擬與改動前一致（純新增，位元回歸）。

## 本卡驗收
1. 三件套照常；舊檔正常。
2. 7 型別逐一可放（多格正確 root+ref）、扣款/維護/稅精確（GV 驗，無幽靈稅）、效果生效（觀光/幸福/教育 GV 逐項驗）；拆一格整棟拆；存讀檔往返保持。
3. 夜間細節/夜光可見；小地圖色正確；inspect 文案正確。
4. 建築型別總數達 41（GV/KNAME 枚舉）。
