# T37 程序化背景音樂系統

## 目標
為遊戲建立一套可擴展的程序化背景音樂/氛圍音生成系統，依據晝夜、天氣、季節動態變換。本卡先用傳統程序化算法實現（零外部素材、不依賴 NPU），但架構上預留 WebNN/NPU 接口，未來可無縫替換為本地模型生成。

## 需求

### 1. 架構設計
- 新增 `AudioComposer` 模組（位於 index.html script 內），負責：
  - 根據當前 `day`（晝夜）、`weather`（晴/雨/暴雨）、`inWinter()`（冬季）選擇情緒標籤。
  - 用程序化算法生成短循環旋律/和聲/節奏（不使用任何外部音訊檔案）。
  - 透過現有 `AudioContext` 輸出，並與現有 `sndMode`（🔇/🔊/🎵）整合。
- 預留 `NPUComposer` 接口（空殼或 stub），未來可接入 WebNN/DirectML 模型。

### 2. 情緒與場景對照
| 條件 | 音樂風格 |
|------|----------|
| 白天晴天 | 輕快民謠，木吉他式撥弦 + 柔和長音 |
| 白天雨天 | 憂鬱鋼琴式琶音，節奏放慢 |
| 暴雨 | 低沉弦樂鋪底，緊張感 |
| 夜晚 | 緩慢 pad + 蟲鳴/環境音（沿用 T05 環境音） |
| 冬季 | 冷色調鐘琴/合成器，減少低頻 |

### 3. 技術實現
- 使用 Web Audio API `OscillatorNode` + `GainNode` 即時合成。
- 定義簡易音階/和弦表（C 大調、A 小調等），根據情緒選擇。
- 用 `setTimeout`/`requestAnimationFrame` 排程短句（phrase，4-8 小節），避免與遊戲主迴圈耦合。
- 天氣或季節切換時，以 crossfade（1-2 秒）過渡到新曲風。

### 4. 遊戲整合
- 在 `begin()` / 速度切換 / 天氣變換時觸發作曲家。
- 當 `sndMode` 為 🎵（音效+環境音）時播放背景音樂；🔊 時僅保留環境音與音效；🔇 時靜音。
- 新增 HUD 按鈕或設定項（可選）：「背景音樂開/關」。

### 5. 測試
- 新增 `test_t37.js` DOM mock 測試：
  - 驗證 `AudioComposer` 可根據不同情緒標籤產生排程事件。
  - 驗證 `sndMode` 切換時作曲家啟停正確。
  - 驗證天氣變化觸發曲目切換。
- `node --check index.html` OK。
- `node test_t37.js` PASS。

### 6. 文件
- 更新 `docs/CHANGELOG.md` 追加 T37 一行。
- 在 `docs/ARCH.md`（若存在）或註解中說明 NPU 預留接口。
