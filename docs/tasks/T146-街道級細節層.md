# T146 街道級細節層（地面層視覺密度）
版本：v4.1 ｜ 難度：★★★ ｜ 前置：無 ｜ 建議模型：Sonnet

## 目標
把空曠的路面填滿生活感：人行道邊石、斑馬線、車道標線（依道路等級）、路邊設施（消防栓/郵筒/長椅/垃圾桶/候車亭）、路邊停放車輛、行人點綴。這是「一眼看上去有沒有做」的最大單項。

## 定位錨
- `buildSprites` 絕對尾端（新 sprite）；`draw()` 地面層道路繪製段、T96 `groundCache`（快取鍵不動）
- 道路等級 `rc`/road mask（bit1=(x,y-1)/bit2=(x+1,y)/bit4=(x,y+1)/bit8=(x-1,y)）
- T128 `detailPass` 尾端疊加手法先例；T107 LOD（遠景跳過）

## 允許觸碰
- 新增 `SPR.roadDeco` 家族（尾端生成）：人行道邊石（依 mask 貼合路緣）、斑馬線（交叉口/端點）、中線與車道標線（rc≥3 才畫）、街道設施小件（消防栓/郵筒/長椅/垃圾桶/候車亭，含夜光候車亭）、路邊停放車（複用既有小車 sprite 換色縮小）、行人（2-3px 點狀，可 visT 兩幀微動）。
- `draw()` 道路繪製後疊加：依 tile 座標決定性挑選（**用座標雜湊，不用 R()**，避免每幀抖動與亂數流污染）；密度依道路等級與鄰近建築等級遞增。
- LOD：`z<1` 跳過街道小件、`z<0.5` 連標線一併跳過（沿用 T107 分級）。
- 快取：這些屬地面層，須併入 `groundCache` 重繪路徑（**不得改快取鍵結構**）。

## 硬性不變量
- 新 sprite 一律 `buildSprites` **絕對尾端**；`__noStreet` 開關關閉時全 SPR 鍵 checksum 與改動前**位元一致**（零亂數位移證明）。
- 街道小件挑選用座標決定性雜湊，**不消耗 R()**；同種子同畫面重繪結果一致（連續兩幀 checksum 相等）。
- 不越出道路格範圍（不蓋到建築/水面，抽查驗）；存檔格式零變更。
- 效能：生成耗時增量 <1s；`groundCache` 命中率不下降（快取仍有效）。

## 本卡驗收
1. 三件套（node --check / test_fixde 380+ / 瀏覽器零錯誤）。
2. `__noStreet` 開時全鍵 checksum 與基準位元一致；關時道路區域像素明顯增densified（getImageData 非透明/色彩多樣度上升）。
3. 斑馬線出現在路口、標線只在 rc≥3、小件不越界；連續兩幀 checksum 相等（無抖動）。
4. `z<1`/`z<0.5` LOD 正確跳過；生成耗時實測 <1s。
