## 目標
HUD 新增 📊 按鈕，開啟面板顯示：昨日稅收明細（住/商/工）、維護費明細（路/公園/電廠）、淨收入、建築統計（各類數量）。

## 允許觸碰
HTML `#hud` 內新增一顆按鈕；第 1 節新增全域 `fin`；第 5 節 `tick()` 經濟段；第 10 節新增 `showStats()` 與按鈕綁定。

## 禁區
`#info` 面板的 `inspect()` 邏輯不動（我們**重用它的 DOM 容器**，但不動它的函數）；經濟數值本身一分錢都不能改。

## 實作步驟
1. HTML 定位錨 `<button class="hbtn" id="bSpeed">▶ 1x</button>` 之前插入
   `<button class="hbtn" id="bStats">📊</button>`。
2. 第 1 節 `let bailoutDay=-999;` 附近新增：
   `let fin={taxR:0,taxC:0,taxI:0,upR:0,upP:0,upE:0,net:0};`
3. `tick()` 經濟段改為分桶統計（**總額計算保持逐字等價**）：
   - 定位錨 `      if(b.k===1)income+=POPS[b.lv]*.12;` 起的三行，改為：
     ```js
     if(b.k===1){const v2=POPS[b.lv]*.12;income+=v2;taxR+=v2;}
     else if(b.k===2){const v2=JOBSC[b.lv]*.18;income+=v2;taxC+=v2;}
     else{const v2=JOBSI[b.lv]*.15;income+=v2;taxI+=v2;}
     ```
     並在 `let income=0,...` 行補宣告 `taxR=0,taxC=0,taxI=0`。
   - 定位錨 `  upkeep=roads*.02+parks*.5+plants*4;` 之後加：
     ```js
     fin={taxR,taxC,taxI,upR:roads*.02,upP:parks*.5,upE:plants*4,net:income-upkeep};
     ```
4. 第 10 節（`$('#bSave').onclick` 附近）新增並綁定：
   ```js
   function showStats(){
     let nR=0,nC=0,nI=0,nP=0,nE=0;
     for(let i=0;i<N*N;i++){const b=tiles[i].bld;if(!b)continue;
       if(b.k===1)nR++;else if(b.k===2)nC++;else if(b.k===3)nI++;
       else if(b.k===4)nP++;else nE++;}
     const f=v=>(v>=0?'+':'')+v.toFixed(1);
     $('#infoBody').innerHTML=
       `<h3>📊 小鎮統計</h3>
        <div class="row">🏠 住宅稅 ${f(fin.taxR)}　🏪 商業稅 ${f(fin.taxC)}　🏭 工業稅 ${f(fin.taxI)}</div>
        <div class="row">🛣 道路 -${fin.upR.toFixed(1)}　🌳 公園 -${fin.upP.toFixed(1)}　⚡ 電廠 -${fin.upE.toFixed(1)}</div>
        <div class="row"><b>每日淨收入 ${f(fin.net)}</b></div>
        <div class="row">建築：住${nR} 商${nC} 工${nI} 公園${nP} 電廠${nE}</div>
        <div class="row">👥 ${pop}　💼 ${jobs}　😊 ${Math.round(cityHappy*100)}%</div>`;
     $('#info').style.display='block';
   }
   $('#bStats').onclick=()=>{showStats();sTick();};
   ```
