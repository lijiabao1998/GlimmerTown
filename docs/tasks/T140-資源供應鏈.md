# T140 資源供應鏈（≥3 級＋地圖稀缺資源）
版本：v3.9 ｜ 難度：★★★ ｜ 前置：無 ｜ 建議模型：Sonnet

## 目標
多段資源鏈：地圖生成油/礦稀缺資源層（地理差異）→ 開採建築抽取為 supplies 存量 → 工業消耗原料產 supplies → 終局 megaproject 消耗 supplies 換大額回饋。對標 TheoTown 油/礦→Supplies→DSA 的 2-3 級鏈（判準 7）。

## 定位錨
- `genWorld`（地圖生成，加資源層）、`foodPoints` 存量＋tick 生產樣式
- 工業 k=3、多格建築架構（新開採/megaproject 建築 k=49-51）、經濟 k 分支
- `drawMini`/miniView（資源視圖）、buildSprites 尾端

## 允許觸碰
- `RESOURCE=Uint8Array(N*N)`：genWorld 依種子鋪油/礦斑塊（地理集中，非均勻）；**確定性可由種子重建**，開採耗損以稀疏可選存檔欄位 `rdep` 記錄（舊檔無＝未耗損）。
- 開採建築：油井（k=49）、礦場（k=50），須放在對應資源格上（canPlace 檢查），每 tick 抽取資源→ `supplies` 全域存量（仿 foodPoints）；資源耗盡後停產。
- 工業可選消耗原料提升產出；終局 megaproject（k=51，如研究/太空中心，多格大型）消耗 supplies 換大額資金/科技回饋。
- 各新 k 顯式經濟 else-if 分支；小地圖資源視圖；`GV.resourceAt`/`GV.supplies` 鉤子；rank 解鎖掛鉤（T133）。

## 硬性不變量
- RESOURCE 由種子確定重建；耗損 `rdep` 為稀疏可選存檔欄位，舊檔相容。
- 新建築沿用多格通用機制；尾端生成；查撞名；經濟分支防幽靈稅。
- **無開採建築的城市模擬與改動前一致**（純新增，位元回歸）。
- supplies/耗損在 newWorld/load 成對重置或重建（鐵律7）。

## 本卡驗收
1. 三件套照常；舊檔正常。
2. 新地圖有油/礦斑塊（地理集中，GV.resourceAt 抽查分佈）；油井/礦場放在資源格上抽取、supplies 上升、資源耗盡停產；工業消耗鏈可觀測；megaproject 消耗 supplies 換回饋（GV 驗）。
3. 存讀檔耗損 rdep 往返保持；資源層由種子重建一致。
4. 無開採城市同種子 30 天位元回歸；建築型別數增加。
