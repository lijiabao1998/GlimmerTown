# T35 圖書館系統

## 目標
新增教育延伸設施「圖書館（library，k=14）」，作為學校（k=7）的輕量替代/互補設施，提升附近居民幸福與升級機率。

## 需求

### 1. 常數與工具列
- `COST.library = 280`。
- `KNAME[14] = '圖書館'`。
- `TOOLS` 在學校工具後插入圖書館；快捷鍵 `l`（library）。
- 小地圖建築色表擴充到索引 14，使用顏色 `#c49a5e`（書卷木色）。

### 2. 建造邏輯
- `canPlace` / `placeCost` / `doPlace` 支援 `library`：僅陸地、非道路、無建築。
- `doPlace` 建立 `t.bld = {k:14, lv:1, v:ri(3), age:0, pw:true, h:1}`。
- 拆除邏輯正確清除圖書館。

### 3. 模擬邏輯
- tick 主迴圈早期計數 `libraries`（與 schools 同一階段），供就業與維護費使用。
- 就業：`jobs += libraries * 4`（與診所同規模）。
- 住宅幸福公式追加：半徑 6 內有圖書館則 `+0.04`（與體育場 +0.08、公車站 +0.04 同級，可疊加）。
- 住宅升級判定：半徑 6 內有圖書館時，升級機率額外 `×1.25`（與學校半徑8×1.6 區隔，學校效果較強但較貴）。
- 經濟段：圖書館計數 `libraries`，每日維護費 `libraries * 2`；統計面板 `fin.upL` 顯示圖書館維護費。

### 4. 視覺
- `buildSprites()` 尾端追加圖書館 sprite：72×112，外觀為小型磚瓦建築＋大窗＋門前階梯＋屋頂小煙囪，夜間窗內暖黃燈光，3 變體。
- `draw()` 物件層正確繪製 `k=14`。

### 5. UI
- `inspect()` 加圖書館分支：「📚 圖書館｜半徑 6 內住宅 +幸福、升級加快｜就業 4｜維護費 $2/天」。
- `showStats()` 計數加 `nL`、維護費行加「📚 圖書館 -$fin.upL.toFixed(1)」、建築行加「圖書館${nL}」。
- `showHelp()` 追加圖書館說明一行。

### 6. 存檔
- 圖書館是正常 1×1 建築，k=14 已透過 `bl` 陣列儲存，無需新增欄位。

### 7. 測試
- 新增 `test_t35.js` DOM mock 測試（沿用 T34 的 mock）：
  - 固定種子建造圖書館與住宅。
  - 測量圖書館半徑6內住宅與半徑外住宅的幸福差異（內側應較高）。
  - 測量圖書館半徑6內住宅與半徑外住宅的升級速度差異（內側應較快）。
  - 存讀檔後圖書館保留。
