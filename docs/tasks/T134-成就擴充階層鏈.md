# T134 成就擴充＋階層鏈（30+，銅銀金）
版本：v3.7 ｜ 難度：★ ｜ 前置：無 ｜ 建議模型：Sonnet

## 目標
成就從 8 擴到 ≥30，加入銅→銀→金階層鏈與少量隱藏成就；成就面板帶進度條。對標 TheoTown 51-54 成就，並以「階層鏈」建立結構性優勢（TheoTown 無成就樹）。

## 定位錨
- `ach` 物件（成就狀態）、成就檢查點、存檔 `ach` 欄位（id 集合）、里程碑 UI
- 各系統指標：pop/happy/災害存活/服務齊全/財富/場景通關（T132）/等級（T133）

## 允許觸碰
- `ACHS` 擴至 30+：定義 id/名稱/描述/條件/階層（bronze/silver/gold）/hidden 旗標；階層鏈用同族遞增門檻（如人口 1k/1w/10w）。
- 成就檢查函式擴充（複用既有觸發點，新增指標讀取）；解鎖 toast。
- 成就面板（複用里程碑/統計 UI）：分類顯示、進度條、隱藏成就未解鎖顯示「？」。
- 與等級（T133）/場景（T132）交叉觸發（若已落地）。

## 硬性不變量
- 既有成就 id 穩定不變（老存檔 ach 集合相容）；ach 存檔格式為 id 集合，天然向後相容擴充。
- 成就檢查不消耗 R()、不改模擬；同種子位元回歸。
- 面板只在開啟時渲染。

## 本卡驗收
1. 三件套照常。
2. 成就總數 ≥30；至少一條銅銀金三階鏈可逐階解鎖；隱藏成就達成前顯「？」、達成後揭示。
3. 面板進度條與實際指標吻合；存讀檔 ach 集合往返保持、舊檔相容。
4. 同種子位元回歸。
