# T634 附屋接合與密集相鄰修訂

業主於2026-10-11檢視fd7a6df真Chrome街景後指出建築像疊在旁棟。工程綠燈不構成美術驗收，本修訂保留原問題街景，不以拉開場景處理。

## 追溯與根因
- 3_2_4維多利亞啤酒廠，原合成街景root(28,29)，單格。紅磚附屋屬同一sprite，不是另一個存檔root。舊附屋只有一層卻高23px，比主屋每層約10.67px高逾兩倍；屋脊也套用主樓最低8px。
- 1_1_5花園郊區坡頂屋，root(34,23)，單格。附屋約31.6%基底埋入主屋，後畫的內部屋脊穿過主牆；獨立附屋煙囪使其更像另一棟。
- 原右下角u+v排序有11個非相交量體的射線遮擋反例。1_3_1格拉斯哥街角高密公寓是fd7尺寸改動引入的新回歸，其餘10個為保留缺陷，並非全數新引入。
- 全315主設計及新／舊尺寸486次draw的49,749個原版地腳點均在原足跡內。這只排除地腳越界，不能用來替屋頂、前後遮擋或比例背書。

## 修正
低附屋在主牆外實際共邊，採接牆方向的低坡頂與正常單層簷高。其他交叉翼重建外牆接合，四個合法的內含屋頂退台／塔體獨立列明。量體以u/v實體前後關係拓撲排序；窄屋脊依屋寬計算。凸窗從外牆開始，若牆段已由另一側翼占用就不生成，修掉4款中的5個程序生成凸窗碰撞，而非删除所有凸窗。

## 獨立守衛
- G13：所有108 RCI兩兩基底交集／真正共牆；只有四個具名內含高塔例外；低附屋層高及屋脊另驗。
- G14：以等角視線(1,1,32)穿過3D牆體的數學oracle，檢查實際輸出畫序，不沿用畫工自己的深度公式作真值。
- G15：315設計、全部新舊足跡的實際z≤0投影點不越界。
- G16：攔截真正巢狀shell呼叫的凸窗，不只檢查靜態m目錄。保持至少30個凸窗，禁止以全刪通關。
- 八個新增故意改壞來源：還原小屋穿牆、啤酒廠23px單層、8px附屋屋脊、舊角點排序、跨格地腳，取消凸窗碰撞判斷、舊屋頂塔畫序及移除母屋頂相交遮罩；首紅必須落在對應守衛。

### 屋頂塔補查
四個內含屋頂塔也經射線與實際像素補查：舊排序會將母屋頂後畫、抹掉物理上在屋頂前面的上層窗。修成母屋先畫、上塔後畫，且按flat/hip母屋頂實際高度裁掉藏在屋頂內的低牆。G17固定三個修前就已定位的上層窗像素，另驗18個低牆／夜光取樣和兩個對應紅源，不以stack語義作正確性證明。

## 真Chrome證據要求
比較基準固定fd7a6df。保留原街景同相機，新增兩個原root專屬近景；另拍單棟／九棟無縫緊鄰，四個地圖旋轉、日夜和前後版。地面、道路、鏡頭固定，密集組只增加八個相鄰root。全315源圖逐項變動／未變清單及原世界／存檔／季節檢查照跑。
