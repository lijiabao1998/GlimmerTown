# T460 效果報告——城市科學十卡（T451-T460）平衡矩陣

**方法**：12 種子 × (基線＋7 政策單開) × 300 天；配對差＝同種子同天(政策−基線)，
報表取跨種子**中位數**（混沌穩健，跑檯紀律）。世代流動(T456)為常駐、機會地圖(T455)為唯讀，不在開關矩陣。


## 〇、怎麼讀這份報告（可信度分層——先讀這段）

1. **最可信：自屬觀測值**（總表最後一欄）。它們是政策機制的直接帳目，決定性且不受混沌影響：
   壅堵費日收 $4、租金管制日砍住宅稅 $17、土地價值稅日收 $76、最低工資日商家成本 $7、
   混合社區 300 天介入 282 次、空品管制日合規成本 $3。**七個政策的機制全部如設計入帳。**
   （產業聚落 aggGain 僅 $0.08/日——密度門檻 .5 在 300 天小城幾乎不觸發，這是「取彈性下緣」
   的刻意保守；它是給後期高密度大城準備的。）
2. **次可信：day150 中位數**（分岔尚未複利放大）。
3. **僅供參考：day300 pop/money 中位數與逐種子明細**——300 天配對差被混沌路徑分岔支配
   （政策改變任何一次生長 roll 之後，兩條世界線各自重擲後續所有隨機事件）。典型例：
   **seed301 是基線 pop 6,545／$140,950 的黃金線**（T456 暴露紅利複利），任何政策一碰就
   從黃金線摔下（−3,000~−6,000 pop）——那是「碰掉了彩券」不是「政策有毒」，逐種子表裡
   它一列就能拖動全表觀感。跑檯鐵訓：**端點差是混沌噪音，機制判斷以自屬觀測值與短視野為準**
   （各卡卡面的同種子短視野配對差已逐一驗證方向）。
4. **安全網（第二節）是硬結論**：96 輪、零 crash、零「政策把非破產城玩到破產」。
