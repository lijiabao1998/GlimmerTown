# T55 分區法令與稅率政策

## 目標
加入政策面板，讓玩家能調整稅率、限制建築高度、設定環保法規，影響城市發展方向。

## 需求

### 1. 政策面板
- 在 `showStats()` 或獨立 `showPolicies()` 中新增政策選項。
- 政策項目：
  - 住宅稅率：0.08～0.18（預設 0.12）
  - 商業稅率：0.12～0.24（預設 0.18）
  - 工業稅率：0.10～0.20（預設 0.15）
  - 限高令：開啟時禁止住宅/商業升到 Lv3
  - 環保法規：開啟時工業稅收 ×0.9、污染懲罰減半
  - 公共交通補貼：開啟時大眾運輸維護費 +20%、全圖住宅幸福 +0.05

### 2. 模擬整合
- 稅率調整即時影響 `tick()` 經濟段計算。
- 限高令影響升級判定。
- 政策狀態存檔（新增 `pol` 欄位）。

### 3. UI
- 政策按鈕切換 on/off，稅率用 +/- 調整。
- `showHelp()` 說明政策系統。

### 4. 存檔
- 新增 `pol` 物件存稅率與開關狀態。

### 5. 測試
- `test_t55.js`：驗證稅率調整影響收入、限高令阻止升級、政策存檔。

## 驗收標準
- [ ] 政策面板可開啟與調整。
- [ ] 稅率與法令即時生效。
- [ ] 政策狀態可存檔。
- [ ] 測試通過。
