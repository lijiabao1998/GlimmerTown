- `toTile()` 為純數學逆變換＋v2w 旋轉（rot=0 恆等）——理論上同格異像素必同結果，與觀察矛盾 ⇒ 必有未發現的 intermediates（像素拾取？事件路徑分流？paintLast 去重？）。
- `doPlace` 失敗時會 toast（silent=false 路路徑）⇒ 靜默失敗代表**呼叫鏈根本沒到 doPlace**，或 toast 出現但未被觀察到。
- `GV.center(x,y)` 是唯讀查詢（回傳螢幕中心的格子），不移動相機——探針曾誤以為可用來置中。
- `GV.canPlaceTool(t,x,y)` 恆回 null（對水域也一樣），不可作為地形真值源；地形真值請用 `place('zr')` 驗屍法。
