## 目標

### A 部：四塊作物加密（作物層，**零新色**）

每塊按自己的色票能力做到最高細節，不強求一致：

| 田 | 目標 | 手法 |
|---|---|---|
| **麥田** | 三階等角犁溝 ＋ 麥稈 | 抄 `field()` 的相位式（見下），三色分 `ph<1` 溝底 `#b89a28`／`ph<4` 土面 `#d8b83a`／其餘亮脊 `#f0d060` |
| **玉米田** | 兩階犁溝 ＋ **稈穗行列** | 犁溝只用 `#2f5f28`／`#3f7a34` 兩階；玉米的視覺識別本來就是「成行的稈」，把 `#e8cc48` 留給穗尖而不是當亮脊 |
| **菜畦** | 單色土 ＋ **雙色植株加密** | 三階用在**植株**（`#4a8a3a` 莖／`#66b04a` 葉亮）而不是土。土只有一色，靠**密度**而非色階做層次 |
| **果園** | **加密果樹至 20+ 株** ＋ 樹本身已是三色 | 現在只有 6 株、容量 54~64。樹幹/冠/冠亮/果實四色已足夠，缺的是**數量與排列** |

**不加新色的層次手法**（只有一種色時怎麼做明暗）：
- **密度抖動**：同一色，用 `(a+b)&1` 或 `(a*3+b)%5` 這類決定性判準控制**留白率**，
  遠看就是明暗漸層。專案裡水面波紋、`railTrack` 的道碴都用同類手法。
- **兩色交錯**：相鄰像素交替兩色，視覺上合成中間色（傳統 dither）。

### 可抄的公式（**只能內嵌，不能呼叫**）

`field()` 的等角犁溝相位（`index.html:7391` 起，抄公式）：

```js
// 相位沿等角軸恆定：xx-2*yy 沿螢幕向量 (2,1) 走一步不變 ⇒ 條紋自動是等角直線
const ph = (((xx - 2*yy) % 6) + 6) % 6;
// 三階：ph<1 溝底／ph<4 土面／其餘亮脊
// 想讓兩塊田壟向交錯，第二種用 xx + 2*yy（另一條等角軸）
```

`plantGrid()` 的等角格網（`index.html:7430` 起，抄公式）：

```js
// 雙基向量：c 軸 (3,2) 順壟密植、r 軸 (5,-2) 跨壟行距
const dx = c*3 + r*5, dy = c*2 - r*2;
// 界內守衛（本卡的田是 (a,b) 矩形，改成矩形判準）
```

### B 部：大紅穀倉立體化（建築層，**新色自由**）

現在是 `sg.fillRect(ax-96,ay-96,30,24)` 一個平面紅方塊加白色 X 門。改用 `isoBox` 畫成等距三面體。

**`isoBox(g, cx, by, hw, h, cL, cR, cTop)` 的參數約束（已查實）**：

- `by` 是**底頂點**，不是左上角
- `hw` 是**半寬**（實寬 `2*hw`），且**必須是偶數**（內部用 `hw>>1`）
- `h` 必須 **≥3**，否則底部 3px AO（alpha=33）落在透明區，低於 `outlineSprite` 的 40 門檻，
  會被描邊色 (26,30,44) 整片吃掉
- **總佔高 = `h + hw`**（回傳 `rty = by - h - hw`）
- 必須畫在 **`sg`**（不是 `g`），與現有 4584-4593 一致，才吃得到 `outlineSprite(sc,26,30,44)`
- `isoBox`／`dia`／`diaEdge`／`shade` **全程零亂數**

可選加值：`windows(g, ng, cx, by, hw, h, rand, litP, opt)` 掛窗。
**注意 `index.html:1139` 是 `if(ng && rand() < litP)`** —— JS 短路，`ng` 為 falsy 時 `rand` 完全不求值。
53_1_0 **沒有 night 畫布**，所以傳 `ng=null` ⇒ **零亂數消耗**。
