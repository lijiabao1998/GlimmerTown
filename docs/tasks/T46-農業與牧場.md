# T46 農業與牧場

## 目標
加入農業區與牧場，讓城市外圍出現鄉村景觀，並提供基礎食物/原料產出。

## 需求

### 1. 常數與工具列
- `COST.farm=120`、`COST.ranch=180`。
- `KNAME[22]='農場'`、`KNAME[23]='牧場'`。
- TOOLS 插入 `farm`、`ranch`；無快捷鍵。

### 2. 建造邏輯
- `farm`/`ranch`：僅草地（t===2）可放，不可在道路或建築上，會清除 tree/deco。
- 農場/牧場為 2×2 多格建築（比照體育場）。

### 3. 模擬邏擬
- 農場：維護費 $1/天，就業 3/座，每天產出食物點數 `food+=3`。
- 牧場：維護費 $1.5/天，就業 2/座，每天產出食物點數 `food+=2`。
- 食物點數：每 10 點可讓 1 座住宅當天幸福 +0.02（上限 +0.06）。
- 農場/牧場不參與電力配額（鄉村設施）。
- 農場半徑 6 內工業幸福 -0.03（氣味）。

### 4. 視覺
- `buildSprites` 追加：
  - `SPR.bld['22_1_v']`：農場 sprite（穀倉＋田畦，依季節變色）。
  - `SPR.bld['23_1_v']`：牧場 sprite（圍欄＋牛隻剪影）。

### 5. UI
- `inspect()` 顯示食物產出與就業。
- `showStats()` 加 `nFarm`、`nRanch` 與食物點數。

### 6. 存檔
- `bl` 存 root，sz=2；食物點數不存（每天重算）。

### 7. 測試
- `test_t46.js`：驗證農場/牧場建造、食物點數影響幸福、存讀檔。

## 驗收標準
- [ ] 農場/牧場僅草地可建，2×2 多格。
- [ ] 食物點數提升住宅幸福。
- [ ] 測試通過。
