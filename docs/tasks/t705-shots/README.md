## 鐵道測試場長什麼樣

`rail-wide-day.png`、`rail-wide-night.png`（全景，zoom 0.7）、`rail-close-day.png`（近景，zoom 1.6）。在本機 Chromium 141 對 main 0d6954e（含 T704）用同一套鋪法試畫，截圖縮成 75%。從左上看起：

- 東西向主線跨過南北向道路（平交道）；
- 東端 L 彎往南、南端 L 彎往西；
- T 字岔線往南、盡頭是線尾（夜裡亮小紅燈）；
- 十字交叉；
- 過水的鐵路橋；
- 車站挨著主線（T574 起一般車站是 3×3 地塊，占 36–38 × 19–21，南邊緊貼 y=22 的主線）；
- 輕軌接鐵路；
- 平行雙線（現在會自動接成梯子，清單 P15）。

五列三節列車固定在直線、轉角、線尾前、橋上、平行線上。東端轉角那一列跨在彎上（車頭剛出彎 0.3 格）：現在的畫法把後兩節順著車頭方向往回推，甩到彎外的草地上（近景右邊看得到），T707 要修的就是這個。
