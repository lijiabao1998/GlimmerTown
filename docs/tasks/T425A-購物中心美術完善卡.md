## 一、TheoTown 美術實現方式（研究結論，本卡基準）

**本機素材**（`C:\Users\Leon1\TheoTown\plugins\sample\`）：32×25 等距建築視圖、196 色漸層材質、紅磚紋＋灰瓦＋綠植＋煙囪；JSON 定義 frames/animation（燈光）/smoke。mpf 插件包為加密格式（`ttplugindonthack`）不可解，遊戲本體素材不可達——以樣本＋官方教程為準。

**官方教程要點**（聯網搜索：TheoTown Forum plugin 教程、貼吧譯文）：
1. **等距視角**，遊戲內光源在左（左面亮、右面暗，暗面加亮框）
2. **比例**：1px≈2ft，人 3px 高；建築最高 256px
3. **陰影**：直落右側、長度＝物高、黑色 20% 不透明度、不畫出地面範圍
4. **材質**：照片取真實色、避免過飽和、繪製時避免深色輪廓
5. **步驟**：地面→牆→屋頂→窗框→細節（煙囪/材質）→草→陰影

**「超越」的定義**（本卡）：在 65_1_0 的 4×4 footprint 菱形硬約束內，美術**細節密度與豐富度**超過上述基準——程序化有限色票以「多體量層次＋立面肌理＋地面接點＋夜間層次＋人尺度附屬物」取勝。
