# T06 小地圖
版本：v1.2 ｜ 難度：★★ ｜ 前置：無 ｜ 建議模型：Sonnet

## 目標
右上角 144×144 小地圖：地形/分區/建築色塊＋目前視野框，點擊跳轉相機。低頻重繪不掉幀。

## 允許觸碰
CSS 新增 `#mini` 規則；HTML 新增一個 canvas；第 10 節新增 drawMini 相關代碼；`begin()` 一行；`endPointer()` 一行；`zoomStep()` 一行。

## 禁區
主 `draw()` 不動（小地圖獨立 canvas、獨立節奏）；toTile/相機數學不動（直接呼叫）。

## 實作步驟
1. CSS：定位錨 `@media (max-height:520px){#logo{display:none}#start h1{font-size:26px}}` → 其前插入：
```css
#mini{position:absolute;top:48px;right:10px;width:144px;height:144px;z-index:18;
  border:2px solid #2c3450;border-radius:8px;background:#0d1226;
  image-rendering:pixelated;cursor:pointer;display:none}
@media (max-width:420px){#mini{width:96px;height:96px;top:64px}}
```
2. HTML：定位錨 `<div id="zoomer">` → 其前插入 `<canvas id="mini" width="144" height="144"></canvas>`
3. 第 10 節（定位錨 `function toast(msg,cls){` 之前）新增：
```js
/* 小地圖 */
const miniCv=$('#mini'),miniG=miniCv.getContext('2d');
function drawMini(){
  if(!tiles)return;
  miniG.fillStyle='#0d1226';miniG.fillRect(0,0,144,144);
  for(let y=0;y<N;y++)for(let x=0;x<N;x++){
    const t=T(idx(x,y));
    let c=t.t===0?'#3671b6':t.t===1?'#d9c689':'#74b258';
    if(t.tree)c='#3e7a3c';
    if(t.zone)c=['','#2e7a44','#2f5f9a','#9a7a2e'][t.zone];
    if(t.road)c='#565b64';
    if(t.bld)c=['','#58c470','#5aa0e8','#e8b23e','#3e9a3c','#c8cfd8'][t.bld.k];
    miniG.fillStyle=c;miniG.fillRect(x*2,y*2,2,2);
  }
  // 視野框：四個螢幕角反推格座標連線
  miniG.strokeStyle='rgba(255,255,255,.85)';miniG.lineWidth=1;miniG.beginPath();
  [[0,0],[cvs.clientWidth,0],[cvs.clientWidth,cvs.clientHeight],[0,cvs.clientHeight]]
    .forEach((p,i)=>{const[tx,ty]=toTile(p[0],p[1]);
      const mx=clamp(tx,0,N)*2,my=clamp(ty,0,N)*2;
      i?miniG.lineTo(mx,my):miniG.moveTo(mx,my);});
  miniG.closePath();miniG.stroke();
}
setInterval(()=>{if(running)drawMini();},2000);
miniCv.addEventListener('pointerdown',e=>{
  e.stopPropagation();
  const r=miniCv.getBoundingClientRect();
  const tx=(e.clientX-r.left)/r.width*N, ty=(e.clientY-r.top)/r.height*N;
  cam.x=(tx-ty)*32;cam.y=(tx+ty)*16;clampCam();drawMini();
});
```
4. `endPointer()` 定位錨 `    $('#dragcost').style.display='none';` → 其後加一行 `    drawMini();`
5. `zoomStep()` 定位錨 `  clampCam();`（zoomStep 內那一處，函數末尾）→ 其後加一行 `  drawMini();`
   ⚠️ `clampCam();` 在檔案中出現多處，務必改 **zoomStep() 函數內** 的那一處。
6. `begin()` 定位錨 `  running=true;` → 其後加一行 `  $('#mini').style.display='block';drawMini();`

## 本卡驗收
1. 開新地圖 → 右上角出現小地圖，能看出水域/草地形狀與白色視野框。
2. 拖曳平移主畫面 → 2 秒內視野框跟著動；滾輪縮放 → 框大小變化。
3. 點小地圖左上角 → 主畫面跳到地圖西北角。
4. 建一片區域＋道路 → 鬆手後小地圖立即出現對應色塊。
5. VERIFY.md 全套＋效能項（FPS 不因小地圖下降）。
