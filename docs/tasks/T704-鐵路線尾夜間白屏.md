## 問題

城市裡只要有一段鐵路的盡頭（連接數 ≤1 的軌道格，例如車站旁的線尾）在畫面裡，**一到晚上整個畫面變白，天亮也回不來，要重新整理**。

根因（origin/main eacb7ff 行號）：

- T582 的車擋夜光在地面烘焙時推入 `rdecGlow.push({rect:[sx+30*z,sy+11*z,4*z,3*z],col:'#ff6a5a'})`（L18735）。這是 14 種 `rdecGlow` 條目裡唯一用 `rect` 格式的一種。
- T149 地面光暈迴圈（L18774–18786）只認 `x/y/w/h`：`gx=rg2.x+(rg2.w||0)/2` 得到 NaN，`ctx.createRadialGradient(NaN,…)` 丟錯。
- 丟錯時已經 `ctx.save()` 並設成 `'lighter'`，`ctx.restore()` 被跳過；`frame()` 沒有 try，每一個夜晚幀都重來一次，合成模式和 save 堆疊一直漏，畫面疊成全白。
- Node 測試抓不到：`test_fixde.js` 把 `createRadialGradient` 換成不會丟錯的替身；CI 的 frame 場景裡沒有鐵路。

本機 Chromium 實測（scratch `rail/train-hsr/out/live-night-compare.png`）：有線尾的夜景整片白，`window.__noBufferGlow582=true` 時正常。

## 做什麼

1. L18735 的車擋條目加 `noHalo:1`。小紅燈本身照舊由夜燈層（`nightSprites` 的 `rect` 分支，L20285）畫出；T582 G6c 釘的條件行（L18734）一字不動。
2. T149 光暈迴圈在算出 `gx,gy` 後加一行：不是有限數就 `continue`。日後再有別種條目缺 `x/y`，也只是少一圈光暈，不會白屏。
3. 行為測試 `docs/tasks/t704-shots/check-halo.cjs`：從 `index.html` 取出實際的 T149 迴圈原文，在 vm 裡用「遇到非有限數就丟錯」的 `createRadialGradient` 替身重放，放入車擋 `rect` 條目、正常路燈條目、和一筆故意缺座標的條目：
   - 不丟錯；`save`／`restore` 成對；正常條目照畫光暈；
   - 原始碼裡每一個 `rdecGlow.push({rect:` 都帶 `noHalo`；
   - 負控制：拿掉 `noHalo`、拿掉有限數檢查，兩者都要首紅在本測試。
   `test_fixde.js` 尾端只追加一段呼叫它。
4. `tools/bump.py` 升版；ARCH、CHANGELOG。
