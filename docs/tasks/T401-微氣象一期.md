# T401 — 微氣象一期:收割揚塵+秋末燒茬煙柱(農業美術三期 R5)

業主原文:「收割揚塵、秋末燒茬煙柱(遠景一兩柱,別多)」。晨霧局部化因兩套同名 fog
的地雷(見 T398-401 設計文檔)另卡處理,本卡不碰。

## 設計(全部掛在既有 smoke 管線,零新系統)

於 `updSmoke` 的逐建築 spawn 迴圈加農田分支(獨立 push,**不走 offs 路徑**——
offs 路徑尾端的 `ri(offs.length)` 正是 T402 記錄的亂數犯行,新代碼絕不沾):

1. **收割揚塵**:k22/k53 錨點格(`!b.ref` 防 2×2 四重噴)處於割茬態
   (gst===3,同 draw 端公式 `(day+⌊streetHash(x,y,777)*16⌋)%16÷4`,不含豐收節強制
   ——節慶全圖收割若跟著全圖揚塵會太吵,偏離披露)且非冬季時,低機率
   (`Math.random()<.10`)噴淡土色小塵煙(life 短、不 big)。
2. **燒茬煙柱**:秋季(sea===2)且割茬態,由 `streetHash(x,y,4010)<.06` 選出的
   「易燒農戶」噴褐色高煙柱(big),**每次 spawn 掃描硬上限 2 柱**(計數器,
   掃描序決定性)——業主紅線「一兩柱,別多」以硬上限落實而非機率。
3. 逃生閥 `__noFarmFx401`;煙量全程受既有 smokeCap 節流;亂數只用
   Math.random(噴發抖動)+streetHash(選址/相位),**零 R()/ri()**。

## 紅線

- 不動 offs 路徑、不動既有煙分支;存檔/模擬零影響(smokes 是運行時陣列,已有清空對)。
- gst 公式必須與 draw 端字面一致(週期 16、鹽 777)——公式漂移=煙與畫面對不上。
