# T128 建築細節密度提升（建築更細：屋頂與立面雜件）
版本：v3.5 ｜ 難度：★★★ ｜ 前置：T127 ｜ 建議模型：Sonnet

## 目標
全體建築的細節密度上一個台階：屋頂雜物（空調外機/通風管/曬衣繩/儲物箱/太陽能小板）、立面件（陽台欄杆/遮陽棚/窗台花箱/店招燈箱）——TheoTown 級的「湊近看有東西」。

## 架構鐵律（本卡成敗關鍵）
**絕不在既有生成序列中間加 R() 消耗**（會位移整條亂數流）。做法＝**尾端疊加 pass**：
buildSprites 絕對尾端（含 T127 塔樓生成之後）新增 detailPass()：遍歷 SPR.bld 全部鍵，讀對應 DRAFTS 行的幾何參數（hw/h/roofStyle 等）推算屋頂/立面區域，用**尾端位置的 R()** 直接往既有 sprite 畫布上補畫細節件；夜光件（燈箱/空調指示燈）同步補進 night 圖層。

## 定位錨
buildSprites 尾端；DRAFTS 幾何欄位；PARTS 風格（新細節件函數放 detailPass 內部，不改既有 PARTS）。

## 允許觸碰
detailPass 函式（新增）；細節件密度按建築等級遞增（lv1 少、lv3 密）；k=33/34 塔樓也吃 pass。細節色從該建築 PAL 行派生（同色系加深/提亮），不引入突兀新色。

## 硬性不變量
- 疊加只畫在 sprite 畫布既有非透明區域的合理範圍（屋頂=頂部菱形區、立面=牆面矩形區，從 DRAFTS 幾何推算），**不越出建築剪影**（越界=懸空件，驗收抽查）。
- detailPass 前的一切生成與改動前逐 R() 呼叫序一致（尾端 pass 零位移證明：pass 關閉開關時全部 sprite 與改動前位元一致）。
- 生成耗時增量 <1.5s；記憶體不新增鍵（原畫布上疊加）。

## 本卡驗收
1. 三件套照常。
2. 帶 __noDetail 除錯開關：開關開（跳過 pass）時全 SPR 鍵 checksum 與改動前位元一致（零位移證明）；關（正常）時逐鍵 checksum 與改動前互異（細節真的畫上了）。
3. 抽 10 鍵人眼級抽查（getImageData 區域取樣）：細節件在屋頂/牆面範圍內、無懸空越界；夜層燈箱亮點存在。
4. 冬季版（bldW 家族若有）不破圖；零 console 錯誤。
