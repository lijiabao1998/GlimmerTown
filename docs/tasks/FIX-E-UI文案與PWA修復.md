2. **doze 鈕重複**：非 base 分類重複出現第二個拆除鈕，移除重複項。
3. **inspect 文案對齊真實機制**：太陽能供電 15 棟／風力 20 棟／監獄半徑 8 防止犯罪發生／

   火車站·地標·機場改述「吸引遊客｜遊客提升全城商業稅收（上限 +20%）」。
4. **同區塊再三則**：停車場半徑 8 內商業 +10% 稅收／輕軌站改中性描述（大眾運輸節點）／回收中心全城垃圾容量 +30。
