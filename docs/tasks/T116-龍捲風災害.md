# T116 龍捲風災害
版本：v3.3 ｜ 難度：★★ ｜ 前置：無 ｜ 建議模型：Sonnet

## 目標
第四種災害：龍捲風——一條隨機直線路徑的移動實體，沿途建築轉廢墟、樹木吹倒，數十 tick 後消散。受災害總開關與 T115 難度倍率管轄。

## 定位錨
tick() 災害觸發區（地震/洪水先例）；移動實體先例（updTrains/updAmbulances）；draw() 實體繪製；disastersOn 開關；DIFF_HAZ 倍率；GV.quake/flood 鉤子先例。

## 允許觸碰
新增 tornado 狀態物件（null 或 {x,y,dx,dy,life}）；每日極低機率生成（×難度倍率、災害開關可關）；每 tick 沿路徑推進，所到之格：建築→既有廢墟/焦土鏈（複用火災燒毀處置，不新造資料形態）、樹→清除；漏斗雲用程序化 sprite（灰色錐形旋轉 2-3 幀，buildSprites 尾端生成）；toast 帶座標（T114 通知）；GV.tornado() 手動鉤子；T115 沙盒手動災害鈕列加一顆。

## 硬性不變量
tornado 不入存檔（讀檔即消散，簡單安全）；生成/推進的亂數走種子流 R()；災害開關關閉時零觸發；不動既有三災邏輯。

## 本卡驗收
1. 三件套照常。
2. GV.tornado() 觸發：實體沿路徑推進、途經建築變廢墟、樹消失、life 耗盡消散；漏斗雲兩幀動畫可見（連續取樣 diff>0）；toast 與通知日誌出現帶座標記錄且可跳轉。
3. 災害開關關閉時強制 0 觸發（統計 500 天）；存讀檔往返正常（tornado 不序列化）。
