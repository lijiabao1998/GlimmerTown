# T159 粒子與特效豐富化
版本：v4.3 ｜ 難度：★★ ｜ 前置：無 ｜ 建議模型：Sonnet

## 目標
在既有煙/雨雪之外加入低成本高感知的粒子特效：建造時塵土揚起、拆除碎屑、工業煙囪多樣煙羽、電廠蒸汽、達成里程碑/升星彩帶、火災火花與餘燼、樹木落葉（秋季）、車輛尾氣（重車）。

## 定位錨
- 既有粒子系統（`updSmoke`/`updRain`/煙掛點）、`updParticles` 若有、`visT`
- 建造 `doPlace`／拆除 `doze`／里程碑 `MILES`／升星／火災 `fire` 觸發點
- T149 光影層（火花可發光）

## 允許觸碰
- 新增輕量粒子類型（沿用既有粒子陣列結構或新增小陣列，運行時、不入存檔）：建造塵土（doPlace 觸發一次性）、拆除碎屑（doze）、達成彩帶（里程碑/升星，畫面頂部灑落）、火花餘燼（fire 格）、落葉（秋季樹格稀疏飄落）、車尾氣（卡車/重車）。
- 煙羽多樣化：工業/電廠煙依建築類型不同顏色/密度（既有煙掛點擴充）。
- 粒子生成可用 R()（屬事件觸發的動態粒子，非 sprite 生成；但**不得改 buildSprites 亂數流**——粒子在 tick/事件層，與 sprite 生成無關）；LOD：`z<0.5` 減量或跳過。

## 硬性不變量
- 粒子為運行時狀態，**不入存檔**，newWorld/load 清空（鐵律7）。
- 不改 `buildSprites`（不新增 sprite 鍵，粒子用 fillRect/既有小 sprite）；不改模擬數值與存檔。
- 粒子有上限（依效能檔 quality 縮放，沿用 T97 上限機制）；低效能檔大幅減量。
- 效能：粒子峰值時 60 幀採樣幀時間可接受。

## 本卡驗收
1. 三件套（node --check / test_fixde 380 / 瀏覽器零錯誤）。
2. 各特效逐一觸發確認：建造塵土、拆除碎屑、里程碑彩帶、火災火花、秋季落葉、煙羽多樣化（getImageData 或視覺驗）。
3. 粒子上限依效能檔縮放；newWorld 後粒子清空；存檔不含粒子。
4. 幀時間增量記錄；低效能檔減量生效。
