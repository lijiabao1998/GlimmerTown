## 0. 這張卡做什麼

**UI 現代化**＝在**不觸碰玩法／模擬／存讀檔**的前提下，把介面從「功能齊全」推進到
「現代遊戲 UI 的觀感與手感」：清晰的視覺層級、一致的分組、克制的動效、良好的空態與
反饋、響應式細節補齊。**目標不是加功能，是讓既有功能看起來／用起來更現代。**

### 施工白名單（唯一可改處）

- `index.html` 的 **CSS 樣式區**（`<style>` 內）與 **UI 渲染函式**（`showXxx`／`buildXxx`／`statTab`／`dataTable`／`toast`／`drawHUD` 相關）
- **嚴禁觸碰**：`tick`／`newWorld`／`load`／`save`／`doPlace`／`canPlace`／`aiStep`／經濟／AI／COST／TOOLS 資料結構／RLE／地圖／存檔格式／`R()`／`ri()`／`vri`／兩釘軌跡
- `test_fixde.js`：只增本卡守衛，既有斷言不得放寬
- `docs/tasks/T423-*.md`／`docs/CHANGELOG.md`／`docs/ARCH.md`（release tail 時）
- 每輪迭代獨立 commit；**不 bump 版號直到合併前**（版號跟合併序）

- 兩釘：`seed301 pop===4153`、`seed22 pop===4550` 必須恆等
