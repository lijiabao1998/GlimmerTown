# T47 觀光客與地標

## 目標
加入地標建築與觀光客系統，讓城市除了工業與住宅外，擁有文化與旅遊收入來源。

## 需求

### 1. 常數與工具列
- `COST.landmark=2000`。
- `KNAME[24]='地標'`。
- TOOLS 插入 `landmark`；無快捷鍵。

### 2. 建造邏輯
- 地標為 2×2 多格建築，可放於陸地、無建築、無道路。
- 每座城市限建 3 座地標。

### 3. 模擬邏擬
- 地標維護費 $8/天，就業 8/座。
- 每座地標每天吸引觀光客：`tourists += 50 + cityStar×20`。
- 觀光客收入：`tourismIncome = tourists × 0.08`（每天）。
- 地標半徑 12 內商業稅收 ×1.15。
- 城市評分 +5/座（上限 +15）。

### 4. 視覺
- `buildSprites` 追加 `SPR.bld['24_1_v']`：3 種地標（鐘樓、紀念碑、觀景塔），夜間燈光秀。

### 5. UI
- `inspect()`：「🗼 地標｜觀光客…｜商業稅×1.15｜評分+5」。
- `showStats()` 加 `nLand`、觀光客數、觀光收入。

### 6. 存檔
- `bl` 存 root，sz=2；觀光客不存（每天重算）。

### 7. 測試
- `test_t47.js`：驗證限建 3 座、觀光收入、評分加成、存讀檔。

## 驗收標準
- [ ] 地標 2×2 可建，全城限 3 座。
- [ ] 觀光客與收入計算正確。
- [ ] 測試通過。
