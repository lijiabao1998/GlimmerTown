# T05 環境音（晝鳥鳴／夜蟲鳴）＋音效三段開關
版本：v1.1 ｜ 難度：★★ ｜ 前置：無 ｜ 建議模型：DeepSeek

## 目標
音效按鈕從兩段（開/關）改三段循環：🔇靜音 → 🔊音效 → 🎵音效+環境音。環境音＝白天隨機鳥鳴、夜晚規律蟲鳴，全部 WebAudio 程式化，無音檔。設定持久化。

## 允許觸碰
第 9 節（音效）；第 10 節 `$('#bSound').onclick`；第 13 節啟動段讀取靜音設定的兩行。

## 禁區
`initAudio()` 的手勢解鎖模式不能破壞（瀏覽器規定：使用者第一次點擊前不得出聲）；`tone()` 簽名不改（其他音效都在用）。

## 實作步驟
1. 第 9 節：把「muted 布林」升級為「sndMode 0|1|2」。定位錨 `let muted=false;`（第 1 節）改為 `let muted=false,sndMode=1;`（保留 muted 變數名，由 sndMode 推導：`muted = sndMode===0`，避免改動所有音效函數）。
2. 第 9 節末尾新增環境音排程器：
   ```js
   setInterval(()=>{
     if(sndMode<2||!AC||AC.state!=='running'||!running)return;
     const b=daylight().b;
     if(b>.6&&Math.random()<.14){        // 白天鳥鳴：兩聲快速下滑音
       tone(1750+Math.random()*300,.09,'triangle',.02,1350);
       setTimeout(()=>tone(1500+Math.random()*250,.07,'triangle',.016,1200),120);
     }else if(b<.45&&Math.random()<.5){  // 夜晚蟲鳴：四連脈衝
       for(let i=0;i<4;i++)setTimeout(()=>tone(4200,.03,'square',.012),i*90);
     }
   },700);
   ```
   ※`daylight` 定義在第 7 節、此排程器在第 9 節執行時才呼叫，函數宣告有提升，可直接用。
3. 第 10 節按鈕改三段循環。定位錨 `$('#bSound').onclick=()=>{` 整個處理器替換為：
   ```js
   $('#bSound').onclick=()=>{
     sndMode=(sndMode+1)%3;
     muted=sndMode===0;
     $('#bSound').textContent=['🔇','🔊','🎵'][sndMode];
     localStorage.setItem(SAVEKEY+'.snd',sndMode);
     if(sndMode)sTick();
   };
   ```
4. 第 13 節啟動段。定位錨兩行
   `muted=localStorage.getItem(SAVEKEY+'.mute')==='1';`
   `$('#bSound').textContent=muted?'🔇':'🔊';`
   替換為（含舊設定遷移）：
   ```js
   const oldMute=localStorage.getItem(SAVEKEY+'.mute');
   sndMode=+(localStorage.getItem(SAVEKEY+'.snd')??(oldMute==='1'?0:1));
   if(sndMode<0||sndMode>2||isNaN(sndMode))sndMode=1;
   muted=sndMode===0;
   $('#bSound').textContent=['🔇','🔊','🎵'][sndMode];
   ```

## 存檔相容性
遊戲存檔無變更；設定鍵新增 `.snd`，舊 `.mute` 自動遷移（只讀不刪）。
