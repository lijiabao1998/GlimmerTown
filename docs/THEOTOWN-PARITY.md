## 四、架構級決策：資料驅動重構（v2.0 的核心）

TheoTown 最值得學的不是某個功能，是**「內容＝數據」**：建築由 JSON 定義、圖由掛點合成。
我們的對應版本（全原創）：把 buildSprites 里寫死的建築參數抽成資料表——

```js
const DRAFTS=[
  {k:1,lv:1,v:0, hw:20,h:14, wall:['#efe3c0','#cfc0a0'], roof:'#b0563c',
   roofStyle:'pyramid', door:'right', windows:{gx:6,gy:8,litP:.55},
   deco:['bush','path'], smoke:[], lights:'windows'},
  ...
]
```
繪製引擎讀資料表合成 sprite（金字塔頂/平頂/煙囪/遮陽棚…都是可組合的部件函數）。
**收益**：之後「加一種建築」＝往資料表加一行——正好是 Kimi/DeepSeek/Sonnet 能安全做的事，
且冬季幀、四向旋轉都變成「引擎各畫一遍」而不是「每棟樓重畫」。
