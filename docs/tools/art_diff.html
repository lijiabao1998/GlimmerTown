美術加蓋覆核台

用法（兩個模式，都可用 --dump-dom 無頭取字）：
① 量測模式（動手前的硬前置 A）：art_diff.html?a=/base/index.html&geom=1&keys=25_1_0,26_1_0 　印出每個鍵的 w/h/ax/ay、完整色票、重點細節色（≤16 px）座標、主色逐列 run（判斷等角走向）。
② 對照模式（每輪必交的證據）：art_diff.html?a=/base/index.html&b=/after/index.html&keys=25_1_0,26_1_0 　印出鍵集／metadata／逐鍵 img+night CRC 差分、白名單外改動、像素帳（變更／剪影溢出／覆蓋既有像素完整原色分佈）， 　並對「覆蓋 ≤16 px 重點細節色」直接判紅；下方輸出 5× 對照條（左 a／中 b／右 紅=新增不透明、黃=改動）。
兩個 URL 必須同源（自架靜態站把兩個版本掛在同一埠的兩個路徑下），否則跨源畫布會被污染而讀不到像素。
