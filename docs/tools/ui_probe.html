版面探針 · 標題畫面在多個視窗尺寸下的版面不變量

用法：ui_probe.html?a=/index.html&sizes=1280x720,1440x900,1920x1080,375x812
無頭取字：chrome --headless=new --disable-gpu --virtual-time-budget=90000 --dump-dom "<URL>"
原理：每個尺寸開一個**該尺寸的 iframe**（iframe 內的 media query 依 iframe 視窗解析，等同真實視窗）， 等 GV 開機後量 #start 覆蓋層的版面不變量。**同源**才讀得到 iframe 內的 DOM。
