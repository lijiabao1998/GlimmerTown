版面探針 · 標題畫面在多個視窗尺寸下的版面不變量（T428 R04 + T515）

用法：ui_probe.html?a=/index.html&b=/before.html&sizes=1280x720,390x844
無頭取字：chrome --headless=new --disable-gpu --virtual-time-budget=900000 --dump-dom "<URL>"
原理：每個尺寸開一個該尺寸的 iframe（iframe 內的 media query／vh 依 iframe 視窗解析，等同真實視窗）， 等 GV 開機後量 #start 覆蓋層。同源才讀得到 iframe 內的 DOM。
量的是「視窗尺寸」不是「螢幕尺寸」：1280×720 的螢幕上最大化的桌面瀏覽器可視高約 620px， 所以驗收清單裡要同時放 1280×620／1440×790 這類真實可視高（覆核者 S1 指出的第 7 條）。
給 b=（改動前的檔）才驗得了「不得退步」那組條件；沒給就標成 SKIPPED，不會假裝通過。
b= 有兩種取法：①另存 git show <改動前 commit>:index.html； ②直接用逃生閥——b=/index.html%3FnoT428=1（`?` 要編碼成 `%3F`）。 第②種讓 §5 的「關閉時逐值等於 BEFORE」真的在工具鏈內做得出來，不必改檔案； 前提是逃生閥的每一條退回都忠實（T428 R04/R07 各修過一次失真，見卡面 §11）。
