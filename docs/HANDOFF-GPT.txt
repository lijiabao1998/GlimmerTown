【項目是什麼】

  零依賴、全 Canvas 程序化像素美術、PWA。等距 64x32 瓦片、72x72 到 216x216 可選地圖。
- 61 種建築(k=1..61)、四季系統、災害、AI 市長模式、升級系統、特化經濟鏈。
- 測試套件 test_fixde.js：539 個斷言，DOM mock + eval 整個遊戲 + GV 鉤子驅動。

【開工前必做三件事】
1. 備份：複製 index.html 為 backups/index.pre-gpt.html（沒有 backups 目錄就建一個）。
2. 跑基線：node test_fixde.js → 必須看到 539 個 PASS、0 FAIL。不是 539 就停手回報。
3. 讀 docs/CHANGELOG.md 最上面 15 行，了解最近改了什麼。

【瀏覽器驗證規矩（保命條款）】
- 啟動：python -m http.server 8123 --directory <本資料夾>
- 一律用 http://127.0.0.1:8123 開測試頁（獨立 origin）。
- 玩家的真實存檔在 http://localhost:8123 這個 origin 的 localStorage——絕對不要開
  localhost 去測試，絕對不要動它的存檔。
- 測試頁先執行：localStorage.setItem('glimmerville.v1.slot','3')
  只允許用槽 3。絕不讀寫 glimmerville.v1.s1 / s2。
- 有 Service Worker：測前 unregister 全部 SW + caches.delete 全部，再帶
  ?cb=隨機字串 重載，否則你跑的是舊代碼（血淚教訓）。
- 遊戲全域 GV 是測試鉤子入口（window 下沒有，但 GV 有暴露）。常用：
  GV.newWorld() / GV.newWorldSeeded(n) / GV.place(tool,x,y) / GV.tile(x,y)
  GV.step(n)(n<=60，長跑用迴圈) / GV.addMoney(n) / GV.stats() / GV.food()
  GV.setSeason(0..3) / GV.weather(0)鎖晴 / GV.setVisT(0夜|55正午) / GV.forceDraw()
  GV.lookAt(x,y)+GV.setZoom(z) 相機 / GV.upgrade(x,y) / GV.inspectAt(x,y)
  GV.ai(true|false) AI市長 / GV.ignite(x,y)點火 / GV.setMapSize(72|108|144|216)
  GV.canPlaceTool(tool,x,y)→null=可蓋 / GV.sprNightAudit()夜燈審計(應回空陣列)
  GV.region().powerCap 供電容量 / GV.cov(field,x,y) 服務覆蓋

【鐵律（每一條都是真實事故換來的，違反=大概率翻車）】
1. 單寫者：同一時刻只允許一個 AI 寫這個資料夾。你開工期間 Claude 已停筆；
   你停止後也不要留背景進程繼續改檔。
2. 亂數流：新增會消耗 rand()/R() 的 sprite 生成，只能放 buildSprites 尾端
   （搜 "FIX-B 亂數流對齊"），或用局部 PRNG（mulberry32/局部 LCG/Math.random
   僅限 sprite 生成內），或純座標雜湊 streetHash(x,y,salt)。動了中段亂數流
   = 全部既有地圖變樣。
3. 存檔相容：save()/load() 格式改動要向後相容（新欄位一律「可選、缺省安全」）。
   load 端每個 k 有獨立重建碼——新欄位要用「非預設值」實測 load 是否硬編碼。
4. 稅收守衛：新建築 k 若會進 tick() 第二經濟迴圈，必須在稅收 else-if 鏈加一條
   空守衛 `else if(b.k===K);`，否則 fall through 到工業稅，建築升級到 lv>=4 時
   JOBSI[lv]=undefined → money=NaN → 存檔毀（搜 "鐵律14"）。
5. 預設值：設定表(如 UP_JOB)讀取用 ?? 不用 ||（顯式 0 會被 0||6 吃掉）。
6. 完工線：建築 age>=9 才算蓋完（9 天分階段施工）。驗渲染效果前先
   GV.step(12) 催熟，否則本體還沒畫、diff 全 0 是假象。
7. 夜燈：建築 night 畫布在 buildSprites 尾端有 destination-in 本體遮罩
   （maskNight）。新建築 sprite 有夜燈的話會自動被遮，別把夜燈畫到本體外。
8. 像素驗證要用「乾淨隔離世界」：GV.newWorld + GV.weather(0) + 指定季節 +
   手動建設 + 催熟，再取樣。AI 長跑過的世界有天氣殘留（濕膜/雪）會把畫面
   洗白造成誤判。
9. 全域狀態新增時，newWorld() 與 load() 要成對重置（搜「鐵律7」樣例）。
10. GV.tile() 回傳副本，直接改它的欄位不會生效。要改狀態走 GV.place/
    GV.upgrade 等操作型鉤子。
11. RCI 住宅/商業立面多為手繪 HERO_PIX 覆蓋，程序化改立面大概率不可見。
    改前先 git/checksum A/B 確認有像素差，沒差就回退別硬做。
12. 多格新建築完整清單（做新建築照抄這份，漏一項就出 bug）：
    TOOLS 條目 / COST / KNAME / canPlace(canPlaceMulti) / placeCost switch /
    doPlace(root+ref 格) / 第一迴圈計數+jobs+upkeep / 第二迴圈稅收守衛 /
    inspect 文案 / MSZ 表(load 反查 sz，漏了 ref 格全失) / MINI_BLD_PAL 色 /
    sprite(尾端) / test_fixde.js 的 SV 清單+SVK+tampered 計數同步 +1。
