# P01-C 後續候選，非已實作或發布授權

## P02 設備動畫
只在同一四台岸橋與既有堆場上新增可重播的吊具升降、橫移、回位三段動畫。位置／高度在固定時間軸計算；維持足部、梁架、艙位界線與同一圖層排序。先以空載示範，不能把貨櫃移動宣稱為真實貨流。
驗收：固定 seed/time × 四方向、夜冬、遠近景；停止／恢復／切換逃生閥無跳位；吊具不穿地或屋頂；60 Hz 時間抽樣與低 FPS 跳幀仍落在同一動作階段；原世界／財政／存檔不變；cache 不逐幀烘焙；新幀成本分開記錄。先獨立候選，不自動接入主線。

## P03 船舶進出港
以實際水格連通圖建立岸前泊位至地圖邊界的確定性航路。先一艘貨櫃輪及等待／入港／靠泊／離港狀態，拖船和散裝輪列後續資產卡。船長、寬、轉彎 swept footprint 需碰撞整個船體而非單一中心點。
驗收：封閉港池、狹窄水道、錯誤岸向、地圖邊界與中途封路負控制；不得穿陸、瞬移、錯位靠泊；逐步位置／朝向和回播；各泊位的停靠空間不能被岸橋足部侵占。船舶圖像先做大小選樣與圖審，動畫不接經濟吞吐。真實容量、船期與鐵海聯運另立 P04/P05 帳本卡。
