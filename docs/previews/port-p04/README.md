# P04 船岸貨櫃交接候選

基線 P03 2166f378。獨立候選，不合併 main、不部署 Pages、不解除暫停、不寫玩家存檔。

## 實際操作

在此目錄 node build.cjs 產生單檔 native-preview.html，以獨立瀏覽器開啟，或在非玩家埠提供HTTP。預覽只用記憶體槽3。展開左上港口預覽，使用船舶播放／暫停／重設，或裝卸對位／吊起畫面／交付畫面與時間滑桿。P04首航比P03增加54秒；第3岸橋只交接原船1件貨櫃。交付後該件留在堆場，後續航次不重複生成；重設才明確恢復初始候選帳。

?noP04=1 或 window.__noP04=true 還原P03原始6秒停泊及整幀；再疊noP03/noP02可回退P02/P01-C。此處不是正式遊戲存檔或港口經濟帳。

## 為何不是直接播放原岸橋

原靠泊首個近岸櫃位於27.25,36.19，沒有一台岸橋精確對準；最近第2岸橋的岸前空位只有.495格，而原貨櫃深.5格。保留這個拒絕結果。P04在原靠泊後加入12秒可重播的低速對位，整艘船連續移到29.25,36.3，貨櫃仍保持原船上相對位置，自然對準第3岸橋30,35.99。卸貨後12秒連續返位，再接原P03出港航次。船體完整掃掠水格檢查，不重做導航、不瞬移。

原小車、吊具、四索、腳座、船櫃尺寸不變。空載吊具先對準櫃頂12，抓取後升到48，移到30,34.62，降至櫃底2、吊具底7後釋放，再抬起返回。最小幾何間距只有.015–.074格等級，是明確的候選幾何裕度，不宣稱真實工程安全係數。所有檢查納入完整體積及保守線段包絡，不只檢查中心點。
