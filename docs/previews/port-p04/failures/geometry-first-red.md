# 保留首個真實幾何拒絕

未改任何原設備前：P03近岸船櫃x27.25/y36.19與原第2岸橋x27不同軸，原P02最遠小車中心35.98；即便到36.19，.24深小車越過原梁端36.23達.08格。原第2岸橋堆場前間隙僅.495格，小於不變的.5深貨櫃。後方中央橫樑也會與原小車/索具碰撞。

拒絕直接搬運，不移腳座、不縮貨櫃、不虛構斜拉或空位。實作改為P04限定、連續掃掠驗證的12秒船體對位，使用原第3岸橋與真實空白支撐地塊。geometry-test保留原梁端、窄空位、橫樑、足座、岸壁、滿載負控制。

首輪原生排序覆核另外抓到反向視角吊櫃被船甲板遮蓋：獨立射線深度檢查228畫面12996樣點有38處錯誤。改成相同船舶上層幾何群內交錯繪製，但貨櫃所有權仍為吊具；落地後才獨立地面排序。不是把櫃複製回船，也不是強制永遠最後繪製。

將吊櫃放入船舶群雖解決船甲板問題，但完整港區覆核再抓到153處吊具／前景橋柱遮擋錯誤。因此保留第二次紅源，改為貨櫃只在最終候選節點繪製，且逐面以真正原生港區、船體和吊具面片的射線深度扣除較近遮擋；不是永遠蓋住別物的overlay。相交遮擋取聯集，重疊區不重新露出；原P01–P03及OFF像素不變。

本地首輪舊存檔602/603曾因新增橋接用隱式P01B全域而紅，改明確window.P01B後原有8項focused檢查全部過；原失敗log保留。未改原測試或門檻。
